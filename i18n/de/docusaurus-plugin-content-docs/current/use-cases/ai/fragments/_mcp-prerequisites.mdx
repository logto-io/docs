## Voraussetzungen \{#prerequisites}

- Ein [Logto Cloud](https://cloud.logto.io) (oder selbst gehosteter) Mandant
- Node.js >= 20 Umgebung

### Architektur verstehen \{#understanding-the-architecture}

- **MCP-Server**: Der Server, der Tools und Ressourcen für MCP-Clients bereitstellt. Nach der [neuesten MCP-Spezifikation](https://modelcontextprotocol.io/specification/latest/basic/authorization) agiert er als OAuth 2.0-Ressourcenserver, der Zugangstokens (Access tokens) validiert, die von Logto ausgestellt wurden.
- **MCP-Client**: Ein Client, der verwendet wird, um den Authentifizierungsablauf zu starten und die Integration zu testen. {<b>{props.isThirdParty ? 'Der Drittanbieter-AI-Agent wird in dieser Anleitung als Client verwendet.' : "Wir verwenden VS Code (mit integrierter MCP-Unterstützung) als Client in dieser Anleitung."}</b>}
- **Logto**: Dient als OpenID Connect-Provider (Autorisierungsserver), verwaltet Benutzeridentitäten und stellt zielgruppenbezogene JWT-Zugangstokens (Access tokens) für deinen MCP-Server aus.
