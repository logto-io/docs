Initialisiere den Client, indem du eine `LogtoClient`-Instanz mit einem `LogtoConfig`-Objekt erstellst.

```swift title="ContentView.swift"
import Logto
import LogtoClient

let config = try! LogtoConfig(
  endpoint: "<your-logto-endpoint>", // Z. B. http://localhost:3001
  appId: "<your-app-id>"
)
let client = LogtoClient(useConfig: config)
```

:::info

Standardmäßig speichern wir Anmeldedaten wie ID-Token (ID token) und Auffrischungstoken (Refresh token) im Schlüsselbund (Keychain). Dadurch muss sich der Benutzer nicht erneut anmelden, wenn er zurückkehrt.

Um dieses Verhalten zu deaktivieren, setze `usingPersistStorage` auf `false`:

```swift
let config = try! LogtoConfig(
  // ...
  usingPersistStorage: false
)
```

:::
