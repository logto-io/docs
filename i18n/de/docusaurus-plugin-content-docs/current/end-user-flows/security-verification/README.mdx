# Sicherheitsüberprüfung

Wenn authentifizierte Benutzer versuchen, sensible oder risikoreiche Aktionen durchzuführen – wie das Ändern ihres Passworts, das Tätigen einer Zahlung oder den Zugriff auf vertrauliche Informationen wie Gehaltsabrechnungen oder Bankkontodaten – sind zusätzliche Sicherheitsmaßnahmen unerlässlich. Dieser Ablauf ist besonders kritisch in sensiblen Anwendungen wie dem Bankwesen, dem Gesundheitswesen und bei staatlichen Diensten.

Dieser Prozess, bekannt als _Sicherheitsüberprüfung (security verification)_, verlangt von den Benutzern, ihre Identität erneut zu verifizieren, um zu bestätigen, dass sie der autorisierte Kontoinhaber sind. Durch die Implementierung der Sicherheitsüberprüfung verstärkt das System den Schutz vor unbefugtem Zugriff, fügt eine entscheidende Sicherheitsebene für risikoreiche Aktionen hinzu und hilft, sensible Daten zu schützen.

:::tip[Bevorzuge OIDC Step-up-Authentifizierung für Anwendungen und APIs]
Um eine kürzlich erfolgte Authentifizierung oder MFA für deine eigenen Anwendungen und geschützten API-Ressourcen durchzusetzen – oder um sensible [Account API](/end-user-flows/account-settings/by-account-api)-Aufrufe mit Standard-Tokens zu autorisieren – verwende [OIDC Step-up-Authentifizierung](/end-user-flows/step-up-authentication) (`acr_values`, `max_age` und RFC 9470 Challenges).

Nutze die untenstehende Verification API, wenn deine First-Party-Anwendung die Account API direkt mit einem `logto-verification-id`-Header aufruft oder wenn du den Besitz einer neuen E-Mail-Adresse oder Telefonnummer nachweisen musst, bevor du sie an das Konto bindest.
:::

## Sicherheitsüberprüfung per Account API implementieren \{#implement-security-verification-by-account-api}

:::note
Denke daran, zuerst die [Account API zu aktivieren](/end-user-flows/account-settings/by-account-api) und das `access_token` für den Benutzer zu erhalten.
:::

## Passwortüberprüfung \{#password-verification}

Wenn Benutzer versuchen, ihr Passwort oder eine andere Sicherheitseinstellung über eine direkte Account API-Integration zu ändern, fordere sie auf, ihr aktuelles Passwort einzugeben, um eine 10-minütige `verificationRecordId` für den `logto-verification-id`-Header zu erhalten.

| Methode | Pfad                                                                                                     | Beschreibung                       |
| ------- | -------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| POST    | [/api/verifications/password](https://openapi.logto.io/operation/operation-createverificationbypassword) | Aktuelles Benutzerpasswort prüfen. |

## E-Mail/SMS-Einmalcode-Überprüfung \{#emailsms-one-time-code-verification}

Sende einen Bestätigungscode an die E-Mail-Adresse oder Telefonnummer des Benutzers und fordere ihn auf, den Code einzugeben, um seine Identität zu bestätigen. Diese Endpunkte können verwendet werden, um die Identität eines Benutzers zu überprüfen oder den Besitz einer bestimmten E-Mail-Adresse oder Telefonnummer zu bestätigen. Dieser Verifizierungsschritt wird dringend empfohlen, wenn ein Benutzer versucht, eine neue E-Mail-Adresse oder Telefonnummer mit seinem Konto zu verknüpfen, um die Echtheit der bereitgestellten Informationen sicherzustellen.

| Methode | Pfad                                                                                                                             | Beschreibung                                           |
| ------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| POST    | [/api/verifications/verification-code](https://openapi.logto.io/operation/operation-createverificationbyverificationcode)        | E-Mail- oder Telefonnummer-Bestätigungscode senden.    |
| POST    | [/api/verifications/verification-code/verify](https://openapi.logto.io/operation/operation-verifyverificationbyverificationcode) | E-Mail oder Telefonnummer per Bestätigungscode prüfen. |
