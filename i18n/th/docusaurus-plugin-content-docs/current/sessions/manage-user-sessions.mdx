# จัดการเซสชันผู้ใช้

การจัดการเซสชันผู้ใช้ช่วยให้ผู้ใช้และผู้ดูแลระบบสามารถตรวจสอบสถานะการลงชื่อเข้าใช้ที่กำลังใช้งานอยู่ และเพิกถอนเซสชันเมื่อจำเป็น

ใน Logto คุณสามารถจัดการเซสชันผ่าน 3 เส้นทางหลักดังนี้:

- **Account API**: สำหรับบริการตนเองของผู้ใช้ปลายทางในหน้าตั้งค่าบัญชีของผลิตภัณฑ์คุณ
- **Management API**: สำหรับเครื่องมือผู้ดูแลหรือฝ่ายสนับสนุนเพื่อจัดการเซสชันของผู้ใช้รายใดก็ได้
- **Admin Console**: สำหรับกระบวนการของผู้ปฏิบัติงานใน Logto Console โดยไม่ต้องสร้างเครื่องมือเอง

## เลือก API ที่เหมาะสม \{#choose-the-right-api}

| สถานการณ์                                          | API ที่แนะนำ   |
| -------------------------------------------------- | -------------- |
| ให้ผู้ใช้ที่ลงชื่อเข้าใช้จัดการเซสชันของตนเอง      | Account API    |
| ให้ผู้ดูแลหรือทีมสนับสนุนจัดการเซสชันของผู้ใช้     | Management API |
| ให้ผู้ปฏิบัติงานจัดการเซสชันโดยตรงใน Logto Console | Admin Console  |

## ดูเซสชันที่กำลังใช้งาน \{#view-active-sessions}

### Account API (บริการตนเอง) \{#account-api-self-service}

ใช้ endpoint ของ Account API สำหรับเซสชันเพื่อแสดงรายการเซสชันที่กำลังใช้งานของผู้ใช้ปัจจุบัน

- ส่วนอ้างอิง: [จัดการเซสชันผู้ใช้](/end-user-flows/account-settings/by-account-api#manage-user-sessions)
- Endpoint: [`GET /api/my-account/sessions`](https://openapi.logto.io/operation/operation-getsessions)

ก่อนเปิดใช้งานความสามารถนี้ให้ผู้ใช้ปลายทาง โปรดตรวจสอบให้แน่ใจว่าได้เปิดใช้งานการจัดการเซสชันใน Account center settings และแอปของคุณร้องขอขอบเขต Account API ที่จำเป็น

### Management API (เครื่องมือผู้ดูแล) \{#management-api-admin-tools}

ใช้ Management API เมื่อระบบผู้ดูแลของคุณต้องการแสดงรายการเซสชันของผู้ใช้เป้าหมาย

- ส่วนอ้างอิง: [การจัดการเซสชันผู้ใช้](/end-user-flows/account-settings/by-management-api#user-session-management)
- Endpoint: [`GET /api/users/{userId}/sessions`](https://openapi.logto.io/operation/operation-listusersessions)
- Endpoint รายละเอียดเพิ่มเติม (ไม่บังคับ): [`GET /api/users/{userId}/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-getusersession)

## เพิกถอนเซสชัน \{#revoke-sessions}

### Account API (ผู้ใช้ปลายทางเพิกถอนเซสชันของตนเอง) \{#account-api-end-user-revokes-own-sessions}

ผู้ใช้ปลายทางสามารถเพิกถอนเซสชันใดเซสชันหนึ่งจากรายการเซสชันของตนเองได้

- ส่วนอ้างอิง: [จัดการเซสชันผู้ใช้](/end-user-flows/account-settings/by-account-api#manage-user-sessions)
- Endpoint: [`DELETE /api/my-account/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-deletesessionbyid)

สำหรับการดำเนินการที่ละเอียดอ่อน การจัดการเซสชันผ่าน Account API ต้องมีการยืนยันตัวตนของผู้ใช้ล่าสุดก่อนเข้าถึง ดู [การยืนยันตัวตนขั้นสูง (Step-up authentication)](/end-user-flows/step-up-authentication#account-api-and-account-center)

### Management API (ผู้ดูแลเพิกถอนเซสชันของผู้ใช้) \{#management-api-admin-revokes-user-sessions}

ผู้ดูแลสามารถเพิกถอนเซสชันของผู้ใช้เป้าหมายโดยใช้ user ID และ session ID

- ส่วนอ้างอิง: [การจัดการเซสชันผู้ใช้](/end-user-flows/account-settings/by-management-api#user-session-management)
- Endpoint: [`DELETE /api/users/{userId}/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-deleteusersession)

## Admin Console \{#admin-console}

หากทีมของคุณจัดการผู้ใช้โดยตรงใน Logto Console คุณสามารถตรวจสอบเซสชันที่กำลังใช้งานและเพิกถอนเซสชันเฉพาะจากหน้ารายละเอียดผู้ใช้ได้

- ส่วนอ้างอิง: [จัดการเซสชันที่กำลังใช้งานของผู้ใช้](/user-management/manage-users#manage-user-active-sessions)
