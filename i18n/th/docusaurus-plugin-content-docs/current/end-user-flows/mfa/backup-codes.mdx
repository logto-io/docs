# รหัสสำรอง (Backup codes)

## แนวคิด \{#concepts}

รหัสสำรอง หรือที่เรียกว่า Recovery code คือรหัสใช้ครั้งเดียวสำหรับการยืนยันตัวตนหลายปัจจัย (MFA) ทำหน้าที่เป็นทางเลือกสำรองในกรณีที่ปัจจัยการยืนยันตัวตนหลักของผู้ใช้ (เช่น แอปยืนยันตัวตน หรือโทเค็นฮาร์ดแวร์) ไม่พร้อมใช้งาน

การสูญเสียรหัสเหล่านี้อาจทำให้การกู้คืนบัญชีเป็นเรื่องยาก ดังนั้นจึงแนะนำให้ตั้งค่าปัจจัยหลักเพิ่มเติมก่อนเปิดใช้งานรหัสสำรอง และให้ความสำคัญกับปัจจัยหลัก

Logto จะสร้างรหัสสำรอง 10 ชุดโดยอัตโนมัติให้กับผู้ใช้เมื่อมีการตั้งค่าปัจจัยเพิ่มเติมแล้ว โดยแต่ละรหัสใช้ได้เพียงครั้งเดียว ผู้ใช้สามารถสร้างรหัสชุดใหม่ได้ผ่าน [หน้าศูนย์บัญชีสำเร็จรูป](/end-user-flows/account-settings/by-account-center-ui) (`/account/backup-codes/regenerate`), อินเทอร์เฟซบริการตนเองแบบกำหนดเองที่สร้างด้วย [Account API](/end-user-flows/account-settings/by-account-api#manage-backup-codes) หรือเครื่องมือผู้ดูแลระบบที่ใช้ [Management API](/end-user-flows/account-settings/by-management-api#user-mfa-settings-management) ก่อนที่รหัสเดิมจะถูกใช้หมด

## ตั้งค่ารหัสสำรองสำหรับ MFA \{#configure-backup-codes-for-mfa}

1. ไปที่ <CloudLink to="/mfa">Console > Multi-factor authentication</CloudLink>
2. เปิดใช้งานปัจจัย "Backup Codes" (รหัสสำรองไม่สามารถใช้เป็นปัจจัย MFA เดียวได้ ต้องใช้ร่วมกับปัจจัย MFA หลักอื่น ๆ เช่น passkeys, แอปยืนยันตัวตน, SMS, อีเมล)
3. กำหนดนโยบาย MFA ที่ต้องการ (เลือกได้: ไม่บังคับ, ปรับเปลี่ยนตามสถานการณ์, หรือบังคับ)
4. บันทึกการเปลี่ยนแปลงการตั้งค่า

## ตั้งค่าการจัดการรหัสสำรอง \{#configure-backup-codes-management}

ผู้ใช้สามารถดูและสร้างรหัสสำรองใหม่ได้ผ่าน [หน้าศูนย์บัญชีสำเร็จรูป](/end-user-flows/account-settings/by-account-center-ui) (`/account/backup-codes/manage` และ `/account/backup-codes/regenerate`) คุณยังสามารถใช้ Account API เพื่อสร้างอินเทอร์เฟซจัดการบัญชีแบบกำหนดเองที่ผู้ใช้สามารถดู สร้างใหม่ และลบรหัสสำรองของตนเองได้ วิธีนี้ช่วยให้ผู้ใช้จัดการตัวเลือกการกู้คืนบัญชีได้โดยตรงจากหน้าตั้งค่าบัญชีของแอปพลิเคชันของคุณ

สำหรับขั้นตอนการใช้งานและ API endpoint โดยละเอียด ดูที่ [การตั้งค่าบัญชีด้วย Account API](/end-user-flows/account-settings/by-account-api#manage-backup-codes)

## กระบวนการตั้งค่ารหัสสำรอง \{#backup-codes-setup-flows}

เนื่องจากรหัสสำรองเป็นปัจจัย MFA รอง จึงสามารถตั้งค่าได้หลังจากที่มีการตั้งค่าปัจจัย MFA หลักสำเร็จแล้วเท่านั้น ระบบจะแสดงรหัสสำรองที่สร้างอัตโนมัติ 10 ชุดให้ผู้ใช้ ซึ่งสามารถดาวน์โหลดและคัดลอกเก็บไว้อย่างปลอดภัย ผู้ใช้ต้องยืนยันรหัสสำรองด้วยตนเองเพื่อให้กระบวนการตั้งค่า MFA เสร็จสมบูรณ์

## กระบวนการตรวจสอบรหัสสำรอง \{#backup-codes-verification-flow}

รหัสสำรองทำหน้าที่เป็นการยืนยันตัวตนฉุกเฉินเมื่อปัจจัย MFA หลักไม่พร้อมใช้งาน โดยแต่ละรหัสใช้ได้เพียงครั้งเดียวและจะหมดอายุหลังจากตรวจสอบสำเร็จ

**ลำดับความสำคัญในการตรวจสอบ:**

- **ปัจจัยหลักมาก่อน**: เมื่อผู้ใช้ตั้งค่าปัจจัย MFA อื่นไว้แล้ว ระบบจะขอปัจจัยหลัก (passkeys, TOTP, SMS, อีเมล) ก่อน
- **เข้าถึงรหัสสำรอง**: ผู้ใช้สามารถเปลี่ยนไปใช้รหัสสำรองได้โดยคลิก "ลองวิธีอื่นเพื่อยืนยัน" หากปัจจัยหลักไม่พร้อมใช้งาน
- **กรณีสำรองสุดท้าย**: หากปัจจัยหลักทั้งหมดถูกลบ รหัสสำรองจะกลายเป็นตัวเลือกเดียวสำหรับการยืนยัน หลังจากยืนยัน MFA สำเร็จด้วยรหัสสำรองขณะลงชื่อเข้าใช้ Logto จะขอให้ผู้ใช้ตั้งค่าปัจจัยหลักใหม่โดยอัตโนมัติ
