# รหัสสำรอง (Backup codes)

## แนวคิด \{#concepts}

รหัสสำรอง หรือที่เรียกว่า Recovery code คือรหัสใช้ครั้งเดียวสำหรับการยืนยันตัวตนหลายปัจจัย (MFA) ทำหน้าที่เป็นตัวสำรองในกรณีที่ปัจจัยการยืนยันตัวตนหลักของผู้ใช้ (เช่น แอปยืนยันตัวตน หรือโทเค็นฮาร์ดแวร์) ไม่พร้อมใช้งาน

หากสูญเสียรหัสเหล่านี้ อาจทำให้การกู้คืนบัญชีเป็นเรื่องยาก ดังนั้นจึงแนะนำให้ตั้งค่าปัจจัยหลักเพิ่มเติมก่อนเปิดใช้งานรหัสสำรอง และให้ความสำคัญกับปัจจัยหลัก

Logto จะสร้างรหัสสำรอง 10 รหัสโดยอัตโนมัติให้กับผู้ใช้เมื่อมีการตั้งค่าปัจจัยเพิ่มเติมแล้ว โดยแต่ละรหัสใช้ได้เพียงครั้งเดียว ผู้ใช้สามารถสร้างชุดรหัสใหม่ได้ผ่าน [หน้าศูนย์บัญชีสำเร็จรูป](/end-user-flows/account-settings/by-account-center-ui) (`/account/backup-codes/regenerate`), อินเทอร์เฟซบริการตนเองที่สร้างด้วย [Account API](/end-user-flows/account-settings/by-account-api#manage-backup-codes) หรือเครื่องมือผู้ดูแลระบบที่ใช้ [Management API](/end-user-flows/account-settings/by-management-api#user-mfa-settings-management) ก่อนที่รหัสเดิมจะถูกใช้หมด

## ตั้งค่ารหัสสำรองสำหรับ MFA \{#configure-backup-codes-for-mfa}

1. ไปที่ <CloudLink to="/mfa">Console > Multi-factor authentication</CloudLink>
2. เปิดใช้งานปัจจัย "Backup Codes" (รหัสสำรองไม่สามารถใช้เป็นปัจจัย MFA เดียวได้ ต้องใช้ร่วมกับปัจจัย MFA หลักอื่น ๆ เช่น passkeys, แอปยืนยันตัวตน, SMS, อีเมล)
3. กำหนดนโยบาย MFA ที่ต้องการ (เลือกได้: ไม่บังคับ, ปรับเปลี่ยนตามสถานการณ์, หรือบังคับใช้)
4. บันทึกการเปลี่ยนแปลงการตั้งค่า

## ตั้งค่าการจัดการรหัสสำรอง \{#configure-backup-codes-management}

ผู้ใช้สามารถดูและสร้างรหัสสำรองใหม่ได้ผ่าน [หน้าศูนย์บัญชีสำเร็จรูป](/end-user-flows/account-settings/by-account-center-ui) (`/account/backup-codes/manage` และ `/account/backup-codes/regenerate`) คุณยังสามารถใช้ Account API เพื่อสร้างอินเทอร์เฟซจัดการบัญชีแบบกำหนดเองที่ผู้ใช้สามารถดู สร้างใหม่ และลบรหัสสำรองของตนเองได้ ช่วยให้ผู้ใช้จัดการตัวเลือกการกู้คืนบัญชีได้โดยตรงจากหน้าตั้งค่าบัญชีของแอปคุณ

สำหรับขั้นตอนการใช้งานและ API endpoint โดยละเอียด ดูที่ [การตั้งค่าบัญชีด้วย Account API](/end-user-flows/account-settings/by-account-api#manage-backup-codes)

## กระบวนการตั้งค่ารหัสสำรอง \{#backup-codes-setup-flows}

เนื่องจากรหัสสำรองเป็นปัจจัย MFA รอง จึงสามารถตั้งค่าได้หลังจากตั้งค่าปัจจัย MFA หลักสำเร็จแล้วเท่านั้น ระบบจะแสดงรหัสสำรองที่สร้างอัตโนมัติ 10 รหัสให้ผู้ใช้ ซึ่งสามารถดาวน์โหลดและคัดลอกเก็บไว้อย่างปลอดภัย ผู้ใช้ต้องยืนยันรหัสสำรองด้วยตนเองเพื่อให้กระบวนการตั้งค่า MFA สมบูรณ์

Logto จะเตือนผู้ใช้ระหว่างการลงชื่อเข้าใช้ให้สร้างและบันทึกรหัสสำรองชุดใหม่ หากเปิดใช้งาน **Backup codes** และผู้ใช้มีปัจจัยหลักอื่นอยู่แล้วแต่ไม่มีรหัสสำรองเหลือ เช่น:

- รหัสสำรองที่สร้างไว้ก่อนหน้านี้ถูกใช้หมดแล้ว
- คุณเปิดใช้งาน **Backup codes** หลังจากที่ผู้ใช้ลงทะเบียนปัจจัย MFA หลักไปแล้ว

สำหรับผู้ใช้เดิม การเตือนนี้จะเกิดขึ้นหลังจากผู้ใช้ยืนยันความท้าทาย MFA (หรือเข้าสู่ระบบด้วย passkey) เท่านั้น การลงชื่อเข้าใช้ที่ข้ามการตรวจสอบ MFA (เช่น อุปกรณ์ที่เชื่อถือได้, การลงชื่อเข้าใช้ [Adaptive MFA](/end-user-flows/mfa/adaptive-mfa) ที่มีความเสี่ยงต่ำ, หรือผู้ใช้ข้าม **Optional MFA**) จะไม่เตือนให้ผูกมัดรหัสสำรองใหม่ระหว่างการลงชื่อเข้าใช้ และการลงชื่อเข้าใช้ [Enterprise SSO](/end-user-flows/enterprise-sso) แบบปกติจะข้ามการตั้งค่า MFA เว้นแต่จะร้องขอ MFA โดยตรงผ่าน `acr_values`

## กระบวนการตรวจสอบรหัสสำรอง \{#backup-codes-verification-flow}

รหัสสำรองทำหน้าที่เป็นการยืนยันตัวตนฉุกเฉินเมื่อปัจจัย MFA หลักไม่พร้อมใช้งาน โดยแต่ละรหัสใช้ได้เพียงครั้งเดียวและจะหมดอายุหลังจากตรวจสอบสำเร็จ

**ลำดับความสำคัญในการตรวจสอบ:**

- **ปัจจัยหลักมาก่อน**: เมื่อผู้ใช้ตั้งค่าปัจจัย MFA อื่นไว้แล้ว ระบบจะถามหาปัจจัยหลัก (passkey, TOTP, SMS, อีเมล) ก่อน
- **เข้าถึงรหัสสำรอง**: ผู้ใช้สามารถสลับไปใช้รหัสสำรองได้โดยคลิก "ลองวิธีอื่นในการยืนยัน" หากปัจจัยหลักไม่พร้อมใช้งาน
- **กรณีสำรอง**: หากปัจจัยหลักทั้งหมดถูกลบ รหัสสำรองจะกลายเป็นตัวเลือกเดียวในการตรวจสอบ หลังจากตรวจสอบ MFA ด้วยรหัสสำรองสำเร็จระหว่างการลงชื่อเข้าใช้ Logto จะเตือนผู้ใช้ให้ตั้งค่าปัจจัยหลักใหม่โดยอัตโนมัติ
