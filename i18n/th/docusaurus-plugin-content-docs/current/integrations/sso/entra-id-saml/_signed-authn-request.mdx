Microsoft Entra ID สามารถกำหนดให้ต้องมีการลงนามในคำขอการยืนยันตัวตน SAML (SAML authentication request) หากต้องการใช้งานร่วมกับ Logto ให้ดำเนินการตามลำดับนี้เพื่อหลีกเลี่ยงปัญหาการลงชื่อเข้าใช้:

1. ในแท็บ `Connection` ของตัวเชื่อมต่อ (Connector) Logto ให้คลิก **Generate new key** ใต้ **Request signing certificate** และดาวน์โหลดใบรับรอง (certificate) ของคีย์ที่ใช้งานอยู่
2. ในการตั้งค่า single sign-on ของแอป Entra ID ให้อัปโหลดใบรับรองดังกล่าวในส่วน **Verification certificates** ดูรายละเอียดที่ [Enforce signed SAML authentication requests](https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/howto-enforce-signed-saml-authentication)
3. กลับมาที่ Logto ให้เปิดใช้งาน **Sign authentication request** บนตัวเชื่อมต่อ (Connector) แล้วบันทึก
4. ที่ Entra ID ให้เลือก **Require verification certificates** จากนั้นทดสอบขั้นตอนการลงชื่อเข้าใช้

Entra ID จะตรวจสอบเฉพาะคำขอที่ลงนามด้วย RSA-SHA256 (อัลกอริทึมเริ่มต้นของ Logto) และบังคับใช้เฉพาะคำขอการลงชื่อเข้าใช้ที่เริ่มต้นโดย SP เท่านั้น สำหรับขั้นตอนการตั้งค่าทั้งหมดและการหมุนเวียนใบรับรอง ดูที่ [Sign the SAML authentication request](https://docs.logto.io/integrations/saml-sso#optional-sign-the-saml-authentication-request)
