# Console SSO

Console SSO ช่วยให้ทีมของคุณลงชื่อเข้าใช้ <Url href="https://cloud.logto.io">Logto Cloud Console</Url> ด้วยผู้ให้บริการข้อมูลระบุตัวตน (IdP) ของบริษัทคุณ เช่น Microsoft Entra ID, Okta หรือ Google Workspace สมาชิกที่คุณยืนยันโดเมนอีเมลจะถูกส่งไปยัง IdP ของคุณเมื่อพวกเขาลงชื่อเข้าใช้ Logto Cloud

Console SSO ครอบคลุมเฉพาะการลงชื่อเข้าใช้ Logto Cloud เท่านั้น หากต้องการให้ **ผู้ใช้ของคุณเอง** ลงชื่อเข้าใช้ **แอปพลิเคชันของคุณ** ด้วย IdP ของบริษัทของพวกเขา ให้ใช้ [Enterprise SSO](/connectors/enterprise-connectors) ใน tenant ของคุณแทน

## Console SSO ทำงานอย่างไร \{#how-console-sso-works}

- **Console SSO เป็นของบัญชีคุณ ไม่ใช่ tenant** ตัวเชื่อมต่อ Console SSO เป็นกรรมสิทธิ์ของบัญชี Logto Cloud ที่สร้างขึ้น และมีเพียงบัญชีนั้นเท่านั้นที่สามารถจัดการได้ แผน tenant, การลดระดับ หรือการลบ tenant จะไม่ส่งผลกระทบต่อมัน
- **Console SSO ไม่ได้ให้สิทธิ์เข้าถึง tenant** การลงชื่อเข้าใช้ด้วย SSO เป็นเพียงการพิสูจน์ตัวตนของบุคคลนั้น พวกเขายังต้องได้รับคำเชิญหรือเป็นสมาชิกเพื่อเปิด tenant ดู [การจัดการสมาชิก tenant](/logto-cloud/tenant-member-management)
- **Console SSO ถูกเรียกเก็บเงินกับบัญชีของคุณ** ตัวเชื่อมต่อจะถูกคิดค่าบริการต่อชิ้นผ่านการสมัครสมาชิกของคุณเอง แยกจากแผน tenant ใด ๆ ดู [ราคาและการเรียกเก็บเงิน](#pricing-and-billing)

## ตั้งค่า Console SSO \{#set-up-console-sso}

### สร้างตัวเชื่อมต่อ \{#create-a-connector}

1. ใน Logto Cloud Console เปิดเมนูผู้ใช้ที่มุมขวาบนแล้วเลือก **Single sign-on** หน้าของ <Url href="https://cloud.logto.io/console-sso">Console SSO</Url> จะเปิดในแท็บใหม่
2. คลิก **Add connector** และเลือกผู้ให้บริการข้อมูลระบุตัวตนของคุณ
3. สำหรับตัวเชื่อมต่อแรก เลือกบัญชีสำหรับเรียกเก็บเงินและชำระเงินผ่าน Stripe Checkout ตัวเชื่อมต่อถัดไปจะถูกเพิ่มเข้าไปในแผนเดียวกันโดยไม่ต้องชำระเงินใหม่
4. ตัวเชื่อมต่อจะเปิดที่หน้าการตั้งค่า

### กำหนดค่าการเชื่อมต่อ \{#configure-the-connection}

ในแท็บ **Connection** ให้กรอกค่าการตั้งค่าจาก IdP ของคุณ ฟิลด์จะเหมือนกับ [Enterprise SSO connectors](/connectors/enterprise-connectors) ใน tenant:

- **OIDC**: ลงทะเบียน **Redirect URI** ที่แสดงในหน้าใน IdP ของคุณ จากนั้นกรอก issuer, client ID และ client secret
- **SAML**: ให้ IdP ของคุณรับ metadata ของ service provider ที่แสดงในหน้า แล้วกรอก metadata ของ IdP ของคุณ

ในแท็บ **SSO Experience** คุณสามารถเปลี่ยนชื่อที่แสดงบนหน้าลงชื่อเข้าใช้ได้

### ยืนยันโดเมนอีเมลของคุณ \{#verify-your-email-domains}

Console SSO จะใช้ได้เฉพาะกับโดเมนอีเมลที่คุณพิสูจน์ความเป็นเจ้าของแล้วเท่านั้น

1. ในแท็บ **SSO Experience** กรอกโดเมน เช่น `example.com` แล้วคลิก **Add domain**
2. เพิ่ม TXT record ที่แสดงไปยังผู้ให้บริการ DNS ของคุณ:

   | Type | Name                           | Value               |
   | ---- | ------------------------------ | ------------------- |
   | TXT  | `_logto-cloud-sso.example.com` | โทเค็นที่แสดงในหน้า |

3. เปิดโดเมนค้างไว้ในหน้า Logto จะตรวจสอบ record ทุก ๆ 10 วินาที เมื่อพบ record แล้ว โดเมนจะถูกผูกกับตัวเชื่อมต่อและแสดงสถานะ **Bound** จากนั้นคุณสามารถลบ TXT record ได้

โดเมนหนึ่งสามารถผูกกับตัวเชื่อมต่อ Console SSO ได้เพียงตัวเดียวเท่านั้น การลบโดเมนที่ผูกไว้จะหยุด SSO สำหรับอีเมลในโดเมนนั้น การเพิ่มกลับต้องยืนยันใหม่

:::note
การเรียกเก็บเงินจะเริ่มทันทีที่สร้างตัวเชื่อมต่อ ไม่รอขั้นตอนนี้ ไม่ว่าคุณจะตั้งค่าการเชื่อมต่อหรือโดเมนเสร็จหรือไม่ก็ตาม
:::

### ลงชื่อเข้าใช้ด้วย SSO \{#sign-in-with-sso}

ในหน้าลงชื่อเข้าใช้ Logto Cloud สมาชิกจะกรอกอีเมลที่ทำงาน หากโดเมนนั้นถูกผูกกับตัวเชื่อมต่อ พวกเขาจะถูกส่งไปยัง IdP ของคุณเพื่อเข้าสู่ระบบ

## ราคาและการเรียกเก็บเงิน \{#pricing-and-billing}

ตัวเชื่อมต่อแต่ละตัวมีค่าใช้จ่าย **128 ดอลลาร์สหรัฐต่อเดือน** (ยังไม่รวมภาษีที่เกี่ยวข้อง) บัญชีของคุณจะมีการสมัครสมาชิก Console SSO หนึ่งรายการ และจำนวนคือจำนวนตัวเชื่อมต่อ

| เมื่อคุณ…                     | สิ่งที่เกิดขึ้น                                                                                             |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------- |
| เพิ่มตัวเชื่อมต่อแรก          | คุณชำระเงินสำหรับเดือนแรกใน Stripe Checkout วันที่ชำระเงินจะกลายเป็นวันเรียกเก็บเงินประจำเดือนของคุณ        |
| เพิ่มตัวเชื่อมต่อถัดไป        | ตัวเชื่อมต่อถูกเพิ่มทันที มีการคิดเงินตามสัดส่วนสำหรับเวลาที่เหลือของเดือนในใบแจ้งหนี้ถัดไป                 |
| ลบตัวเชื่อมต่อ (เหลือตัวอื่น) | มีเครดิตคืนตามสัดส่วนเวลาที่ไม่ได้ใช้ในใบแจ้งหนี้ถัดไป แต่จะไม่คืนเงินเข้าบัตรของคุณ                        |
| ลบตัวเชื่อมต่อสุดท้าย         | การสมัครสมาชิกจะถูกยกเลิกทันที หากเดือนปัจจุบันชำระเงินแล้ว เวลาที่ไม่ได้ใช้จะคืนเงินเข้าวิธีชำระเงินของคุณ |
| เพิ่มตัวเชื่อมต่อหลังยกเลิก   | การสมัครสมาชิกใหม่จะเริ่มต้นผ่าน Stripe Checkout พร้อมวันเรียกเก็บเงินใหม่                                  |

การแก้ไขการตั้งค่าหรือโดเมนของตัวเชื่อมต่อจะไม่เปลี่ยนแปลงค่าใช้จ่ายของคุณ

### ตัวอย่างใบแจ้งหนี้ \{#example-invoice}

ตัวเลขด้านล่างสมมติว่าเดือนละ 30 วัน และยังไม่รวมภาษี การคำนวณจริงจะคิดตามวินาที

| วันที่  | การดำเนินการ                           | ตัวเชื่อมต่อ | ผลกระทบ                                                       |
| ------- | -------------------------------------- | ------------ | ------------------------------------------------------------- |
| 1 พ.ย.  | เพิ่มตัวเชื่อมต่อแรก                   | 1            | ชำระเงินที่ checkout: **$128.00** วันเรียกเก็บเงินคือวันที่ 1 |
| 16 พ.ย. | เพิ่มตัวเชื่อมต่อที่สอง (เหลือ 15 วัน) | 2            | +$128 × 15/30 = +$64.00 ในใบแจ้งหนี้ถัดไป                     |
| 25 พ.ย. | ลบตัวเชื่อมต่อหนึ่ง (เหลือ 6 วัน)      | 1            | −$128 × 6/30 = −$25.60 ในใบแจ้งหนี้ถัดไป                      |
| 1 ธ.ค.  | ใบแจ้งหนี้ประจำเดือน                   | 1            | $128.00 สำหรับธันวาคม + $64.00 − $25.60 = **$166.40**         |
| 16 ธ.ค. | ลบตัวเชื่อมต่อสุดท้าย (เหลือ 15 วัน)   | 0            | การสมัครสมาชิกถูกยกเลิก; **$64.00** คืนเงิน                   |

### ประวัติการสมัครสมาชิกและการเรียกเก็บเงิน \{#subscription-and-billing-history}

เปิด **Subscription** ที่แถบด้านบนของ Console จะแสดงการสมัครสมาชิกของบัญชีคุณ ไม่ว่า tenant ไหนจะถูกเลือก

- **Subscription** แสดงการสมัครสมาชิกปัจจุบันพร้อมราคา, การเรียกเก็บเงินถัดไป และวันเรียกเก็บเงิน ใช้ **Manage payment** เพื่ออัปเดตวิธีชำระเงินหรือชำระใบแจ้งหนี้ที่ค้างอยู่
- **Billing history** แสดงใบแจ้งหนี้ทั้งหมด รวมถึงของการสมัครสมาชิกที่ถูกยกเลิก เลือกใบแจ้งหนี้เพื่อดูรายละเอียดและดาวน์โหลดใบแจ้งหนี้หรือใบเสร็จ

### การชำระเงินล่าช้า \{#overdue-payments}

หากการชำระเงินล้มเหลว Stripe จะลองใหม่และการสมัครสมาชิกจะถูกทำเครื่องหมายว่า **Past due** ตัวเชื่อมต่อของคุณยังคงใช้งานได้ แต่โปรดอัปเดตวิธีชำระเงินผ่าน **Manage payment**

หาก **ใบแจ้งหนี้รายเดือนติดต่อกันสามฉบับ** ยังไม่ได้ชำระและหมดรอบ retry แล้ว Logto จะหยุดการสมัครสมาชิกและ **ลบตัวเชื่อมต่อทั้งหมดของคุณ** ตัวเชื่อมต่อของผู้อื่นและ tenant ของคุณจะไม่ได้รับผลกระทบ ใบแจ้งหนี้ของคุณยังคงอยู่ในประวัติการเรียกเก็บเงิน

การชำระใบแจ้งหนี้ที่ค้างหลังจากนั้นจะไม่กู้คืนตัวเชื่อมต่อที่ถูกลบ หากต้องการใช้ Console SSO อีกครั้ง [ติดต่อเรา](https://logto.io/contact) เพื่อเคลียร์การสมัครสมาชิกที่หยุดไว้ แล้วเพิ่มตัวเชื่อมต่อใหม่เพื่อเริ่มต้นใหม่

## ลบตัวเชื่อมต่อหรือบัญชีของคุณ \{#delete-connectors-or-your-account}

หากต้องการลบตัวเชื่อมต่อ ให้เปิดจากหน้า Console SSO แล้วลบจากเมนูของมัน การลบตัวเชื่อมต่อสุดท้ายจะยกเลิกการสมัครสมาชิกตามที่อธิบายข้างต้น หากการสมัครสมาชิกค้างชำระ ให้ชำระใบแจ้งหนี้ก่อน

ก่อนที่คุณจะลบบัญชี Logto Cloud ของคุณ:

1. ลบตัวเชื่อมต่อ Console SSO ทั้งหมดของคุณ
2. ตรวจสอบให้แน่ใจว่าการสมัครสมาชิกของคุณถูกยกเลิกแล้ว
3. ชำระใบแจ้งหนี้ที่ค้างอยู่ทั้งหมด
