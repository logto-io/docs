# การตั้งค่า Tenant

ผู้ใช้ใหม่ที่ลงทะเบียน Logto Cloud จะได้รับการสร้าง tenant สภาพแวดล้อม **Development** (Dev) ฟรีโดยอัตโนมัติ คุณสามารถทดลองใช้ฟีเจอร์ทั้งหมดใน tenant นี้ได้

หากคุณต้องการสร้าง tenant แยกสำหรับสภาพแวดล้อม **Production** (Prod) หรือโปรเจกต์ใหม่ ให้คลิกชื่อ tenant ปัจจุบันของคุณที่มุมซ้ายบนของแถบด้านบน ในเมนูนี้ คุณสามารถสลับระหว่าง tenant หรือสร้าง tenant ใหม่ได้

คลิก "Create tenant" จากนั้น:

- ตั้งชื่อ tenant
- เลือก [ภูมิภาคข้อมูล tenant](#tenant-region)
- เลือก [ประเภท tenant](#tenant-types-dev-vs-prod) (สภาพแวดล้อม)

สำหรับ tenant ที่มีอยู่แล้ว ไปที่ <CloudLink to="/settings">Console > Tenant settings > Settings</CloudLink> ที่นี่คุณสามารถ:

- ดู tenant ID
- อัปเดตชื่อ tenant
- ดู [ภูมิภาค tenant](#tenant-region) (ไม่สามารถเปลี่ยนแปลงได้หลังจากสร้าง)
- ดู [ประเภท tenant](#tenant-types-dev-vs-prod) (คุณสามารถแปลง Dev tenant เป็น Prod tenant ได้หากต้องการ)
- [ออกจาก tenant](#leave-tenant)
- [ลบ tenant](#delete-tenant)

## ภูมิภาค tenant \{#tenant-region}

เมื่อคุณสร้าง tenant คุณสามารถเลือกภูมิภาคที่จัดเก็บข้อมูล tenant ได้ โดยไม่สามารถเปลี่ยนแปลงได้หลังจากสร้าง tenant แล้ว ภูมิภาคที่มีให้เลือก ได้แก่

- ยุโรป (เนเธอร์แลนด์)
- สหรัฐอเมริกาตะวันตก (แอริโซนา)
- ออสเตรเลีย (ออสเตรเลียตะวันออก)
- ญี่ปุ่น (ญี่ปุ่นตะวันออก)

โดยปกติ คุณควรเลือกภูมิภาคที่ใกล้กับลูกค้าของคุณมากที่สุด เพื่อลดความหน่วงและเพิ่มประสิทธิภาพ

Logto ใช้ประโยชน์จากเครือข่าย edge ทั่วโลกเพื่อมอบประสิทธิภาพและความพร้อมใช้งานที่ดีที่สุดสำหรับแอปของคุณ การกำหนดเส้นทางคำขอได้รับการปรับแต่งเพื่อให้แน่ใจว่าผู้ใช้ของคุณเชื่อมต่อกับตัวเลือกที่มีประสิทธิภาพสูงสุดเสมอ

:::note
กำลังมองหาภูมิภาคอื่น? [ติดต่อเรา](https://logto.io/contact) เพื่อ:

- ขอเพิ่มภูมิภาค public cloud ใหม่
- สอบถามเกี่ยวกับการติดตั้ง Logto Private Cloud ในสถานที่ที่คุณต้องการ
  :::

## ประเภท tenant: Dev กับ Prod \{#tenant-types-dev-vs-prod}

ใน Logto Cloud มี tenant สองประเภท: Development (Dev) และ Production (Prod) ด้วยการแยกประเภท tenant นี้ คุณสามารถจัดการโปรเจกต์ของคุณในแต่ละสภาพแวดล้อมได้อย่างมีประสิทธิภาพ และยังได้รับประโยชน์จาก Logto อย่างเต็มที่

คุณสามารถเลือกประเภท tenant ได้ขณะสร้าง เมื่อพร้อมใช้งานจริงสำหรับ production มีสองทางเลือก:

- **สร้าง Production tenant ใหม่**  
  ตั้งค่า tenant production ใหม่และกำหนดค่าตั้งแต่ต้น เหมาะสำหรับกรณีที่ต้องการแยกสภาพแวดล้อม development และ production อย่างชัดเจน
- **แปลง Dev tenant ปัจจุบันเป็น Production**  
  หากคุณไม่ต้องการตั้งค่าหรือย้ายผู้ใช้ใหม่ คุณสามารถอัปเกรด Dev tenant ที่มีอยู่เป็น Production tenant แบบชำระเงินได้

  - **แปลงเป็น Pro plan**: ไปที่ <CloudLink to="/tenant-settings/settings">Console > Tenant settings > Settings</CloudLink> แล้วคลิก "Convert" เพื่ออัปเกรดด้วยตนเอง ฟีเจอร์ที่ต้องชำระเงินที่คุณใช้ใน dev tenant จะถูกรวมใน Stripe checkout
  - **แปลงเป็น Enterprise plan**: [ติดต่อเรา](https://logto.io/contact) แล้วเราจะช่วยคุณดำเนินการอัปเกรด

  :::note
  เมื่อแปลงแล้ว tenant จะไม่สามารถเปลี่ยนกลับเป็นสภาพแวดล้อม Dev ได้ โปรดยืนยันว่าคุณพร้อมก่อนดำเนินการ
  :::

### Development \{#development}

tenant สำหรับ development (dev tenant) มีไว้สำหรับการทดสอบเป็นหลัก และไม่ควรใช้ในสภาพแวดล้อม production tenant เหล่านี้สามารถเข้าถึงฟีเจอร์พรีเมียมและฟีเจอร์ที่ต้องชำระเงินในแผนชำระเงินได้ฟรีโดยไม่ต้องสมัครสมาชิก

อย่างไรก็ตาม มีข้อจำกัดบางประการสำหรับ dev tenant:

- Dev tenant จะลบผู้ใช้ที่มีอายุเกิน 90 วันโดยอัตโนมัติ ดู [นโยบายการเก็บข้อมูล dev tenant](./dev-tenant-data-retention) สำหรับรายละเอียด
- มีแบนเนอร์แสดงระหว่างประสบการณ์การลงชื่อเข้าใช้ เพื่อระบุว่า tenant นี้อยู่ในโหมด development
- Dev tenant อาจมีข้อจำกัดโควต้าสำหรับฟีเจอร์บางอย่าง โดยอธิบายไว้ในหน้ารายละเอียดฟีเจอร์นั้น ๆ หากมี สำหรับรายการข้อจำกัด Dev plan ทั้งหมด โปรดดูที่หน้า [System limit](./system-limit)
- Logto อาจอัปเดตโควต้าของ dev tenant และจะพยายามแจ้งให้คุณทราบล่วงหน้า

### Production \{#production}

Production tenant คือที่ที่ผู้ใช้ปลายทางเข้าถึงแอปจริง และคุณอาจต้องมี [การสมัครสมาชิกแบบชำระเงิน](https://logto.io/pricing) คุณสามารถสมัครแผน Free หรือ Pro เพื่อสร้าง production tenant ได้ หากสมัครแผน Free จะสร้าง tenant ได้สูงสุด 10 รายการ

## เปิดใช้งาน MFA \{#enable-mfa}

เพิ่มความปลอดภัยให้ workspace ของคุณด้วยการบังคับใช้การยืนยันตัวตนหลายปัจจัย (MFA) สำหรับสมาชิกทุกคนใน Logto Pro/Enterprise tenant ของคุณ

เนื่องจากยังไม่สามารถเปิดใช้งานด้วยตนเองได้ โปรด [ติดต่อเรา](https://logto.io/contact) เพื่อเปิดใช้งานฟีเจอร์นี้

## เปิดใช้งาน Enterprise SSO \{#enable-enterprise-sso}

Logto Cloud รองรับการเชื่อมต่อ Single Sign-On สำหรับองค์กร (Enterprise SSO) สำหรับ tenant แผน Enterprise รวมถึงผู้ให้บริการอย่าง Google Workspace, Okta, Azure AD และอื่น ๆ

หากต้องการเริ่มต้น โปรด [ติดต่อเรา](https://logto.io/contact) เราจะช่วยคุณตั้งค่าอย่างรวดเร็ว

## ออกจาก tenant \{#leave-tenant}

ผู้ดูแลระบบสามารถ [เชิญสมาชิกเพิ่มเติม](/logto-cloud/tenant-member-management) มายัง tenant นี้ได้

หากมี **ผู้ดูแลระบบ** (บทบาท) อย่างน้อยหนึ่งคน หรือคุณเป็น **ผู้ร่วมมือ** หรือ **ผู้ชม** (บทบาท) คุณสามารถเลือกออกจาก tenant ได้ หลังจากออกแล้ว ทรัพยากรทั้งหมดใน tenant จะยังคงอยู่ แต่คุณจะไม่สามารถเข้าถึงได้อีก

หากคุณเป็นผู้ดูแลระบบคนสุดท้าย คุณต้องแต่งตั้งสมาชิกคนอื่นเป็นผู้ดูแลระบบก่อนจึงจะออกได้

## ลบ tenant \{#delete-tenant}

[ผู้ดูแลระบบ](/logto-cloud/tenant-member-management#invite-collaborators) สามารถลบ Logto tenant ได้ การลบ tenant จะลบข้อมูลผู้ใช้และการตั้งค่าทั้งหมดที่เกี่ยวข้องอย่างถาวร การดำเนินการนี้ไม่สามารถย้อนกลับได้ Logto จะขอให้คุณกรอกชื่อ tenant เพื่อยืนยันและช่วยป้องกันการลบโดยไม่ตั้งใจ

หากต้องการความช่วยเหลือ โปรด [ติดต่อเรา](https://logto.io/contact) ทางอีเมล

</details>
