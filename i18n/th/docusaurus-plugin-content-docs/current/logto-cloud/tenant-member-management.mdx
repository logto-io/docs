# การจัดการสมาชิกผู้เช่า (Tenant member management)

## เชิญผู้ร่วมงาน \{#invite-collaborators}

ไปที่ <CloudLink to="/tenant-settings/members">Console > การตั้งค่าผู้เช่า > สมาชิก</CloudLink> คุณจะเห็นสมาชิกปัจจุบันของคุณและสามารถเชิญเพิ่มได้ กรอกที่อยู่อีเมลและกำหนดบทบาท (สามารถทำแบบกลุ่มได้) จากนั้นกดส่ง

Logto ให้คุณเชิญสมาชิกทีมเข้าสู่ผู้เช่าของคุณใน Logto Cloud ได้ 3 บทบาท:

- **Admin:** เข้าถึงผู้เช่าได้เต็มรูปแบบ รวมถึงสมาชิกและการเรียกเก็บเงิน
- **Collaborator:** ดูและเปลี่ยนแปลงทรัพยากรของผู้เช่า เช่น แอปพลิเคชัน ผู้ใช้ ตัวเชื่อมต่อ และประสบการณ์การลงชื่อเข้าใช้ แต่ไม่สามารถจัดการสมาชิกหรือการเรียกเก็บเงินได้
- **Viewer:** ดูทรัพยากรและสมาชิกของผู้เช่าได้ แต่ไม่สามารถเปลี่ยนแปลงได้ ข้อมูลรับรองบางอย่างจะถูกซ่อนจาก viewer; ดู [สิ่งที่ viewer ไม่สามารถดูได้](#what-viewers-cannot-see)

### สิทธิ์ของแต่ละบทบาท \{#role-permissions}

| การกระทำ                                                                               | Admin | Collaborator | Viewer |
| -------------------------------------------------------------------------------------- | ----- | ------------ | ------ |
| ดูทรัพยากรและสมาชิกของผู้เช่า                                                          | ✅    | ✅           | ✅     |
| สร้าง เปลี่ยนแปลง และลบทรัพยากรของผู้เช่า                                              | ✅    | ✅           | ❌     |
| เชิญและลบสมาชิก เปลี่ยนบทบาท และดูคำเชิญ                                               | ✅    | ❌           | ❌     |
| เปลี่ยนชื่อหรือลบผู้เช่า                                                               | ✅    | ❌           | ❌     |
| แปลง Dev tenant เป็น Production                                                        | ✅    | ❌           | ❌     |
| เพิ่มหรือลบโดเมนที่กำหนดเองของผู้เช่าใน **การตั้งค่าผู้เช่า > โดเมน**                  | ✅    | ❌           | ❌     |
| บังคับใช้ MFA สำหรับสมาชิก                                                             | ✅    | ❌           | ❌     |
| ดูแท็บ **แผนและการเรียกเก็บเงิน** และ **ประวัติการเรียกเก็บเงิน** อัปเกรดหรือจัดการบิล | ✅    | ❌           | ❌     |
| [ออกจากผู้เช่า](/logto-cloud/tenant-settings#leave-tenant)                             | ✅    | ✅           | ✅     |

ใน Console ผู้ที่เป็น viewer จะเห็นป้าย **View only** และแบนเนอร์ ปุ่มที่ใช้สร้าง บันทึก ลบ หรือทดสอบจะถูกซ่อน และฟิลด์ทั้งหมดจะเป็นแบบอ่านอย่างเดียว

### สิ่งที่ viewer ไม่สามารถดูได้ \{#what-viewers-cannot-see}

viewer ไม่สามารถอ่านข้อมูลรับรองที่ให้สิทธิ์เข้าถึง Logto tenant หรือผู้ใช้ของคุณได้:

- รหัสลับของแอปพลิเคชัน (Application secrets)
- โทเค็นการเข้าถึงส่วนบุคคลของผู้ใช้ของคุณ
- โทเค็นใช้ครั้งเดียว
- แฮชรหัสผ่านผู้ใช้

ใน Console รหัสลับของแอปพลิเคชันและโทเค็นการเข้าถึงส่วนบุคคลจะแสดงเป็น **Hidden for viewers**

:::warning
viewer ยังสามารถอ่านข้อมูลลับอื่น ๆ ในการตั้งค่าผู้เช่าของคุณ เช่น ในการตั้งค่าตัวเชื่อมต่อและ enterprise SSO, คีย์ลับ CAPTCHA, คีย์ลงนาม webhook และ environment variables ของ custom JWT scripts และ Actions ได้ เชิญเป็น viewer เฉพาะเมื่อคุณไว้ใจบุคคลนั้นกับข้อมูลเหล่านี้
:::

### ขีดจำกัดจำนวนสมาชิก \{#members-limit}

| ประเภทผู้เช่า          | ขีดจำกัดจำนวนสมาชิก                         |
| ---------------------- | ------------------------------------------- |
| Dev tenant             | สูงสุด 3 คน (ติดต่อเราหากต้องการมากกว่านี้) |
| Free production tenant | 1 คน (admin เท่านั้น)                       |
| Pro production tenant  | รวม 1 คน จากนั้น $8 ต่อสมาชิกเพิ่มเติม      |

viewer จะถูกนับรวมในขีดจำกัดและราคาต่อสมาชิกเช่นเดียวกับสมาชิกอื่น ๆ

### จัดการคำเชิญ \{#manage-invitation}

แท็บคำเชิญจะแสดงคำเชิญที่ผ่านมาและสถานะของแต่ละรายการ

| สถานะ    | คำอธิบาย                               | การดำเนินการที่ทำได้ |
| -------- | -------------------------------------- | -------------------- |
| Pending  | ส่งคำเชิญแล้ว แต่ยังไม่ได้รับการตอบรับ | ส่งซ้ำ               |
| Accepted | ผู้ใช้กลายเป็นสมาชิกผู้เช่าแล้ว        | ลบ                   |
| Expired  | คำเชิญหมดอายุเกิน 7 วัน                | ลบ                   |
| Revoked  | ผู้ดูแลระบบยกเลิกคำเชิญ                | ลบ                   |

คุณไม่สามารถเชิญคนที่มีคำเชิญค้างอยู่หรือเป็นสมาชิกอยู่แล้ว

### จัดการสมาชิกผู้เช่า (Admin เท่านั้น) \{#manage-tenant-members-admin-only}

ในฐานะ admin คุณสามารถจัดการทีมของคุณได้หลายวิธี:

- **เชิญหรือลบสมาชิก:** เพิ่มสมาชิกทีมใหม่หรือลบการเข้าถึงตามต้องการ
- **เปลี่ยนบทบาทสมาชิก:** กำหนดบทบาท 'admin', 'collaborator' หรือ 'viewer' ตามระดับการเข้าถึงที่ต้องการ
- **โอนความเป็นเจ้าของผู้เช่า:** หากจำเป็น คุณสามารถโอนความเป็นเจ้าของผู้เช่าให้สมาชิกคนอื่นได้ โดยให้บทบาท admin กับสมาชิกคนนั้นก่อน แล้วเลือกว่าจะอยู่ต่อในฐานะสมาชิกทั่วไปหรือออกจากผู้เช่าเลย
- **เพิ่ม admin หลายคน:** แบ่งปันความรับผิดชอบด้านการจัดการกับสมาชิกทีมคนอื่นเพื่อการบริหารร่วมกัน
