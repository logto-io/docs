# Logto MCP Server

Logto MCP Server คือเซิร์ฟเวอร์ [MCP (Model Context Protocol)](https://modelcontextprotocol.io/) ระยะไกล เพิ่ม URL นี้ลงในแอป AI ของคุณ ลงชื่อเข้าใช้ด้วยบัญชี Logto Cloud ของคุณ แล้วเริ่มพูดคุยกับ Logto ได้เลย

:::tip
Logto MCP Server ถูกสร้างขึ้นด้วย Logto และ [MCP Auth](https://mcp-auth.dev) หากคุณต้องการสร้างเซิร์ฟเวอร์ MCP ระยะไกลของคุณเอง ดูที่ [สร้างเซิร์ฟเวอร์ MCP ระยะไกลของคุณเอง](#build-your-own-remote-mcp-server)
:::

## สิ่งที่คุณสามารถทำได้ \{#what-you-can-do}

- **เพิ่มการยืนยันตัวตนให้กับโปรเจกต์ของคุณ**: AI จะตรวจจับ framework ของคุณ สร้างแอป Logto และสร้างโค้ดสำหรับเชื่อมต่อที่ใช้งานได้จริง รองรับ framework มากกว่า 38 ตัว เช่น React, Next.js, Vue, Nuxt, SvelteKit, Express, Go, Python, iOS, Android, Flutter และอื่น ๆ
- **ถามคำถามเกี่ยวกับ Logto**: AI จะค้นหาข้อมูลจากเอกสาร Logto และให้คำตอบพร้อมแหล่งอ้างอิง

ฟีเจอร์เพิ่มเติมกำลังจะมาเร็ว ๆ นี้ เช่น การตั้งค่าประสบการณ์การลงชื่อเข้าใช้ การจัดการ RBAC และสิทธิ์ (permissions) พร้อมคำแนะนำแนวปฏิบัติที่ดีที่สุด การตั้งค่าหลายผู้เช่าสำหรับสร้างแอป B2B ด้วยองค์กร และอื่น ๆ

## วิธีที่แอป AI ของคุณเชื่อมต่อ \{#how-your-ai-application-connects}

Logto MCP Server รองรับ 2 วิธีที่แอป AI จะระบุตัวเองเมื่อคุณลงชื่อเข้าใช้ คุณไม่จำเป็นต้องสร้างอะไรใน Logto Cloud สำหรับทั้งสองวิธี

- **Server URL เท่านั้น (แนะนำ)**: แอป AI ส่วนใหญ่ในปัจจุบันรองรับ [client ID metadata documents (CIMD)](/integrate-logto/third-party-applications/dynamic-apps) แอปจะใช้ URL ที่เป็นเจ้าของเป็น client ID และ Logto จะอ่านชื่อแอปและ redirect URIs จาก URL นั้น คุณเพียงกรอก server URL `https://mcp.logto.io`
- **Static client ID**: สำหรับแอปที่ยังไม่รองรับ CIMD ให้กรอก public OAuth client ID `mcp-client` client นี้รองรับ loopback redirect URIs (`http://localhost` หรือ `http://127.0.0.1` พร้อมพอร์ตใดก็ได้)

หากแอปของคุณรองรับทั้งสองแบบ ให้ใช้ server URL เท่านั้น การเชื่อมต่อเดิมที่ใช้ `mcp-client` จะยังคงใช้งานได้ คุณไม่จำเป็นต้องเชื่อมต่อใหม่

เมื่อคุณเชื่อมต่อด้วย server URL เท่านั้น หน้า sign-in ของ Logto Cloud จะแสดงหน้าขอความยินยอม (consent screen) พร้อมชื่อแอปและ host ของ client ID URL เช่น `claude.ai` หรือ `vscode.dev` โปรดตรวจสอบว่า host ตรงกับแอปที่คุณใช้งานก่อนอนุญาต

## ตั้งค่าในแอป AI ของคุณ \{#set-up-in-your-ai-application}

### Amp \{#amp}

1. ใน [Amp](https://ampcode.com) เปิด **Personal Settings** > **Integrations & MCP** แล้วคลิก **Add MCP Server**
2. กรอกชื่อ `Logto MCP Server` และ server URL: `https://mcp.logto.io` Amp จะตรวจจับวิธีการยืนยันตัวตนโดยอัตโนมัติ
3. คลิก **Connect** และทำตามคำแนะนำของ Amp เพื่อเข้าสู่ระบบ
4. ลงชื่อเข้าใช้ด้วยบัญชี Logto Cloud ของคุณและอนุญาตการเชื่อมต่อ

:::tip
หาก Amp ค้างที่ **Detecting Authentication** เป็นเวลานาน ให้คลิก **Change** และเลือก **OAuth** เพื่อข้ามการตรวจจับอัตโนมัติ ปล่อย **OAuth Client ID** และ **OAuth Client Secret** ใน **Use Your Own OAuth App** ว่างไว้ จากนั้นคลิก **Connect** และทำตามคำแนะนำ Amp รองรับ CIMD คุณจึงไม่ต้องลงทะเบียน OAuth app หรือกรอก `mcp-client`
:::

### Claude Code \{#claude-code}

```bash
claude mcp add --transport http logto https://mcp.logto.io
```

จากนั้นรัน `/mcp` ใน Claude Code เลือก `logto` และทำตามขั้นตอนในเบราว์เซอร์เพื่อยืนยันตัวตนด้วยบัญชี Logto Cloud ของคุณ หรือจะรัน `claude mcp login logto` ใน shell ก็ได้

### Claude (เว็บและเดสก์ท็อป) \{#claude-web-and-desktop}

1. เปิด **Customize** > **Connectors** แล้วคลิก **Add custom connector**
2. กรอกชื่อ `Logto MCP Server` และ remote MCP server URL: `https://mcp.logto.io` ปล่อยการตั้งค่า OAuth ใน **Advanced settings** ว่างไว้ แล้วคลิก **Add**
3. ในรายการ **Connectors** หา **Logto MCP Server** แล้วคลิก **Connect**
4. คุณจะถูกเปลี่ยนไปยังหน้า sign-in ของ Logto Cloud ลงชื่อเข้าใช้ด้วยบัญชี Logto Cloud ของคุณและอนุญาตการเชื่อมต่อ

Connectors จะถูกบันทึกในบัญชี Claude ของคุณ จึงใช้งานได้ทั้ง Claude บนเว็บและ Claude Desktop

### Codex \{#codex}

```bash
codex mcp add logto --url https://mcp.logto.io
codex mcp login logto
```

จะมีหน้าต่างเบราว์เซอร์เปิดขึ้น ให้ลงชื่อเข้าใช้ด้วยบัญชี Logto Cloud ของคุณเพื่อเชื่อมต่อ แอป ChatGPT เดสก์ท็อป, Codex CLI และ Codex IDE extension ใช้การตั้งค่านี้ร่วมกัน

### Cursor \{#cursor}

Cursor ยังไม่รองรับ CIMD จึงใช้ static client ID

1. เปิด **Customize** > **MCPs** หรือเปิด `~/.cursor/mcp.json` (global) หรือ `.cursor/mcp.json` (project)
2. เพิ่มการตั้งค่าต่อไปนี้:

   ```json
   {
     "mcpServers": {
       "Logto": {
         "url": "https://mcp.logto.io",
         "auth": {
           "CLIENT_ID": "mcp-client",
           "scopes": ["mcp:all"]
         }
       }
     }
   }
   ```

3. คลิก **Connect** ข้างเซิร์ฟเวอร์ จะมีหน้า sign-in ของ Logto Cloud ปรากฏขึ้น ลงชื่อเข้าใช้ด้วยบัญชี Logto Cloud ของคุณเพื่อเชื่อมต่อ

ลงชื่อเข้าใช้จาก Cursor เดสก์ท็อปเท่านั้น Web callback ที่ใช้โดย Cursor บนเว็บและ Cursor Agents ยังไม่รองรับ

### OpenCode \{#opencode}

1. เพิ่มการตั้งค่าต่อไปนี้ในไฟล์ `opencode.json` ของคุณ:

   ```json
   {
     "$schema": "https://opencode.ai/config.json",
     "mcp": {
       "Logto": {
         "enabled": true,
         "type": "remote",
         "url": "https://mcp.logto.io"
       }
     }
   }
   ```

2. รันคำสั่งต่อไปนี้เพื่อยืนยันตัวตน:
   ```bash
   opencode mcp auth Logto
   ```
   หมายเหตุว่า `Logto` ต้องตรงกับชื่อ MCP server ในไฟล์ config ของคุณ

จะมีหน้าต่างเบราว์เซอร์เปิดขึ้น ลงชื่อเข้าใช้ด้วยบัญชี Logto Cloud ของคุณเพื่ออนุญาตและเชื่อมต่อ

### VS Code \{#vs-code}

1. เปิด command palette (`Command + Shift + P`) แล้วเลือก **MCP: Add Server...**
2. เลือก **HTTP** เป็นประเภทเซิร์ฟเวอร์
3. กรอก URL: `https://mcp.logto.io` คุณสามารถเลือกติดตั้งใน workspace เพื่อแยกและจัดการได้ง่ายขึ้น
4. เมื่อ VS Code ขอให้ยืนยันตัวตน ให้อนุญาต จะถูกเปลี่ยนไปยังหน้า sign-in ของ Logto Cloud ลงชื่อเข้าใช้ด้วยบัญชี Logto Cloud ของคุณเพื่อเชื่อมต่อ

หรือจะเพิ่มเซิร์ฟเวอร์ใน `.vscode/mcp.json` หรือ `mcp.json` ของผู้ใช้ก็ได้:

```json
{
  "servers": {
    "logto": {
      "type": "http",
      "url": "https://mcp.logto.io"
    }
  }
}
```

### Windsurf \{#windsurf}

Windsurf ยังไม่มีเอกสารรองรับ CIMD ให้ใช้ [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) กับ static client ID

1. เปิด command palette (`Command + Shift + P`) แล้วเลือก **Windsurf: MCP Marketplace**
2. ในส่วน **Installed MCPs** คลิกไอคอนตั้งค่าทางขวาเพื่อเปิดไฟล์ config MCP
3. เพิ่ม [การตั้งค่านี้](https://docs.windsurf.com/windsurf/cascade/mcp#mcp_config-json):

   ```json
   {
     "mcpServers": {
       "Logto": {
         "command": "npx",
         "args": [
           "mcp-remote",
           "https://mcp.logto.io",
           "--allow-http",
           "--static-oauth-client-info",
           "{ \"client_id\": \"mcp-client\", \"scope\": \"mcp:all\" }",
           "--resource",
           "https://mcp.logto.io/"
         ]
       }
     }
   }
   ```

หน้าลงชื่อเข้าใช้ Logto Cloud จะปรากฏขึ้นโดยอัตโนมัติ ลงชื่อเข้าใช้ด้วยบัญชี Logto Cloud ของคุณเพื่อเชื่อมต่อ

### ลูกค้า MCP อื่น ๆ \{#other-mcp-clients}

Logto MCP Server ใช้งานได้กับลูกค้า MCP ใด ๆ ที่รองรับ OAuth authorization (โทเค็นการอนุญาต):

- **ถ้าลูกค้าของคุณรองรับ CIMD**: กรอกเพียง MCP server URL `https://mcp.logto.io` ลูกค้าจะค้นหาข้อมูลอื่น ๆ จากเซิร์ฟเวอร์เอง
- **หากไม่รองรับ**: ใช้การตั้งค่าต่อไปนี้
  - **MCP server URL:** `https://mcp.logto.io`
  - **OAuth client ID:** `mcp-client` (ไม่ต้องใช้ client secret)
  - **Redirect URI:** loopback address เช่น `http://localhost:<port>/callback`
  - **Resource:** `https://mcp.logto.io/` (ถ้าลูกค้าต้องการ)
  - **Scope:** `mcp:all` (ถ้าลูกค้าต้องการ)

Logto MCP Server ไม่รองรับ Dynamic Client Registration (DCR) หากคุณเป็นนักพัฒนาแอป AI [เผยแพร่ client ID metadata document](/integrate-logto/third-party-applications/dynamic-apps#publish-a-client-id-metadata-document) สำหรับแอปของคุณ แล้วจะเชื่อมต่อได้โดยไม่ต้องตั้งค่าใด ๆ ใน Logto หากทำไม่ได้ [ติดต่อเรา](https://logto.io/contact) พร้อมรายละเอียดแอปของคุณ

## สร้างเซิร์ฟเวอร์ MCP ระยะไกลของคุณเอง \{#build-your-own-remote-mcp-server}

Logto MCP Server ถูกสร้างขึ้นด้วย Logto และ [MCP Auth](https://mcp-auth.dev) หากคุณต้องการสร้างเซิร์ฟเวอร์ MCP ระยะไกลของคุณเองพร้อมการยืนยันตัวตน ดูแหล่งข้อมูลต่อไปนี้:

- [Remote MCP server in action: a new entry point for SaaS products in the AI era](https://blog.logto.io/remote-mcp-server-in-action)
- [เข้าร่วม Discord ของเรา](https://discord.gg/fUQmaFyAam): แบ่งปันประสบการณ์และแนวปฏิบัติที่ดีที่สุดในการสร้างเซิร์ฟเวอร์ MCP ระยะไกล
- [MCP Auth](https://mcp-auth.dev): ทุกอย่างที่คุณต้องการเพื่อเพิ่มการยืนยันตัวตนระดับ production ให้กับ MCP server ของคุณ ไม่ต้องเสียเวลาหลายสัปดาห์อ่านสเปกหรือเชื่อมโยงระบบเอง
