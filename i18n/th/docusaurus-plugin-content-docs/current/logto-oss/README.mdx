# Logto OSS

Logto มีทั้งเวอร์ชันโอเพ่นซอร์ส (OSS) และ [Cloud](/logto-cloud) ส่วนนี้จะเน้นที่โซลูชัน OSS: <Url href="https://github.com/logto-io/logto">github.com/logto-io/logto</Url>

Logto OSS เป็นโซลูชันระบุตัวตนที่ใช้ฟรี ให้ความสามารถในการปรับแต่งได้อย่างเต็มที่และควบคุมข้อมูลของคุณเองได้ทั้งหมด Logto OSS มีความยืดหยุ่นในการปรับแต่งโค้ดให้ตรงกับความต้องการเฉพาะ เหมาะสำหรับผู้ที่ให้ความสำคัญกับอธิปไตยข้อมูล (data sovereignty) และต้องการโซลูชันผู้ให้บริการข้อมูลระบุตัวตนที่ปรับแต่งได้และเติบโตไปพร้อมกับแอปพลิเคชันของคุณ

## ฟีเจอร์ที่รองรับโดย Logto OSS \{#feature-supported-by-logto-oss}

Logto OSS รองรับความสามารถหลักส่วนใหญ่ของบริการ Logto และมีการอัปเดตและดูแลอย่างสม่ำเสมอ

ฟีเจอร์ขั้นสูงบางอย่างมีเฉพาะในเวอร์ชัน Logto Cloud ได้แก่:

| ข้อจำกัดของฟีเจอร์ใน OSS                                                            | คำอธิบาย                                                                                                                                     |
| ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| [Logto console: หลาย tenant](/logto-cloud/tenant-settings)                          | สร้างและจัดการหลาย tenant ของ Logto ใน console                                                                                               |
| [Logto console: เชิญผู้ร่วมงาน](/logto-cloud/tenant-member-management)              | เชิญและจัดการสมาชิกหลายคนใน tenant เดียวของ Logto                                                                                            |
| Logto console: เปิดใช้งาน MFA                                                       | เพิ่มความปลอดภัยโดยบังคับใช้การยืนยันตัวตนหลายปัจจัย (MFA) เมื่อเข้าสู่ Logto Console                                                        |
| [Logto Protected App](/integrate-logto/protected-app)                               | การผสานการยืนยันตัวตนแบบรวดเร็วโดยไม่ต้องใช้ SDK ด้วย Cloudflare                                                                             |
| [Logto built-in email service](/connectors/email-connectors/built-in-email-service) | ใช้บริการอีเมลในตัวและฟรีสำหรับการส่งอีเมล                                                                                                   |
| [Bring your UI](/customization/bring-your-ui)                                       | ปรับแต่ง UI หรือ flow ของประสบการณ์การลงชื่อเข้าใช้ด้วยฟีเจอร์นี้ (OSS สามารถ fork โค้ดบน GitHub เพื่อปรับแต่งประสบการณ์ลงชื่อเข้าใช้โดยตรง) |
| [IdP-initiated SSO](/end-user-flows/enterprise-sso/idp-initiated-sso)               | เปิดใช้งาน enterprise SSO ที่เริ่มต้นโดยผู้ให้บริการข้อมูลระบุตัวตน (IdP)                                                                    |
| [SAML apps](/integrate-logto/saml-app)                                              | ผสานแอปพลิเคชันผ่านโปรโตคอล SAML เวอร์ชัน OSS จำกัดที่ 3 SAML apps                                                                           |
| [ซ่อนแบรนด์ Logto](/customization/match-your-brand#hide-logto-branding)             | ลบเครื่องหมาย "Powered by Logto" ออกจากประสบการณ์การลงชื่อเข้าใช้                                                                            |

เคล็ดลับ: Multi-tenancy, การเชิญสมาชิก, และ MFA จะไม่พร้อมใช้งานสำหรับทีมของคุณในการลงชื่อเข้าใช้ Logto console แบบโอเพ่นซอร์ส อย่างไรก็ตาม คุณสามารถนำฟีเจอร์เหล่านี้ไปใช้ในผลิตภัณฑ์ของคุณเองด้วย Logto OSS เพื่อให้ผู้ใช้ปลายทางของคุณใช้งานได้

การเชิญผู้ร่วมงานใน Console, การบังคับใช้ MFA ใน Console, Bring your UI, การซ่อนแบรนด์ Logto และ SAML apps ไม่จำกัด สามารถปลดล็อกได้ด้วย [self-hosted license](/logto-oss/self-hosted-license)
