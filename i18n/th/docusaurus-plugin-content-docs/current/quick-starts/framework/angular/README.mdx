# เพิ่มการยืนยันตัวตนให้กับแอป Angular ของคุณ (Add authentication to your Angular application)

คู่มือนี้จะแสดงวิธีการผสานรวม Logto Angular SDK v2 เข้ากับแอปพลิเคชันของคุณ

<GuideTip />

## ข้อกำหนดเบื้องต้น \{#prerequisites}

- บัญชี [Logto Cloud](https://cloud.logto.io) หรือ [Logto แบบโฮสต์เอง](/introduction/set-up-logto-oss)
- แอปพลิเคชันหน้าเดียว (SPA) ที่สร้างใน Logto Console
- โปรเจกต์ Angular 20
