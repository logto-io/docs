Logto มีแม่แบบสำหรับปรับแต่งเนื้อหาอีเมลในแต่ละกรณีการใช้งานที่แตกต่างกัน

ขอแนะนำอย่างยิ่งให้คุณใช้แม่แบบที่แตกต่างกันในแต่ละสถานการณ์ มิฉะนั้นผู้ใช้อาจได้รับเนื้อหาอีเมลที่ไม่ตรงกับการดำเนินการปัจจุบัน ทำให้เกิดความสับสน หากมีแม่แบบที่ขาดหายและไม่ได้กำหนดค่า อาจทำให้เกิดข้อผิดพลาดใน flow ที่ต้องพึ่งพาแม่แบบนั้นและส่งผลต่อการพัฒนาธุรกิจตามปกติ

## ตัวเลือกการปรับแต่งแม่แบบอีเมล \{#email-template-customization-options}

Logto มี 3 วิธีหลักสำหรับการจัดการแม่แบบอีเมล:

1. **ปรับแต่งแม่แบบใน Logto**

   - **ตัวเชื่อมต่อ (Connectors)**:
     - [SMTP](/integrations/smtp)
     - [SendGrid](/integrations/sendgrid-email)
     - [Mailgun](/integrations/mailgun)
     - [AWS Direct Mail](/integrations/aws-ses)
     - [Aliyun Direct Mail](/integrations/aliyun-dm)
   - **ความสามารถ**:
     - ✅ แทรกตัวแปรหลากหลายลงในแม่แบบได้อย่างยืดหยุ่น
     - ✅ สร้างแม่แบบหลายภาษาแบบกำหนดเองผ่าน Management APIs
     - ✅ แก้ไขแม่แบบได้เต็มรูปแบบภายใน Logto

2. **ปรับแต่งแม่แบบในแพลตฟอร์มผู้ให้บริการ**

   - **ตัวเชื่อมต่อ (Connectors)**:
     - [Postmark](/integrations/postmark)
     - [HTTP Email](/integrations/http-email)
   - **ความสามารถ**:
     - ✅ ส่งตัวแปรไปยังแพลตฟอร์มผู้ให้บริการ
     - ✅ ส่งพารามิเตอร์ `locale` ไปยังแพลตฟอร์มผู้ให้บริการเพื่อรองรับหลายภาษา
     - ✅ แก้ไขแม่แบบได้เต็มรูปแบบในแดชบอร์ดของผู้ให้บริการ (ใช้ Logto Management APIs)

3. **แม่แบบสำเร็จรูป (ไม่สามารถปรับแต่งได้)**

   - **ตัวเชื่อมต่อ (Connector)**:
     - [Logto Built-in Email Service](/connectors/email-connectors/built-in-email-service)
   - **ความสามารถ**:
     - ✅ รองรับตัวแปรโดยตรง
     - ✅ แม่แบบหลายภาษา
     - ❌ ไม่สามารถแก้ไขแม่แบบ / UI ได้

## ตัวแปรในแม่แบบอีเมล \{#email-template-variables}

### Code \{#code}

รหัสยืนยันที่ผู้ใช้ต้องกรอกเพื่อดำเนินการยืนยันให้เสร็จสมบูรณ์ ใช้ได้ในแม่แบบ `SignIn`, `Register`, `ForgotPassword`, `Generic`, `UserPermissionValidation` และ `BindNewIdentifier`

- รหัสยืนยันจะหมดอายุใน 10 นาที ขณะนี้ยังไม่รองรับการปรับแต่งระยะเวลาหมดอายุของรหัสยืนยัน
- ต้องเว้นที่ว่าง `{{code}}` ในแม่แบบ เมื่อส่งรหัสยืนยัน ระบบจะนำรหัสที่สร้างแบบสุ่มมาแทนที่ก่อนส่งอีเมลถึงผู้ใช้

### ApplicationInfo \{#applicationinfo}

ข้อมูลสาธารณะของแอปพลิเคชันที่ผู้ใช้กำลังโต้ตอบด้วย ใช้ได้ในแม่แบบ `SignIn`, `Register`, `ForgotPassword`, `UserPermissionValidation` และ `BindNewIdentifier`

```ts
type ApplicationInfo = {
  id: string;
  name: string;
  displayName?: string;
  branding?: {
    logoUrl?: string;
    darkLogoUrl?: string;
    favicon?: string;
    darkFavicon?: string;
  };
};
```

- สามารถเข้าถึงฟิลด์ย่อยทั้งหมดของ application info ในแม่แบบผ่าน dot notation เช่น `{{application.name}}` จะถูกแทนที่ด้วยชื่อแอปจริงจากการตั้งค่าของคุณ
- หากไม่ได้ส่งตัวแปร `application` หลักมา ตัวแปร handlebars จะถูกละเว้นและไม่ถูกแทนที่
- หาก object `application` ที่ส่งมาไม่มีฟิลด์ที่ต้องการหรือค่าเป็น undefined ตัวแปร handlebars จะถูกแทนที่ด้วยสตริงว่าง เช่น `{{application.foo.bar}}` จะถูกแทนที่ด้วย ``

### OrganizationInfo \{#organizationinfo}

ข้อมูลสาธารณะขององค์กรที่ผู้ใช้กำลังโต้ตอบด้วย

```ts
type OrganizationInfo = {
  id: string;
  name: string;
  branding?: {
    logoUrl?: string;
    darkLogoUrl?: string;
    favicon?: string;
    darkFavicon?: string;
  };
};
```

- สำหรับแม่แบบ `SignIn`, `Register` และ `ForgotPassword` ตัวแปร `organization` เป็นตัวเลือก จะมีให้เฉพาะเมื่อมีพารามิเตอร์ `organization_id` ในคำขอการอนุญาต ดู [การตั้งค่าแบรนด์เฉพาะองค์กร](/customization/match-your-brand#organization-specific-branding) สำหรับรายละเอียดเพิ่มเติม
- สำหรับแม่แบบ `OrganizationInvitation` ตัวแปร `organization` จำเป็นต้องมี

### UserInfo \{#userinfo}

ข้อมูลสาธารณะของผู้ใช้ที่อีเมลถูกส่งถึง ใช้ได้ในแม่แบบ `UserPermissionValidation`, `BindNewIdentifier` และ `OrganizationInvitation`

```ts
type UserInfo = {
  id: string;
  name?: string;
  username?: string;
  primaryEmail?: string;
  primaryPhone?: string;
  avatar?: string;
  profile?: Profile;
};
```

- ดู [profile](/user-management/user-data#profile) สำหรับรายละเอียดเพิ่มเติมเกี่ยวกับชนิด `Profile`
- ตัวแปร `user` จำเป็นสำหรับแม่แบบ `UserPermissionValidation` และ `BindNewIdentifier`
- ตัวแปร `inviter` เป็นตัวเลือกสำหรับแม่แบบ `OrganizationInvitation` จะมีให้เฉพาะเมื่อมี `inviterId` ในคำขอเชิญองค์กร

### UI Locales \{#ui-locales}

ค่าต้นฉบับของ `ui_locales` ที่ให้มาในคำขอการยืนยันตัวตน OIDC ที่เริ่มต้นการโต้ตอบปัจจุบัน

- ชนิด: `string` (รายการ tag ภาษา BCP 47 คั่นด้วยช่องว่าง ตามสเปค OIDC) เช่น `"fr-CA fr en"`
- การมีอยู่: จะมีเมื่อการโต้ตอบ sign-in ปัจจุบันถูกเริ่มด้วย `ui_locales` หากไม่ได้ให้มาจะละเว้นตัวแปรนี้
- การใช้งานทั่วไป: ใส่ในเนื้อหาอีเมลหรือหัวเรื่องเพื่อบันทึกภาษาที่ผู้ใช้ร้องขอสำหรับการรองรับ i18n หรือการตรวจสอบ เช่น `Requested languages: {{uiLocales}}`
