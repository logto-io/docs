# Gestion des membres du tenant

## Inviter des collaborateurs \{#invite-collaborators}

Allez dans <CloudLink to="/tenant-settings/members">Console > Paramètres du tenant > Membres</CloudLink>. Vous verrez vos membres actuels et pourrez en inviter d'autres. Saisissez les adresses e-mail et attribuez des rôles (vous pouvez le faire en masse), puis envoyez.

Logto vous permet d'inviter des membres de l'équipe sur votre tenant avec deux rôles différents dans Logto Cloud :

- **Admin :** Accès complet et gestion de toutes les ressources du tenant.
- **Collaborateur :** Peut gérer les ressources liées à l'identité, mais avec des limitations :
  - Pas d'accès aux informations de facturation
  - Ne peut pas inviter ou gérer d'autres membres
  - Ne peut pas changer le nom du tenant
  - Ne peut pas supprimer le tenant

### Limite de membres \{#members-limit}

| Type de tenant               | Limite de membres                                   |
| ---------------------------- | --------------------------------------------------- |
| Tenant de développement      | Jusqu'à 3 membres (contactez-nous pour plus)        |
| Tenant de production gratuit | 1 membre (admin uniquement)                         |
| Tenant de production Pro     | 1 membre inclus, puis 8 $ par membre supplémentaire |

### Gérer les invitations \{#manage-invitation}

L'onglet d'invitation affiche les invitations passées avec leur statut

| Statut     | Explication                                    | Action disponible |
| ---------- | ---------------------------------------------- | ----------------- |
| En attente | Invitation envoyée, mais pas encore acceptée.  | Renvoyer          |
| Acceptée   | L'utilisateur est maintenant membre du tenant. | Supprimer         |
| Expirée    | L'invitation a dépassé la limite de 7 jours.   | Supprimer         |
| Révoquée   | L'admin a annulé l'invitation.                 | Supprimer         |

Vous ne pouvez pas inviter des personnes qui ont déjà des invitations en attente ou qui sont membres.

### Gérer les membres du tenant (Admin uniquement) \{#manage-tenant-members-admin-only}

En tant qu'admin, vous disposez de plusieurs moyens pour gérer votre équipe :

- **Inviter ou supprimer des membres :** Ajoutez de nouveaux membres à l'équipe ou retirez l'accès si nécessaire.
- **Changer les rôles des membres :** Attribuez les rôles 'admin' ou 'collaborateur' selon le niveau d'accès requis.
- **Transférer la propriété du tenant :** Si besoin, vous pouvez transférer la propriété du tenant à un autre membre. Vous pouvez d'abord donner le rôle d'admin à un autre membre, puis choisir de rester membre régulier ou de quitter complètement le tenant.
- **Ajouter plusieurs admins :** Partagez les responsabilités administratives avec d'autres membres de l'équipe pour une gestion collaborative.
