# Gestion des membres du tenant

## Inviter des collaborateurs \{#invite-collaborators}

Allez dans <CloudLink to="/tenant-settings/members">Console > Paramètres du tenant > Membres</CloudLink>. Vous verrez vos membres actuels et pourrez en inviter d'autres. Saisissez les adresses e-mail et attribuez des rôles (vous pouvez le faire en masse), puis envoyez.

Logto vous permet d'inviter des membres de l'équipe à votre tenant avec trois rôles différents dans Logto Cloud :

- **Admin :** Accès complet au tenant, y compris à ses membres et à la facturation.
- **Collaborateur :** Peut voir et modifier les ressources du tenant, telles que les applications, les utilisateurs, les connecteurs et l'expérience de connexion, mais ne peut pas gérer les membres ni la facturation.
- **Lecteur :** Peut voir les ressources et les membres du tenant, mais ne peut pas les modifier. Certains identifiants sont masqués pour les lecteurs ; voir [Ce que les lecteurs ne peuvent pas voir](#what-viewers-cannot-see).

### Permissions des rôles \{#role-permissions}

| Action                                                                                                             | Admin | Collaborateur | Lecteur |
| ------------------------------------------------------------------------------------------------------------------ | ----- | ------------- | ------- |
| Voir les ressources et les membres du tenant                                                                       | ✅    | ✅            | ✅      |
| Créer, modifier et supprimer les ressources du tenant                                                              | ✅    | ✅            | ❌      |
| Inviter et supprimer des membres, changer leurs rôles, et voir les invitations                                     | ✅    | ❌            | ❌      |
| Renommer ou supprimer le tenant                                                                                    | ✅    | ❌            | ❌      |
| Convertir un tenant Dev en Production                                                                              | ✅    | ❌            | ❌      |
| Ajouter ou supprimer les domaines personnalisés du tenant dans **Paramètres > Domaines**                           | ✅    | ❌            | ❌      |
| Exiger MFA pour les membres                                                                                        | ✅    | ❌            | ❌      |
| Voir les onglets **Plan et facturation** et **Historique de facturation**, mettre à niveau ou gérer la facturation | ✅    | ❌            | ❌      |
| [Quitter le tenant](/logto-cloud/tenant-settings#leave-tenant)                                                     | ✅    | ✅            | ✅      |

Dans la Console, les lecteurs voient une étiquette **Lecture seule** et une bannière. Les boutons permettant de créer, sauvegarder, supprimer ou tester sont masqués, et les champs sont en lecture seule.

### Ce que les lecteurs ne peuvent pas voir \{#what-viewers-cannot-see}

Les lecteurs ne peuvent pas lire les identifiants qui donnent accès à votre tenant Logto ou à ses utilisateurs :

- Secrets d'application
- Jetons d’accès personnels de vos utilisateurs
- Jetons à usage unique
- Hashs de mots de passe utilisateur

Dans la Console, les secrets d'application et les jetons d’accès personnels s'affichent comme **Masqué pour les lecteurs**.

:::warning
Les lecteurs peuvent toujours lire d'autres secrets dans les paramètres de votre tenant, tels que ceux dans les configurations de connecteur et de connecteur SSO d’entreprise, les clés secrètes CAPTCHA, les clés de signature de webhook, et les variables d'environnement des scripts JWT personnalisés et des Actions. N'invitez quelqu'un en tant que lecteur que si vous lui faites confiance pour ces éléments.
:::

### Limite de membres \{#members-limit}

| Type de tenant         | Limite de membres                                   |
| ---------------------- | --------------------------------------------------- |
| Tenant Dev             | Jusqu'à 3 membres (contactez-nous pour plus)        |
| Tenant production Free | 1 membre (admin uniquement)                         |
| Tenant production Pro  | 1 membre inclus, puis 8 $ par membre supplémentaire |

Les lecteurs comptent dans la limite et dans le prix par membre comme tout autre membre.

### Gérer les invitations \{#manage-invitation}

L'onglet des invitations affiche les invitations passées avec leur statut

| Statut     | Explication                                    | Action disponible |
| ---------- | ---------------------------------------------- | ----------------- |
| En attente | Invitation envoyée, mais pas encore acceptée.  | Renvoyer          |
| Acceptée   | L'utilisateur est maintenant membre du tenant. | Supprimer         |
| Expirée    | L'invitation a dépassé la limite de 7 jours.   | Supprimer         |
| Révoquée   | L'admin a annulé l'invitation.                 | Supprimer         |

Vous ne pouvez pas inviter des personnes qui ont déjà une invitation en attente ou qui sont membres.

### Gérer les membres du tenant (Admin uniquement) \{#manage-tenant-members-admin-only}

En tant qu'admin, vous disposez de plusieurs moyens pour gérer votre équipe :

- **Inviter ou supprimer des membres :** Ajoutez de nouveaux membres à l'équipe ou retirez l'accès si nécessaire.
- **Changer les rôles des membres :** Attribuez les rôles 'admin', 'collaborateur' ou 'lecteur' selon le niveau d'accès requis.
- **Transférer la propriété du tenant :** Si besoin, vous pouvez transférer la propriété du tenant à un autre membre. Vous pouvez d'abord donner le rôle d'admin à un autre membre puis choisir de rester comme membre régulier ou de quitter complètement le tenant.
- **Ajouter plusieurs admins :** Partagez les responsabilités administratives avec d'autres membres de l'équipe pour une gestion collaborative.
