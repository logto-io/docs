Initialisez le client en créant une instance de `LogtoClient` avec un objet `LogtoConfig`.

```swift title="ContentView.swift"
import Logto
import LogtoClient

let config = try! LogtoConfig(
  endpoint: "<your-logto-endpoint>", // Par exemple : http://localhost:3001
  appId: "<your-app-id>"
)
let client = LogtoClient(useConfig: config)
```

:::info

Par défaut, nous stockons les identifiants tels que le Jeton d’identifiant (ID Token) et le Jeton de rafraîchissement (Refresh Token) dans le Trousseau. Ainsi, l'utilisateur n'a pas besoin de se reconnecter à son retour.

Pour désactiver ce comportement, définissez `usingPersistStorage` sur `false` :

```swift
let config = try! LogtoConfig(
  // ...
  usingPersistStorage: false
)
```

:::
