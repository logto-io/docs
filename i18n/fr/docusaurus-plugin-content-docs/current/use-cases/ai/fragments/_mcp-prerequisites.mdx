## Prérequis \{#prerequisites}

- Un tenant [Logto Cloud](https://cloud.logto.io) (ou auto-hébergé)
- Environnement Node.js >= 20

### Comprendre l’architecture \{#understanding-the-architecture}

- **Serveur MCP** : Le serveur qui expose des outils et des ressources aux clients MCP. Conformément à la [dernière spécification MCP](https://modelcontextprotocol.io/specification/latest/basic/authorization), il agit en tant que serveur de ressources OAuth 2.0 qui valide les jetons d’accès émis par Logto.
- **Client MCP** : Un client utilisé pour initier le flux d’authentification et tester l’intégration. {<b>{props.isThirdParty ? 'L’agent IA tiers sera utilisé comme client dans ce guide.' : "Nous utiliserons VS Code (avec le support MCP intégré) comme client dans ce guide."}</b>}
- **Logto** : Sert de fournisseur OpenID Connect (serveur d’autorisation), gère les identités des utilisateurs et émet des jetons d’accès JWT liés à l’audience pour votre serveur MCP.

Un diagramme de séquence non normatif illustre le déroulement global du processus :
