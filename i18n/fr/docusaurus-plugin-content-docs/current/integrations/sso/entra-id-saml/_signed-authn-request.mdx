Microsoft Entra ID peut exiger des requêtes d’authentification SAML signées. Pour utiliser cela avec Logto, suivez cet ordre afin d’éviter toute interruption de connexion :

1. Dans l’onglet `Connection` du connecteur Logto, cliquez sur **Générer une nouvelle clé** sous **Certificat de signature de requête**, puis téléchargez le certificat de la clé active.
2. Dans les paramètres d’authentification unique de l’application Entra ID, téléversez le certificat sous **Certificats de vérification**. Voir [Appliquer les requêtes d’authentification SAML signées](https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/howto-enforce-signed-saml-authentication).
3. De retour dans Logto, activez **Signer la requête d’authentification** sur le connecteur et enregistrez.
4. Dans Entra ID, cochez **Exiger des certificats de vérification**, puis testez le flux de connexion.

Entra ID ne vérifie que les requêtes signées avec RSA-SHA256 (l’algorithme par défaut de Logto), et applique l’exigence pour les requêtes de connexion initiées par le fournisseur de services (SP). Pour la configuration complète et le processus de rotation du certificat, consultez [Signer la requête d’authentification SAML](https://docs.logto.io/integrations/saml-sso#optional-sign-the-saml-authentication-request).
