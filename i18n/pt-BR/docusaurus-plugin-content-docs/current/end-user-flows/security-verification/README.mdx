# Verificação de segurança

Quando usuários autenticados tentam realizar ações sensíveis ou de alto risco—como alterar sua senha, efetuar um pagamento ou acessar informações confidenciais como contracheques ou detalhes de contas bancárias—medidas de segurança adicionais são essenciais. Esse fluxo é especialmente crítico em aplicações sensíveis como bancos, saúde e serviços governamentais.

Esse processo, conhecido como _verificação de segurança_, exige que os usuários revalidem sua identidade para confirmar que são os titulares autorizados da conta. Ao implementar a verificação de segurança, o sistema reforça a proteção contra acessos não autorizados, adicionando uma camada crítica de segurança para ações de alto risco e ajudando a proteger dados sensíveis.

:::tip[Prefira autenticação step-up OIDC para aplicações e APIs]
Para exigir autenticação recente ou MFA para suas próprias aplicações e recursos de API protegidos—ou para autorizar chamadas sensíveis da [Account API](/end-user-flows/account-settings/by-account-api) usando tokens padrão—utilize a [autenticação step-up OIDC](/end-user-flows/step-up-authentication) (`acr_values`, `max_age` e desafios RFC 9470).

Use a Verification API abaixo quando sua aplicação de primeira parte chamar a Account API diretamente com um cabeçalho `logto-verification-id`, ou quando precisar comprovar a posse de um novo endereço de e-mail ou número de telefone antes de vinculá-lo à conta.
:::

## Implementar verificação de segurança pela Account API \{#implement-security-verification-by-account-api}

:::note
Lembre-se de [habilitar a Account API](/end-user-flows/account-settings/by-account-api) primeiro e obter o `access_token` para o usuário.
:::

## Verificação de senha \{#password-verification}

Quando os usuários tentam alterar sua senha ou outra configuração de segurança por meio de uma integração direta com a Account API, solicite que insiram sua senha atual para obter um `verificationRecordId` válido por 10 minutos para o cabeçalho `logto-verification-id`.

| method | path                                                                                                     | description                         |
| ------ | -------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| POST   | [/api/verifications/password](https://openapi.logto.io/operation/operation-createverificationbypassword) | Verificar a senha atual do usuário. |

## Verificação por código único de e-mail/SMS \{#emailsms-one-time-code-verification}

Envie um código de verificação para o e-mail ou número de telefone do usuário e solicite que ele insira o código para confirmar sua identidade. Esses endpoints podem ser usados para verificar a identidade de um usuário ou para confirmar a posse de um e-mail ou número de telefone específico. Essa etapa de verificação é altamente recomendada quando um usuário tenta vincular um novo endereço de e-mail ou número de telefone à sua conta, garantindo a autenticidade das informações fornecidas.

| method | path                                                                                                                             | description                                              |
| ------ | -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| POST   | [/api/verifications/verification-code](https://openapi.logto.io/operation/operation-createverificationbyverificationcode)        | Enviar código de verificação por e-mail ou telefone.     |
| POST   | [/api/verifications/verification-code/verify](https://openapi.logto.io/operation/operation-verifyverificationbyverificationcode) | Verificar e-mail ou telefone pelo código de verificação. |
