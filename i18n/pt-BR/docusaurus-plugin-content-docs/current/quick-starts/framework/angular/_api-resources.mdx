Una `UserScope.Organizations` a quaisquer escopos existentes e faça login novamente após atualizar a configuração. `getOrganizationToken(organizationId)` retorna um token para a organização Logto selecionada; use `getAccessToken(resource)` para um token de recurso de API.

### Anexar token de acesso aos cabeçalhos da requisição \{#attach-access-token-to-request-headers}

Coloque o token no cabeçalho HTTP `Authorization` usando o formato Bearer (`Bearer SEU_TOKEN`). Por exemplo, adicione este método a um componente autenticado que injeta `LogtoService`:

```ts
async fetchProducts() {
  const accessToken = await this.logto.getAccessToken('https://shopping.your-app.com/api');
  const response = await fetch('https://shopping.your-app.com/api/products', {
    headers: {
      Authorization: `Bearer ${accessToken}`,
    },
  });

  if (!response.ok) {
    throw new Error(`Request failed: ${response.status}`);
  }

  return response.json();
}
```

:::note
O exemplo usa `fetch`. Se você usar o `HttpClient` do Angular, defina o mesmo cabeçalho `Authorization` nas opções da requisição.
:::
