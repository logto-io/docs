# Serviço principal

## Introdução \{#introduction}

_O Serviço principal_ é um serviço monolítico para funções críticas do Logto. O código-fonte está em [`@logto/core`](https://github.com/logto-io/logto/tree/master/packages/core).

:::note
_O Serviço principal_ e _SDK core_ são dois conceitos separados. Veja [Convenção de SDK](/developers/sdk-conventions) para as diferenças.
:::

Para simplificar, dividimos o Serviço principal em quatro módulos principais:

      </td>

As APIs de backend, incluindo OIDC, são construídas dentro do pacote `core`, enquanto os proxies de frontend dependem dos pacotes irmãos correspondentes no monorepo do Logto.

## OIDC Provider \{#oidc-provider}

O Logto utiliza a incrível implementação certificada do [OpenID Connect](https://openid.net/connect/) chamada [node-oidc-provider](https://github.com/panva/node-oidc-provider) nos bastidores. O provider é montado em `/oidc`, e você pode conferir as configurações e arquivos relativos em [packages/core/src/oidc](https://github.com/logto-io/logto/tree/master/packages/core/src/oidc).

O [Userinfo Endpoint](https://openid.net/specs/openid-connect-core-1_0.html#UserInfo) do OIDC está disponível e montado em `/oidc/me`.

:::info
Se você quiser chamar as APIs OIDC diretamente, lembre-se de definir o cabeçalho `Content-Type: application/x-www-form-urlencoded`.
:::

## Logto API \{#logto-api}

### Management API \{#management-api}

_Management API_ é um conjunto de APIs que gerenciam e atualizam dados do Logto. Somente usuários com o papel `admin` têm acesso a elas.

Acesse [Referências de API](https://openapi.logto.io) para ver os detalhes.

Para acessar a API programaticamente, veja [Interaja com a Management API](/integrate-logto/interact-with-management-api).

### Experience API \{#experience-api}

Experience API é um conjunto de endpoints dedicados que suportam interações de interface de login personalizada.

Essas APIs permitem que desenvolvedores implementem funcionalidades principais de autenticação, incluindo login, cadastro, redefinição de senha, vinculação de conta social e autenticação multifatorial (MFA). Para implementar essas funcionalidades, sua interface personalizada precisa interagir com a Experience API.

Para entender melhor os fluxos de usuário e detalhes de implementação:

- Confira o guia [Desenvolva sua interface personalizada](/customization/bring-your-ui/#develop-your-custom-ui) para aprender como usar a Experience API para construir sua interface de experiência personalizada
- Consulte [Referências da Experience API](https://openapi.logto.io/group/endpoint-experience) para documentação detalhada da API
- Leia o [RFC de design da Experience API](https://github.com/logto-io/rfcs/blob/master/draft/0004-experience-api.md) para especificações técnicas aprofundadas e exemplos

### Account API \{#account-api}

Account API é um conjunto abrangente de APIs que oferece aos usuários finais acesso direto à API sem precisar passar pela Management API. Aqui estão os destaques:

- Acesso direto: A Account API permite que os usuários finais acessem e gerenciem diretamente seu próprio perfil de conta sem exigir o repasse da Management API.
- Gerenciamento de perfil e identidades: Usuários podem gerenciar seus perfis e configurações de segurança, incluindo email, telefone, senha, conexões sociais e fatores MFA, além de recuperar tokens do Secret Vault para conexões sociais e SSO corporativo vinculadas.
- Controle de acesso global: O administrador tem controle total e global sobre as configurações de acesso, podendo personalizar cada campo.
- Autorização sem atrito: Autorizar nunca foi tão fácil! Basta usar `client.getAccessToken()` para obter um token opaco de acesso para o OP (Logto) e anexá-lo ao cabeçalho Authorization como `Bearer <access_token>`.

Com a Account API do Logto, você pode construir um sistema personalizado de gerenciamento de contas, como uma página de perfil totalmente integrada ao Logto.

Confira [Configurações de conta pela Account API](/end-user-flows/account-settings/by-account-api) para aprender como aproveitar a Account API para construir sua própria página de configurações de conta.

Consulte [Referências da Account API](https://openapi.logto.io/group/endpoint-my-account) para documentação detalhada da API.

## Proxies de frontend \{#frontend-proxies}

Um _proxy de frontend_ é uma função middleware que serve um projeto frontend de acordo com o ambiente:

- Se for desenvolvimento, ele faz proxy das requisições HTTP para o servidor de desenvolvimento do frontend.
- Se for produção, ele serve arquivos estáticos do frontend diretamente.
