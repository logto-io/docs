O Microsoft Entra ID pode exigir solicitações de autenticação SAML assinadas. Para usar isso com o Logto, siga esta ordem para evitar qualquer interrupção no login:

1. Na guia `Connection` do conector do Logto, clique em **Gerar nova chave** em **Certificado de assinatura de solicitação** e faça o download do certificado da chave ativa.
2. Nas configurações de autenticação única do aplicativo Entra ID, faça o upload do certificado em **Certificados de verificação**. Veja [Exigir solicitações de autenticação SAML assinadas](https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/howto-enforce-signed-saml-authentication).
3. De volta ao Logto, ative **Assinar solicitação de autenticação** no conector e salve.
4. No Entra ID, marque **Exigir certificados de verificação** e teste o fluxo de login.

O Entra ID só verifica solicitações assinadas com RSA-SHA256 (algoritmo padrão do Logto) e aplica a exigência para solicitações de login iniciadas pelo SP. Para a configuração completa e o fluxo de rotação de certificados, consulte [Assinar a solicitação de autenticação SAML](https://docs.logto.io/integrations/saml-sso#optional-sign-the-saml-authentication-request).
