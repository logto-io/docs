# Logto MCP Server

O Logto MCP Server é um servidor remoto [MCP (Model Context Protocol)](https://modelcontextprotocol.io/). Adicione a URL ao seu aplicativo de IA, faça login com sua conta Logto Cloud e comece a conversar com o Logto.

:::tip
O Logto MCP Server é construído com Logto e [MCP Auth](https://mcp-auth.dev). Se você quiser construir seu próprio servidor remoto MCP, veja [Construa seu próprio servidor remoto MCP](#build-your-own-remote-mcp-server).
:::

## O que você pode fazer \{#what-you-can-do}

- **Adicionar autenticação ao seu projeto**: A IA detecta seu framework, cria um aplicativo Logto e gera código de integração funcional. Suporta mais de 38 frameworks incluindo React, Next.js, Vue, Nuxt, SvelteKit, Express, Go, Python, iOS, Android, Flutter e outros.
- **Fazer perguntas sobre Logto**: A IA pesquisa na documentação do Logto e fornece respostas com fontes.

Mais funcionalidades estão chegando em breve, incluindo configuração da experiência de login, gerenciamento de RBAC e permissões com orientações de melhores práticas, configuração de multi-tenancy para construir apps B2B com organizações e muito mais.

## Como seu aplicativo de IA se conecta \{#how-your-ai-application-connects}

O Logto MCP Server suporta duas formas para um aplicativo de IA se identificar ao fazer login. Você não precisa criar nada no Logto Cloud para nenhuma delas.

- **Apenas URL do servidor (recomendado)**: A maioria dos aplicativos de IA agora suporta [documentos de metadados de client ID (CIMD)](/integrate-logto/third-party-applications/dynamic-apps). O aplicativo usa uma URL que possui como seu client ID, e o Logto lê o nome do aplicativo e os URIs de redirecionamento dessa URL. Você só precisa informar a URL do servidor `https://mcp.logto.io`.
- **Client ID estático**: Para aplicativos que ainda não suportam CIMD, informe o client ID OAuth público `mcp-client`. Esse client aceita URIs de redirecionamento loopback (`http://localhost` ou `http://127.0.0.1` com qualquer porta).

Se seu aplicativo tiver ambas as opções, use apenas a URL do servidor. Conexões existentes que usam `mcp-client` continuam funcionando, então você não precisa reconectá-las.

Quando você se conecta apenas com a URL do servidor, a página de login do Logto Cloud exibe uma tela de consentimento com o nome do aplicativo e o host da URL do client ID, como `claude.ai` ou `vscode.dev`. Verifique se o host corresponde ao aplicativo que você está usando antes de autorizar.

## Configuração no seu aplicativo de IA \{#set-up-in-your-ai-application}

### Amp \{#amp}

1. No [Amp](https://ampcode.com), abra **Personal Settings** > **Integrations & MCP** e clique em **Add MCP Server**.
2. Digite o nome `Logto MCP Server` e a URL do servidor: `https://mcp.logto.io`. O Amp detecta automaticamente o método de autenticação.
3. Clique em **Connect** e siga o prompt do Amp para fazer login.
4. Faça login com sua conta Logto Cloud e autorize a conexão.

:::tip
Se o Amp ficar em **Detecting Authentication** por muito tempo, clique em **Change** e selecione **OAuth** para pular a detecção automática de autenticação. Deixe **OAuth Client ID** e **OAuth Client Secret** em **Use Your Own OAuth App** em branco, depois clique em **Connect** e siga o prompt de login. O Amp suporta CIMD, então você não precisa registrar um app OAuth ou informar `mcp-client`.
:::

### Claude Code \{#claude-code}

```bash
claude mcp add --transport http logto https://mcp.logto.io
```

Depois, execute `/mcp` no Claude Code, selecione `logto` e siga o fluxo de login no navegador para autenticar com sua conta Logto Cloud. Você também pode executar `claude mcp login logto` no seu terminal.

### Claude (web e desktop) \{#claude-web-and-desktop}

1. Abra **Customize** > **Connectors** e clique em **Add custom connector**.
2. Digite o nome `Logto MCP Server` e a URL do servidor MCP remoto: `https://mcp.logto.io`. Deixe as configurações OAuth em **Advanced settings** em branco e clique em **Add**.
3. Na lista **Connectors**, encontre **Logto MCP Server** e clique em **Connect**.
4. Você será redirecionado para a página de login do Logto Cloud. Faça login com sua conta Logto Cloud e autorize a conexão.

Os conectores são salvos na sua conta Claude, então ficam disponíveis tanto no Claude web quanto no Claude Desktop.

### ChatGPT e Codex \{#chatgpt-and-codex}

1. Na barra lateral esquerda, abra **Plugins**, depois clique em **Add** > **Add custom MCP server** no canto superior direito.
2. Digite o nome `Logto MCP Server`. Em **Connection**, selecione **Server URL** e informe `https://mcp.logto.io`.
3. Mantenha o padrão **Authentication** (**OAuth**) e **Advanced OAuth settings**.
4. Selecione **I understand and want to continue** e clique em **Create as a plugin**.
5. Na janela **Connect Logto MCP Server**, clique em **Connect Logto MCP Server**. Faça login com sua conta Logto Cloud e autorize a conexão.

:::tip
Se **Logto MCP Server** não aparecer em **Installed** após o login, aguarde um momento e clique no botão de atualizar no canto superior direito da página **Plugins**.
:::

Você também pode adicionar o servidor pelo Codex CLI:

```bash
codex mcp add logto --url https://mcp.logto.io
codex mcp login logto
```

Uma janela do navegador será aberta. Faça login com sua conta Logto Cloud para conectar. O app desktop do ChatGPT, Codex CLI e a extensão Codex IDE compartilham essa configuração.

### Cursor \{#cursor}

O Cursor ainda não suporta CIMD, então utiliza o client ID estático.

1. Abra **Customize** > **MCPs**, ou abra `~/.cursor/mcp.json` (global) ou `.cursor/mcp.json` (projeto).
2. Adicione a seguinte configuração:

   ```json
   {
     "mcpServers": {
       "Logto": {
         "url": "https://mcp.logto.io",
         "auth": {
           "CLIENT_ID": "mcp-client",
           "scopes": ["mcp:all"]
         }
       }
     }
   }
   ```

3. Clique em **Connect** ao lado do servidor. Uma página de login do Logto Cloud aparecerá. Faça login com sua conta Logto Cloud para conectar.

Faça login a partir do app desktop do Cursor. O callback web usado pelo Cursor na web e pelos Cursor Agents não é suportado.

### OpenCode \{#opencode}

1. Adicione a seguinte configuração ao seu arquivo `opencode.json`:

   ```json
   {
     "$schema": "https://opencode.ai/config.json",
     "mcp": {
       "Logto": {
         "enabled": true,
         "type": "remote",
         "url": "https://mcp.logto.io"
       }
     }
   }
   ```

2. Execute o seguinte comando para autenticar:
   ```bash
   opencode mcp auth Logto
   ```
   Note que `Logto` corresponde ao nome do servidor MCP no seu arquivo de configuração.

Uma janela do navegador será aberta. Faça login com sua conta Logto Cloud para autorizar e conectar.

### VS Code \{#vs-code}

1. Abra a paleta de comandos (`Command + Shift + P`) e selecione **MCP: Add Server...**.
2. Escolha **HTTP** como tipo de servidor.
3. Informe a URL: `https://mcp.logto.io`. Você pode optar por instalar no seu workspace para melhor isolamento e gerenciamento.
4. Quando o VS Code solicitar autenticação, permita. Você será redirecionado para a página de login do Logto Cloud. Faça login com sua conta Logto Cloud para conectar.

Alternativamente, adicione o servidor ao `.vscode/mcp.json` ou ao seu `mcp.json` de usuário:

```json
{
  "servers": {
    "logto": {
      "type": "http",
      "url": "https://mcp.logto.io"
    }
  }
}
```

### Windsurf \{#windsurf}

O Windsurf não documenta suporte a CIMD, então use [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) com o client ID estático.

1. Abra a paleta de comandos (`Command + Shift + P`) e selecione **Windsurf: MCP Marketplace**.
2. Na seção **Installed MCPs**, clique no ícone de configurações à direita para abrir o arquivo de configuração MCP.
3. Adicione a seguinte [configuração](https://docs.windsurf.com/windsurf/cascade/mcp#mcp_config-json):

   ```json
   {
     "mcpServers": {
       "Logto": {
         "command": "npx",
         "args": [
           "mcp-remote",
           "https://mcp.logto.io",
           "--allow-http",
           "--static-oauth-client-info",
           "{ \"client_id\": \"mcp-client\", \"scope\": \"mcp:all\" }",
           "--resource",
           "https://mcp.logto.io/"
         ]
       }
     }
   }
   ```

Uma página de login do Logto Cloud aparecerá automaticamente. Faça login com sua conta Logto Cloud para conectar.

### Outros clientes MCP \{#other-mcp-clients}

O Logto MCP Server funciona com qualquer cliente MCP que suporte autorização OAuth:

- **Se seu cliente suporta CIMD**: Informe apenas a URL do servidor MCP `https://mcp.logto.io`. O cliente descobre todo o resto a partir do servidor.
- **Caso contrário**: Use a seguinte configuração.
  - **URL do servidor MCP:** `https://mcp.logto.io`
  - **OAuth client ID:** `mcp-client` (sem client secret)
  - **Redirect URI:** um endereço loopback, como `http://localhost:<port>/callback`
  - **Resource:** `https://mcp.logto.io/` (se seu cliente exigir)
  - **Scope:** `mcp:all` (se seu cliente exigir)

O Logto MCP Server não suporta Dynamic Client Registration (DCR). Se você é desenvolvedor de aplicativos de IA, [publique um documento de metadados de client ID](/integrate-logto/third-party-applications/dynamic-apps#publish-a-client-id-metadata-document) para seu aplicativo, e ele poderá se conectar sem nenhuma configuração no Logto. Se isso não for possível, [entre em contato conosco](https://logto.io/contact) com os detalhes do seu aplicativo.
