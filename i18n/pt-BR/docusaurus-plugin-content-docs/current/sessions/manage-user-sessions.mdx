# Gerenciar sessões de usuário

O gerenciamento de sessões de usuário ajuda usuários e administradores a revisar estados de login ativos e revogar sessões quando necessário.

No Logto, você pode gerenciar sessões por três caminhos comuns:

- **Account API**: Para autoatendimento do usuário final na página de configurações da conta do seu produto.
- **Management API**: Para ferramentas de administração ou suporte gerenciarem sessões de qualquer usuário.
- **Admin Console**: Para fluxos operacionais no Logto Console sem a necessidade de construir ferramentas personalizadas.

## Escolha a API certa \{#choose-the-right-api}

| Cenário                                                                            | API recomendada |
| ---------------------------------------------------------------------------------- | --------------- |
| Permitir que usuários autenticados gerenciem suas próprias sessões ativas          | Account API     |
| Permitir que administradores ou equipes de suporte gerenciem sessões de um usuário | Management API  |
| Permitir que operadores gerenciem sessões diretamente no Logto Console             | Admin Console   |

## Visualizar sessões ativas \{#view-active-sessions}

### Account API (autoatendimento) \{#account-api-self-service}

Use o endpoint de sessão do Account API para listar as sessões ativas do usuário atual.

- Seção de referência: [Gerenciar sessões de usuário](/end-user-flows/account-settings/by-account-api#manage-user-sessions)
- Endpoint: [`GET /api/my-account/sessions`](https://openapi.logto.io/operation/operation-getsessions)

Antes de expor essa funcionalidade aos usuários finais, certifique-se de que o gerenciamento de sessões está habilitado nas configurações do Account center e que seu aplicativo solicita o escopo necessário do Account API.

### Management API (ferramentas administrativas) \{#management-api-admin-tools}

Use o Management API quando seu sistema administrativo precisar listar sessões de um usuário alvo.

- Seção de referência: [Gerenciamento de sessões de usuário](/end-user-flows/account-settings/by-management-api#user-session-management)
- Endpoint: [`GET /api/users/{userId}/sessions`](https://openapi.logto.io/operation/operation-listusersessions)
- Endpoint de detalhes opcionais: [`GET /api/users/{userId}/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-getusersession)

## Revogar sessões \{#revoke-sessions}

### Account API (usuário final revoga suas próprias sessões) \{#account-api-end-user-revokes-own-sessions}

Usuários finais podem revogar uma sessão específica de sua própria lista de sessões.

- Seção de referência: [Gerenciar sessões de usuário](/end-user-flows/account-settings/by-account-api#manage-user-sessions)
- Endpoint: [`DELETE /api/my-account/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-deletesessionbyid)

Para operações sensíveis, o gerenciamento de sessões do Account API exige autenticação recente do usuário antes do acesso. Veja [Autenticação step-up](/end-user-flows/step-up-authentication#account-api-and-account-center).

### Management API (admin revoga sessões de usuário) \{#management-api-admin-revokes-user-sessions}

Administradores podem revogar a sessão de um usuário alvo pelo ID do usuário e ID da sessão.

- Seção de referência: [Gerenciamento de sessões de usuário](/end-user-flows/account-settings/by-management-api#user-session-management)
- Endpoint: [`DELETE /api/users/{userId}/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-deleteusersession)

## Admin Console \{#admin-console}

Se sua equipe gerencia usuários diretamente no Logto Console, você pode revisar sessões ativas e revogar sessões específicas na página de detalhes do usuário.

- Seção de referência: [Gerenciar sessões ativas do usuário](/user-management/manage-users#manage-user-active-sessions)
