# Ative a autenticação para seus apps com MCP usando Logto

<ExploreAiSolutions />

Este guia mostra como integrar o Logto ao seu servidor MCP usando [mcp-auth](https://mcp-auth.dev) e o [SDK oficial do MCP](https://github.com/modelcontextprotocol) v2, permitindo autenticar usuários e ler com segurança sua identidade verificada a partir do token de acesso.

Você aprenderá como:

- Configurar o Logto como servidor de autorização para seu servidor MCP.
- Configurar uma ferramenta “whoami” em seu servidor MCP para retornar as reivindicações de identidade do usuário atual.
- Testar o fluxo com o VS Code (cliente MCP).

Após este tutorial, seu servidor MCP irá:

- Autenticar usuários em seu tenant Logto.
- Verificar tokens de acesso JWT emitidos pelo Logto (assinatura, emissor, público e expiração).
- Retornar as reivindicações de identidade verificadas (`sub`, `iss`, `aud`, etc.) para a invocação da ferramenta "whoami".

Depois de concluir a integração, você pode substituir o VS Code pelo seu próprio cliente MCP, como um aplicativo web, para acessar as ferramentas e recursos expostos pelo seu servidor MCP.

## Configurar app no Logto \{#set-up-app-in-logto}

Seu cliente MCP precisa ser registrado como um aplicativo no Logto para iniciar o fluxo de autorização. Vamos registrar o VS Code como cliente neste guia:

1. Faça login no seu Console Logto.
2. Vá para <CloudLink to="/applications">**Aplicativos**</CloudLink> → **Criar aplicativo** → **Criar app sem framework**.
3. Escolha o tipo: Aplicativo nativo.
4. Preencha o nome do app (por exemplo, "VS Code") e outros campos obrigatórios, depois clique em **Criar aplicativo**.
5. Na seção **Configurações** / **URIs de redirecionamento**, adicione os seguintes URIs de redirecionamento para o VS Code e salve as alterações:

   ```
   http://127.0.0.1
   https://vscode.dev/redirect
   ```

6. Salve e copie o **ID do app** e o **endpoint do emissor**.

## Testar a integração \{#test-the-integration}

1. Inicie o servidor MCP:

   ```bash
   npm start
   ```

2. Conecte o VS Code ao seu servidor MCP:

   1. Pressione `Command + Shift + P` (macOS) ou `Ctrl + Shift + P` (Windows / Linux) para abrir a Paleta de Comandos.
   2. Digite `MCP: Add Server...` e selecione.
   3. Escolha `HTTP` como tipo de servidor.
   4. Insira a URL do servidor MCP: `http://localhost:3001/`
   5. Quando o fluxo OAuth começar, o VS Code solicitará o **Client ID**: cole o **ID do app** que você copiou anteriormente.
   6. Como é um cliente público sem segredo de app, apenas pressione Enter para pular o segredo.
   7. Complete o fluxo de login em seu navegador.

3. Após o login, execute a ferramenta `whoami` no VS Code.

Você deverá ver as reivindicações verificadas do token de acesso, como:

```json
{
  "iss": "https://my-project.logto.app/oidc",
  "sub": "user_XXXX",
  "aud": "http://localhost:3001/",
  "client_id": "<your-app-id>"
}
```
