:::info[Código de exemplo]
O código de exemplo completo e executável para este guia pode ser encontrado no repositório [mcp-auth/js](https://github.com/mcp-auth/js/tree/master/packages/sample-servers):

- [`whoami-express`](https://github.com/mcp-auth/js/tree/master/packages/sample-servers/src/whoami-express): o servidor "whoami" deste guia, em Node.js com Express.
- [`whoami`](https://github.com/mcp-auth/js/tree/master/packages/sample-servers/src/whoami): o mesmo servidor construído com fetch-native (web-standard `Request` / `Response` com [Hono](https://hono.dev)), implantável no Cloudflare Workers.
