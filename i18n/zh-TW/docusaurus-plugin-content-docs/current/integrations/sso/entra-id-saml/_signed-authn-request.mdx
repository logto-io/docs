Microsoft Entra ID 可以要求簽署的 SAML 驗證請求 (SAML authentication requests)。若要在 Logto 中使用此功能，請依照以下順序操作，以避免登入流程中斷：

1. 在 Logto 連接器 (Connector) 的 `Connection` 分頁下，於 **Request signing certificate** 點擊 **Generate new key**，並下載作用中金鑰的憑證。
2. 在 Entra ID 應用程式的單一登入 (Single Sign-On) 設定中，於 **Verification certificates** 上傳該憑證。詳見 [強制簽署 SAML 驗證請求 (Enforce signed SAML authentication requests)](https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/howto-enforce-signed-saml-authentication)。
3. 回到 Logto，在連接器 (Connector) 上啟用 **Sign authentication request**，並儲存設定。
4. 在 Entra ID 勾選 **Require verification certificates**，然後測試登入流程。

Entra ID 僅驗證以 RSA-SHA256（Logto 預設演算法）簽署的請求，並強制要求 SP 發起 (SP-initiated) 的登入請求。完整設定與憑證輪替流程，請參閱 [簽署 SAML 驗證請求 (Sign the SAML authentication request)](https://docs.logto.io/integrations/saml-sso#optional-sign-the-saml-authentication-request)。
