:::info[範例程式碼]
本指南的完整可執行範例程式碼可在 [mcp-auth/js](https://github.com/mcp-auth/js/tree/master/packages/sample-servers) 儲存庫中找到：

- [`whoami-express`](https://github.com/mcp-auth/js/tree/master/packages/sample-servers/src/whoami-express)：本指南中的 "whoami" 伺服器，基於 Node.js 與 Express。
- [`whoami`](https://github.com/mcp-auth/js/tree/master/packages/sample-servers/src/whoami)：相同伺服器，採用 fetch-native（網頁標準 `Request` / `Response`，搭配 [Hono](https://hono.dev)），可部署至 Cloudflare Workers。

:::
