# 核心服務 (Core Service)

## 簡介 \{#introduction}

_核心服務 (Core Service)_ 是負責 Logto 關鍵職責的單體服務。原始碼位於 [`@logto/core`](https://github.com/logto-io/logto/tree/master/packages/core)。

:::note
_核心服務 (Core Service)_ 與 _SDK core_ 是兩個不同的概念。差異請參見 [SDK 規範](/developers/sdk-conventions)。
:::

為簡化說明，我們將核心服務分為四大模組：

後端 API（包含 OIDC）皆建構於 `core` 套件中，而前端代理則依賴 Logto monorepo 中對應的同層套件。

## OIDC Provider \{#oidc-provider}

Logto 內部採用經過認證的 [OpenID Connect](https://openid.net/connect/) 實作 [node-oidc-provider](https://github.com/panva/node-oidc-provider)。該 provider 掛載於 `/oidc`，相關設定與檔案可於 [packages/core/src/oidc](https://github.com/logto-io/logto/tree/master/packages/core/src/oidc) 查閱。

OIDC [Userinfo Endpoint](https://openid.net/specs/openid-connect-core-1_0.html#UserInfo) 可用，掛載於 `/oidc/me`。

:::info
若你想直接呼叫 OIDC API，請記得設置標頭 `Content-Type: application/x-www-form-urlencoded`。
:::

## Logto API \{#logto-api}

### Management API \{#management-api}

_Management API_ 是一組用於管理與更新 Logto 資料的 API，僅具有 `admin` 角色的使用者可存取。

詳細內容請參閱 [API 參考文件](https://openapi.logto.io)。

如需程式化存取 API，請參考 [與 Management API 互動](/integrate-logto/interact-with-management-api)。

### Experience API \{#experience-api}

Experience API 是一組專為自訂登入介面互動設計的端點。

這些 API 讓開發者能實作核心驗證 (Authentication) 功能，包括登入、註冊、重設密碼、社交帳號綁定與多重要素驗證 (MFA)。若要實現這些功能，你的自訂 UI 需與 Experience API 互動。

想更深入了解使用者流程與實作細節：

- 請參閱 [開發自訂 UI](/customization/bring-your-ui/#develop-your-custom-ui) 指南，學習如何利用 Experience API 建構自訂體驗 UI
- 參考 [Experience API 參考文件](https://openapi.logto.io/group/endpoint-experience) 取得詳細 API 文件
- 閱讀 [Experience API 設計 RFC](https://github.com/logto-io/rfcs/blob/master/draft/0004-experience-api.md) 以獲得更深入的技術規格與範例

### Account API \{#account-api}

Account API 是一組完整的 API，讓終端使用者可直接存取 API，而無需經過 Management API，重點如下：

- 直接存取：Account API 讓終端使用者可直接存取並管理自己的帳號資料，無需透過 Management API 中繼。
- 使用者資料與身分管理：使用者可管理個人資料與安全設定，包括電子郵件、手機、密碼、社交連結與 MFA 因子，並可取得已連結社交與企業級單一登入 (SSO) 的 Secret Vault 權杖。
- 全域存取控制：管理員可對存取設定進行完整、全域的控制，並可自訂各欄位。
- 無縫授權 (Seamless authorization)：授權變得前所未有地簡單！只需使用 `client.getAccessToken()` 取得 OP (Logto) 的不透明權杖 (opaque access token)，並以 `Bearer <access_token>` 附加於 Authorization 標頭即可。

透過 Logto Account API，你可以打造如個人資料頁等與 Logto 完整整合的自訂帳號管理系統。

請參閱 [透過 Account API 管理帳號設定](/end-user-flows/account-settings/by-account-api) 學習如何利用 Account API 建立自己的帳號設定頁。

詳細 API 文件請參考 [Account API 參考文件](https://openapi.logto.io/group/endpoint-my-account)。

## 前端代理 (Frontend proxies) \{#frontend-proxies}

_前端代理 (frontend proxy)_ 是一個中介軟體函式，根據環境為前端專案提供服務：

- 開發環境時，會將 HTTP 請求代理至前端開發伺服器。
- 生產環境時，則直接提供靜態前端檔案。
