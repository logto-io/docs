:::note
Logto Android SDK 最低支援的 Android API 等級為 24。
:::

Logto Android SDK 主要有兩個版本：

- **v3**：在 [Chrome Custom Tabs](https://developer.android.com/develop/ui/views/layout/webapps/overview-of-android-custom-tabs)（系統瀏覽器）中開啟登入體驗，支援通行密鑰登入（passkey sign-in）並共用瀏覽器會話。請注意，v3 移除了 <MainSiteUrl href="/integrations/wechat-native">WeChat (Native)</MainSiteUrl> 和 <MainSiteUrl href="/integrations/alipay-native">Alipay (Native)</MainSiteUrl> 連接器的支援；你可以改用 <MainSiteUrl href="/integrations/wechat-web">WeChat (Web)</MainSiteUrl> 和 <MainSiteUrl href="/integrations/alipay-web">Alipay (Web)</MainSiteUrl>，這些會透過瀏覽器運作。如果你依賴原生連接器，請繼續使用 v2。
- **v2**：在嵌入式 WebView 中開啟登入體驗，這是原生社交連接器所需，但不支援 <MainSiteUrl href="/end-user-flows/sign-up-and-sign-in/passkey-sign-in">通行密鑰登入 (passkey sign-in)</MainSiteUrl>（WebView 不支援 WebAuthn，也就是通行密鑰的底層標準）。

本指南涵蓋兩個版本。請在下方分頁選擇你的版本，選擇將在本指南中同步保留。

在安裝 Logto Android SDK 前，請確保已在 Gradle 專案的建置檔案中加入 `mavenCentral()` 至你的 repository 設定：

```kotlin title="settings.gradle.kts"
// 設定 mavenCentral 作為套件來源
dependencyResolutionManagement {
  repositories {
    mavenCentral()
  }
}
```

由於 SDK 需要網路存取權限，請在你的 `AndroidManifest.xml` 檔案中加入以下權限設定：

```xml title="AndroidManifest.xml"
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
  xmlns:tools="http://schemas.android.com/tools">

  <!-- 加入網路權限 -->
  <uses-permission android:name="android.permission.INTERNET" />

  <!-- 其他設定... -->
</manifest>
```
