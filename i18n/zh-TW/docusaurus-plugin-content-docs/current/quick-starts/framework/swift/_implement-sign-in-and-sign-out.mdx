#### 設定 Redirect URI \{#configure-redirect-uri}

<Tabs groupId="swift-sdk-version" defaultValue="v2">

<TabItem value="v2" label="v2">

<ConfigureRedirectUri
  figureSrc="/img/assets/ios-redirect-uri.png"
  redirectUri="io.logto.app://callback"
/>

在 v2 中，登入體驗會在 [`ASWebAuthenticationSession`](https://developer.apple.com/documentation/authenticationservices/aswebauthenticationsession)（系統瀏覽器）中開啟，並透過作業系統層級的 callback 匹配將 redirect 導回你的應用程式。對於像 `io.logto.app://callback` 這樣的自訂 scheme redirect URI，只需在你的 app 的 `Info.plist` 中註冊 scheme 部分（`io.logto.app`），然後將完整的 redirect URI 加入 Logto 應用程式的 Redirect URIs。

在 Xcode 中，打開你的 app target，選擇 **Info**，展開 **URL Types**，並在 **URL Schemes** 中新增一筆 `io.logto.app`。如果你直接編輯 `Info.plist`，請加入：

```xml title="Info.plist"
<key>CFBundleURLTypes</key>
<array>
  <dict>
    <key>CFBundleTypeRole</key>
    <string>Editor</string>
    <key>CFBundleURLName</key>
    <string>io.logto.app</string>
    <key>CFBundleURLSchemes</key>
    <array>
      <string>io.logto.app</string>
    </array>
  </dict>
</array>
```

在 v2 的瀏覽器流程中，你不需要呼叫 `LogtoClient.handle(url:)`；該 plugin handoff API 已隨內嵌 WebView 流程移除。

#### 要用 Universal Links 取代自訂 scheme 嗎？ \{#use-universal-links-instead-of-a-custom-scheme}

</summary>

你也可以使用像 `https://example.com/callback` 這樣的 HTTPS redirect URI：

1. 為你的 app 加入 Associated Domains 能力。
2. 設定 `webcredentials:example.com`，讓 `ASWebAuthenticationSession` 能在 iOS 17.4 及更新版本上匹配 HTTPS callback。
3. 如果同一個 URL 也要在驗證 (Authentication) 流程外以 Universal Link 開啟你的 app，請設定 `applinks:example.com`，並為該網域與路徑主機一份有效的 `apple-app-site-association` 檔案。
4. 將 HTTPS URI 加入 Logto 應用程式的 Redirect URIs。
5. 將同一 URI 傳給 `signInWithBrowser`。

在 iOS 17.4 及更新版本，SDK 會使用 `ASWebAuthenticationSession` 的 HTTPS callback matching API，因此 HTTPS redirect 可自動完成並關閉 session。在舊版 iOS，授權請求仍可用 HTTPS redirect URI，但 session 可能不會自動關閉，除非你的 app 自行處理 Universal Link callback。如果你需要在舊版 iOS 上自動完成，請保留自訂 scheme redirect 作為相容選項。

#### 登入與登出 \{#sign-in-and-sign-out}

<SignInNote calling=".signInWithBrowser(redirectUri:)" />

<Tabs groupId="swift-sdk-version" defaultValue="v2">

<TabItem value="v2" label="v2">

在 v2 中，`client.signOut(postLogoutRedirectUri:)` 會執行完整登出：清除本地憑證、撤銷重新整理權杖 (refresh token)，並在系統瀏覽器開啟 end session endpoint 結束 Logto session。瀏覽器會透過 post sign-out redirect URI 導回你的 app。使用前，請先到 Logto Console 的應用程式詳細頁，新增 post sign-out redirect URI `io.logto.app://signed-out` 並點擊「Save changes」。post sign-out redirect URI 可使用你登入時註冊的相同自訂 scheme。

例如，在 SwiftUI app 中：

```swift title="ContentView.swift"
// 這裡僅註解與訊息可翻譯，其餘程式碼請保持原樣
struct ContentView: View {
  @State var isAuthenticated: Bool

  private let redirectUri = "io.logto.app://callback"
  private let postLogoutRedirectUri = "io.logto.app://signed-out"

  init() {
    isAuthenticated = client.isAuthenticated
  }

  var body: some View {
    VStack {
      if isAuthenticated {
        Button("Sign Out") {
          Task { [self] in
            let error = await client.signOut(postLogoutRedirectUri: postLogoutRedirectUri)
            if let error = error {
              print(error)
              return
            }
            isAuthenticated = false
          }
        }
      } else {
        Button("Sign In") {
          Task { [self] in
            do {
              try await client.signInWithBrowser(redirectUri: redirectUri)
              isAuthenticated = true
            } catch let error as LogtoClientErrors.SignIn {
              // 登入時發生錯誤
            } catch {
              // 其他錯誤
            }
          }
        }
      }
    }
  }
}
```

:::note

- 你也可以呼叫 `client.signOut()` 而不帶 post sign-out redirect URI。這種情況下不需在 Console 設定：瀏覽器會顯示 Logto 登出頁面，使用者可手動關閉返回 app。
- 若無 UI context，可呼叫 `client.clearCredentials()` 清除本地憑證並撤銷重新整理權杖 (refresh token)。注意這會保留瀏覽器中的 Logto session，因此下次 `signInWithBrowser` 可能會自動透過該 session 靜默登入。

:::

#### 保留「儲存密碼」提示 \{#keep-the-save-password-prompt}

`ASWebAuthenticationSession` 會在 Logto redirect 回你的 app 時立即關閉，因此 iOS 的「儲存密碼」提示會在密碼登入後馬上消失。若要保留提示，請在 `extraParams` 傳入 `confirm_redirect_policy=password`。Logto 會在使用者輸入密碼後顯示繼續頁面，待使用者點擊繼續後才返回你的 app：

```swift
try await client.signInWithBrowser(
  redirectUri: redirectUri,
  extraParams: ["confirm_redirect_policy": "password"]
)
```

詳情請參閱 [保留 iOS「儲存密碼」提示](https://docs.logto.io/end-user-flows/authentication-parameters#keep-the-ios-save-password-prompt)。

你可以使用 `client.signInWithBrowser(redirectUri:)` 讓使用者登入，並用 `client.signOut()` 讓使用者登出。

例如，在 SwiftUI app 中：

```swift title="ContentView.swift"
// 這裡僅註解與訊息可翻譯，其餘程式碼請保持原樣
struct ContentView: View {
  @State var isAuthenticated: Bool

  init() {
    isAuthenticated = client.isAuthenticated
  }

  var body: some View {
    VStack {
      if isAuthenticated {
        Button("Sign Out") {
          Task { [self] in
            await client.signOut()
            isAuthenticated = false
          }
        }
      } else {
        Button("Sign In") {
          Task { [self] in
            do {
              try await client.signInWithBrowser(redirectUri: "io.logto://callback")
              isAuthenticated = true
            } catch let error as LogtoClientErrors.SignIn {
              // 登入時發生錯誤
            } catch {
              // 其他錯誤
            }
          }
        }
      }
    }
  }
}
```
