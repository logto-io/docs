初始化用戶端時，請建立一個 `LogtoClient` 實例並傳入 `LogtoConfig` 物件。

```swift title="ContentView.swift"
import Logto
import LogtoClient

let config = try! LogtoConfig(
  endpoint: "<your-logto-endpoint>", // 例如：http://localhost:3001
  appId: "<your-app-id>"
)
let client = LogtoClient(useConfig: config)
```

:::info

預設情況下，我們會將像是 ID 權杖 (ID Token) 和重新整理權杖 (Refresh Token) 等憑證儲存在 Keychain，因此使用者回來時無需再次登入。

若要關閉此行為，請將 `usingPersistStorage` 設為 `false`：

```swift
let config = try! LogtoConfig(
  // ...
  usingPersistStorage: false
)
```

:::
