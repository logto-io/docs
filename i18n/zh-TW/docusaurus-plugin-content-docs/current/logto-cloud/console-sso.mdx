# Console SSO

Console SSO 讓你的團隊可以使用公司身分提供者 (IdP)，如 Microsoft Entra ID、Okta 或 Google Workspace，登入 <Url href="https://cloud.logto.io">Logto Cloud Console</Url>。當你驗證了成員的電子郵件網域後，這些成員在登入 Logto Cloud 時會被導向你的 IdP。

Console SSO 僅涵蓋登入 Logto Cloud 本身。若要讓**你的使用者**使用他們公司的 IdP 登入**你的應用程式**，請在你的租戶中使用 [企業級單一登入 (Enterprise SSO)](/connectors/enterprise-connectors)。

## Console SSO 如何運作 \{#how-console-sso-works}

- **它屬於你的帳號，而非租戶。** Console SSO 連接器由建立它的 Logto Cloud 帳號擁有，僅該帳號可管理。租戶方案、降級或租戶刪除不會影響它。
- **它不授予租戶存取權。** 使用 SSO 登入僅證明身分，仍需邀請或成員資格才能開啟租戶。詳見 [租戶成員管理](/logto-cloud/tenant-member-management)。
- **它由你的帳號計費。** 連接器按連接器數量透過你的訂閱單獨計費，與租戶方案分開。詳見 [價格與計費](#pricing-and-billing)。

## 設定 Console SSO \{#set-up-console-sso}

### 建立連接器 \{#create-a-connector}

1. 在 Logto Cloud Console，點擊右上角使用者選單並選擇 **單一登入 (Single sign-on)**。<Url href="https://cloud.logto.io/console-sso">Console SSO</Url> 頁面會在新分頁開啟。
2. 點擊 **新增連接器 (Add connector)** 並選擇你的身分提供者。
3. 建立第一個連接器時，選擇計費帳號並在 Stripe Checkout 完成付款。之後新增的連接器會自動加入同一訂閱，無需再次結帳。
4. 連接器會在其設定頁面開啟。

### 設定連線 \{#configure-the-connection}

在 **連線 (Connection)** 分頁，輸入來自你的 IdP 的設定。欄位與租戶中的 [企業級單一登入 (Enterprise SSO) 連接器](/connectors/enterprise-connectors) 相同：

- **OIDC**：將頁面顯示的 **Redirect URI** 註冊到你的 IdP，然後輸入 issuer、client ID 和 client secret。
- **SAML**：將頁面顯示的服務提供者中繼資料提供給你的 IdP，然後輸入 IdP 的中繼資料。

在 **SSO 體驗 (SSO Experience)** 分頁，你可以更改登入頁面顯示的名稱。

### 驗證你的電子郵件網域 \{#verify-your-email-domains}

Console SSO 僅適用於你證明擁有的電子郵件網域。

1. 在 **SSO 體驗 (SSO Experience)** 分頁，輸入一個網域，例如 `example.com`，並點擊 **新增網域 (Add domain)**。
2. 將下方顯示的 TXT 記錄新增到你的 DNS 服務商：

   | Type | Name                           | Value                                        |
   | ---- | ------------------------------ | -------------------------------------------- |
   | TXT  | `_logto-cloud-sso.example.com` | 頁面顯示的權杖 (The token shown on the page) |

3. 保持該網域頁面開啟。Logto 每 10 秒檢查一次記錄。找到記錄後，該網域會綁定到連接器並標記為 **已綁定 (Bound)**。你可以移除 TXT 記錄。

一個網域只能綁定到一個 Console SSO 連接器。移除已綁定網域會停止該網域電子郵件地址的 SSO。再次新增需重新驗證。

:::note
計費不會等待這一步。連接器自建立起即開始計費，無論連線設定或網域是否完成。
:::

### 使用 SSO 登入 \{#sign-in-with-sso}

在 Logto Cloud 登入頁面，成員輸入工作電子郵件。如果其網域已綁定連接器，將被導向你的 IdP 進行登入。

## 價格與計費 \{#pricing-and-billing}

每個連接器每月費用為 **128 美元**，另加適用稅金。你的帳號僅有一個 Console SSO 訂閱，其數量即為連接器數量。

| 當你…                            | 發生的情況                                                 |
| -------------------------------- | ---------------------------------------------------------- |
| 新增第一個連接器                 | 於 Stripe Checkout 支付首月費用。付款日即為每月帳單日。    |
| 新增另一個連接器                 | 立即新增。當月剩餘天數的比例費用將加到下期帳單。           |
| 刪除一個連接器（尚有其他連接器） | 未用時間的比例金額將於下期帳單折抵，不會退刷到信用卡。     |
| 刪除最後一個連接器               | 訂閱立即取消。若當月已付費，未用時間將退還至你的付款方式。 |
| 取消後再次新增連接器             | 透過 Stripe Checkout 開啟新訂閱，並有新的帳單日。          |

編輯連接器設定或網域不會影響費用。

### 帳單範例 \{#example-invoice}

下表假設每月 30 天且未含稅。實際比例費用以秒計算。

| 日期  | 動作                           | 連接器數 | 帳單影響                                      |
| ----- | ------------------------------ | -------- | --------------------------------------------- |
| 11/1  | 新增第一個連接器               | 1        | 結帳時支付：**$128.00**。帳單日為每月 1 日。  |
| 11/16 | 新增第二個連接器（剩 15 天）   | 2        | +$128 × 15/30 = +$64.00 加入下期帳單          |
| 11/25 | 刪除一個連接器（剩 6 天）      | 1        | −$128 × 6/30 = −$25.60 加入下期帳單           |
| 12/1  | 月帳單                         | 1        | 12 月 $128.00 + $64.00 − $25.60 = **$166.40** |
| 12/16 | 刪除最後一個連接器（剩 15 天） | 0        | 訂閱取消；**$64.00** 退還                     |

### 訂閱與帳單紀錄 \{#subscription-and-billing-history}

在 Console 頂部列開啟 **訂閱 (Subscription)**。無論選擇哪個租戶，都會顯示你帳號的訂閱。

- **訂閱 (Subscription)** 顯示目前訂閱、價格、下次收費與帳單日。使用 **管理付款 (Manage payment)** 可更新付款方式或支付未結帳單。
- **帳單紀錄 (Billing history)** 顯示所有帳單，包括已取消訂閱。可選擇帳單檢視並下載發票或收據。

### 逾期付款 \{#overdue-payments}

若付款失敗，Stripe 會重試，訂閱標記為 **逾期 (Past due)**。你的連接器仍可使用，但請透過 **管理付款 (Manage payment)** 更新付款方式。

若**連續三期月帳單**皆未付且所有重試失敗，Logto 會暫停訂閱並**刪除所有連接器**。他人連接器與你的租戶不受影響。帳單仍保留於帳單紀錄。

事後補繳逾期帳單不會恢復已刪除連接器。若要再次使用 Console SSO，請[聯絡我們](https://logto.io/contact)結清暫停訂閱，然後新增連接器開啟新訂閱。

## 刪除連接器或帳號 \{#delete-connectors-or-your-account}

要刪除連接器，請從 Console SSO 頁面開啟並於選單中刪除。刪除最後一個連接器會如上所述取消訂閱。若訂閱逾期，請先支付未結帳單。

刪除 Logto Cloud 帳號前：

1. 刪除所有 Console SSO 連接器。
2. 確認所有訂閱已取消。
3. 支付所有未結帳單。

## 疑難排解 \{#troubleshooting}

<details>

<summary>

### 我已付款，但連接器沒出現 \{#i-paid-but-my-connector-didnt-appear}

</summary>

Logto 收到 Stripe 確認後會立即建立連接器，通常只需幾秒。請重新整理 Console SSO 頁面。若數分鐘後仍未出現，請[聯絡我們](https://logto.io/contact)，勿重複付款。若無法建立連接器，Logto 會自動取消訂閱並退款。

</details>

<details>

<summary>

### 新增連接器時要求我解決現有訂閱 \{#adding-a-connector-asks-me-to-resolve-my-current-subscription}

</summary>

現有 Console SSO 訂閱無法支援新連接器，通常因逾期付款而暫停。請[聯絡我們](https://logto.io/contact)結清後再新增連接器。

</details>

<details>

<summary>

### 建立連接器過程中失敗 \{#creating-a-connector-failed-partway}

</summary>

請在同一頁面重試：Logto 會繼續原連接器而非建立新連接器。若要放棄未完成的連接器，請選擇 **重新開始 (Start over)**。建立失敗不會取消訂閱或產生費用。

</details>

<details>

<summary>

### 我的網域一直無法驗證 \{#my-domain-stays-unverified}

</summary>

請確認 TXT 記錄名稱正確為 `_logto-cloud-sso.` 加上你的網域，且值與頁面權杖一致。DNS 變更可能需時間傳播。若頁面顯示該網域已綁定其他連接器，請先從其他連接器移除。

</details>
