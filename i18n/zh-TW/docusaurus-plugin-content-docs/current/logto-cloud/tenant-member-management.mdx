# 租戶成員管理 (Tenant member management)

## 邀請協作者 \{#invite-collaborators}

前往 <CloudLink to="/tenant-settings/members">控制台 > 租戶設定 > 成員</CloudLink>。你會看到目前的成員，並可邀請更多人。輸入電子郵件地址並指派角色（可批次操作），然後送出邀請。

Logto 允許你以兩種不同角色邀請團隊成員加入 Logto Cloud 的租戶：

- **管理員 (Admin)：** 擁有所有租戶資源的完整存取與管理權限。
- **協作者 (Collaborator)：** 可管理與身分相關的資源，但有以下限制：
  - 無法存取帳單資訊
  - 無法邀請或管理其他成員
  - 無法變更租戶名稱
  - 無法刪除租戶

### 成員數量限制 \{#members-limit}

| 租戶類型                              | 成員數量上限                            |
| ------------------------------------- | --------------------------------------- |
| 開發租戶 (Dev tenant)                 | 最多 3 位成員（如需更多請聯絡我們）     |
| 免費正式租戶 (Free production tenant) | 1 位成員（僅限管理員）                  |
| 專業正式租戶 (Pro production tenant)  | 含 1 位成員，超過後每位額外成員 $8 美元 |

### 管理邀請 \{#manage-invitation}

邀請分頁會顯示過去的邀請及其狀態

| 狀態              | 說明                       | 可用操作 |
| ----------------- | -------------------------- | -------- |
| 等待中 (Pending)  | 邀請已發送，但尚未被接受。 | 重新發送 |
| 已接受 (Accepted) | 使用者已成為租戶成員。     | 刪除     |
| 已過期 (Expired)  | 邀請超過 7 天期限。        | 刪除     |
| 已撤銷 (Revoked)  | 管理員已取消邀請。         | 刪除     |

你無法邀請已經有等待中邀請或已是成員的人。

### 管理租戶成員（僅限管理員）\{manage-tenant-members-admin-only} \{#manage-tenant-members-admin-only}

作為管理員，你可以用多種方式管理團隊：

- **邀請或移除成員：** 新增團隊成員或移除存取權。
- **變更成員角色：** 根據所需存取層級指派「管理員 (admin)」或「協作者 (collaborator)」角色。
- **轉移租戶擁有權：** 如有需要，可將租戶擁有權轉移給其他成員。你可以先將管理員角色給予其他成員，然後選擇繼續作為一般成員或完全離開租戶。
- **新增多位管理員：** 與其他團隊成員共同分擔管理責任，實現協作管理。
