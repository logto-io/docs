# 租戶成員管理

## 邀請協作者 \{#invite-collaborators}

前往 <CloudLink to="/tenant-settings/members">控制台 > 租戶設定 > 成員</CloudLink>。你會看到目前的成員，並可邀請更多人。輸入電子郵件地址並指派角色（可批次操作），然後發送邀請。

Logto 允許你以三種不同角色邀請團隊成員加入 Logto Cloud 的租戶：

- **管理員 (Admin)：** 完整存取租戶，包括成員與帳單管理。
- **協作者 (Collaborator)：** 可檢視與變更租戶資源，如應用程式、使用者、連接器與登入體驗，但無法管理成員或帳單。
- **檢視者 (Viewer)：** 可檢視租戶資源與成員，但無法變更。部分憑證對檢視者隱藏；詳見[檢視者無法看到的內容](#what-viewers-cannot-see)。

### 角色權限 \{#role-permissions}

| 操作                                                   | 管理員 (Admin) | 協作者 (Collaborator) | 檢視者 (Viewer) |
| ------------------------------------------------------ | -------------- | --------------------- | --------------- |
| 檢視租戶資源與成員                                     | ✅             | ✅                    | ✅              |
| 建立、變更與刪除租戶資源                               | ✅             | ✅                    | ❌              |
| 邀請與移除成員、變更其角色、檢視邀請                   | ✅             | ❌                    | ❌              |
| 重新命名或刪除租戶                                     | ✅             | ❌                    | ❌              |
| 將 Dev 租戶轉為正式環境                                | ✅             | ❌                    | ❌              |
| 在 **租戶設定 > 網域** 新增或移除租戶自訂網域          | ✅             | ❌                    | ❌              |
| 強制成員啟用 MFA                                       | ✅             | ❌                    | ❌              |
| 檢視 **方案與帳單**、**帳單紀錄** 分頁，升級或管理帳單 | ✅             | ❌                    | ❌              |
| [離開租戶](/logto-cloud/tenant-settings#leave-tenant)  | ✅             | ✅                    | ✅              |

在控制台中，檢視者會看到 **僅可檢視 (View only)** 標籤與橫幅。建立、儲存、刪除或測試的按鈕會隱藏，欄位皆為唯讀。

### 檢視者無法看到的內容 \{#what-viewers-cannot-see}

檢視者無法讀取可存取 Logto 租戶或其使用者的憑證：

- 應用程式密鑰
- 使用者的個人存取權杖 (personal access tokens)
- 一次性權杖 (one-time tokens)
- 使用者密碼雜湊值

在控制台中，應用程式密鑰與個人存取權杖會顯示為 **檢視者隱藏 (Hidden for viewers)**。

:::warning
檢視者仍可讀取租戶設定中的其他密鑰，例如連接器與企業級單一登入 (SSO) 連接器設定、CAPTCHA 密鑰、Webhook 簽章金鑰，以及自訂 JWT 腳本與 Actions 的環境變數。僅在你信任檢視者能接觸這些資訊時才邀請他們。
:::

### 成員數量限制 \{#members-limit}

| 租戶類型     | 成員數量上限                        |
| ------------ | ----------------------------------- |
| Dev 租戶     | 最多 3 位成員（如需更多請聯絡我們） |
| 免費正式租戶 | 1 位成員（僅限管理員）              |
| Pro 正式租戶 | 含 1 位成員，超過後每位額外 $8 美元 |

檢視者與其他成員一樣計入成員上限與每位成員的收費。

### 管理邀請 \{#manage-invitation}

邀請分頁會顯示過往邀請及其狀態

| 狀態   | 說明                       | 可用操作 |
| ------ | -------------------------- | -------- |
| 待接受 | 已發送邀請，但尚未被接受。 | 重新發送 |
| 已接受 | 使用者已成為租戶成員。     | 刪除     |
| 已過期 | 邀請超過 7 天期限。        | 刪除     |
| 已撤銷 | 管理員已取消邀請。         | 刪除     |

你無法邀請已經有待接受邀請或已是成員的人。

### 管理租戶成員（僅限管理員） \{#manage-tenant-members-admin-only}

作為管理員，你可以用多種方式管理團隊：

- **邀請或移除成員：** 新增團隊成員或移除存取權。
- **變更成員角色：** 根據所需存取層級指派「管理員」、「協作者」或「檢視者」角色。
- **轉移租戶擁有權：** 如有需要，可將租戶擁有權轉移給其他成員。你可以先將管理員角色給予他人，再選擇繼續作為一般成員或完全離開租戶。
- **新增多位管理員：** 與其他團隊成員共同分擔管理責任，協作管理租戶。
