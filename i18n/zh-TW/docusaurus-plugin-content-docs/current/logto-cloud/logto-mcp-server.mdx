# Logto MCP Server

Logto MCP Server 是一個遠端 [MCP (Model Context Protocol)](https://modelcontextprotocol.io/) 伺服器。將其 URL 加入你的 AI 應用程式，使用 Logto Cloud 帳號登入，即可開始與 Logto 對話。

:::tip
Logto MCP Server 以 Logto 與 [MCP Auth](https://mcp-auth.dev) 打造。如果你想自行建立遠端 MCP 伺服器，請參閱[建立你自己的遠端 MCP 伺服器](#build-your-own-remote-mcp-server)。
:::

## 你可以做什麼 \{#what-you-can-do}

- **為你的專案新增驗證 (Authentication)**：AI 會偵測你的框架，自動建立 Logto 應用程式並產生可用的整合程式碼。支援 38+ 種框架，包括 React、Next.js、Vue、Nuxt、SvelteKit、Express、Go、Python、iOS、Android、Flutter 等。
- **詢問 Logto 相關問題**：AI 會搜尋 Logto 文件並提供帶有來源的答案。

更多功能即將推出，包括登入體驗設定、RBAC 與權限管理最佳實踐指引、多租戶組織架構協助 B2B 應用程式建置等。

## 你的 AI 應用程式如何連接 \{#how-your-ai-application-connects}

Logto MCP Server 支援兩種方式讓 AI 應用程式在登入時識別自己。這兩種方式都不需要你在 Logto Cloud 預先建立任何內容。

- **僅使用伺服器 URL（推薦）**：大多數 AI 應用程式現已支援 [client ID metadata documents (CIMD)](/integrate-logto/third-party-applications/dynamic-apps)。應用程式會以其擁有的 URL 作為 client ID，Logto 會從該 URL 讀取應用程式名稱與 redirect URI。你只需輸入伺服器 URL `https://mcp.logto.io`。
- **靜態 client ID**：對於尚未支援 CIMD 的應用程式，請輸入公開 OAuth client ID `mcp-client`。此 client 可接受 loopback redirect URI（`http://localhost` 或 `http://127.0.0.1`，可搭配任意 port）。

如果你的應用程式同時支援兩種方式，請優先使用僅伺服器 URL。既有使用 `mcp-client` 的連線會繼續運作，無需重新連接。

當你僅用伺服器 URL 連接時，Logto Cloud 登入頁會顯示帶有應用程式名稱與 client ID URL 主機（如 `claude.ai` 或 `vscode.dev`）的使用者授權頁面 (consent screen)。授權前請確認主機名稱與你正在使用的應用程式相符。

## 在你的 AI 應用程式中設定 \{#set-up-in-your-ai-application}

### Amp \{#amp}

1. 在 [Amp](https://ampcode.com) 中，開啟 **Personal Settings** > **Integrations & MCP**，點擊 **Add MCP Server**。
2. 輸入名稱 `Logto MCP Server` 與伺服器 URL：`https://mcp.logto.io`。Amp 會自動偵測驗證方式。
3. 點擊 **Connect** 並依照 Amp 指示登入。
4. 使用你的 Logto Cloud 帳號登入並授權連接。

:::tip
若 Amp 長時間停留在 **Detecting Authentication**，請點擊 **Change** 並選擇 **OAuth**，以跳過自動驗證偵測。**Use Your Own OAuth App** 下的 **OAuth Client ID** 與 **OAuth Client Secret** 請保持空白，然後點擊 **Connect** 並依照登入指示操作。Amp 支援 CIMD，因此你無需註冊 OAuth app 或輸入 `mcp-client`。
:::

### Claude Code \{#claude-code}

```bash
claude mcp add --transport http logto https://mcp.logto.io
```

然後在 Claude Code 中執行 `/mcp`，選擇 `logto`，並依照瀏覽器登入流程以 Logto Cloud 帳號驗證 (Authentication)。你也可以在終端機執行 `claude mcp login logto`。

### Claude（網頁與桌面版） \{#claude-web-and-desktop}

1. 開啟 **Customize** > **Connectors**，點擊 **Add custom connector**。
2. 輸入名稱 `Logto MCP Server` 與遠端 MCP 伺服器 URL：`https://mcp.logto.io`。**Advanced settings** 下的 OAuth 設定保持空白，然後點擊 **Add**。
3. 在 **Connectors** 清單中找到 **Logto MCP Server**，點擊 **Connect**。
4. 你將被導向 Logto Cloud 登入頁。請使用 Logto Cloud 帳號登入並授權連接。

Connectors 會儲存於你的 Claude 帳號，在 Claude 網頁版與 Claude Desktop 均可使用。

### Codex \{#codex}

```bash
codex mcp add logto --url https://mcp.logto.io
codex mcp login logto
```

瀏覽器視窗會自動開啟。請使用 Logto Cloud 帳號登入以完成連接。ChatGPT 桌面應用、Codex CLI 與 Codex IDE 擴充套件會共用此設定。

### Cursor \{#cursor}

Cursor 尚未支援 CIMD，因此需使用靜態 client ID。

1. 開啟 **Customize** > **MCPs**，或編輯 `~/.cursor/mcp.json`（全域）或 `.cursor/mcp.json`（專案）。
2. 加入以下設定：

   ```json
   {
     "mcpServers": {
       "Logto": {
         "url": "https://mcp.logto.io",
         "auth": {
           "CLIENT_ID": "mcp-client",
           "scopes": ["mcp:all"]
         }
       }
     }
   }
   ```

3. 點擊伺服器旁的 **Connect**。Logto Cloud 登入頁會出現，請使用 Logto Cloud 帳號登入以完成連接。

請從 Cursor 桌面應用登入。Cursor 網頁版與 Cursor Agents 使用的 web callback 尚未支援。

### OpenCode \{#opencode}

1. 在你的 `opencode.json` 檔案中加入以下設定：

   ```json
   {
     "$schema": "https://opencode.ai/config.json",
     "mcp": {
       "Logto": {
         "enabled": true,
         "type": "remote",
         "url": "https://mcp.logto.io"
       }
     }
   }
   ```

2. 執行下列指令以驗證 (Authentication)：
   ```bash
   opencode mcp auth Logto
   ```
   注意 `Logto` 必須與設定檔中的 MCP 伺服器名稱一致。

瀏覽器視窗會自動開啟。請使用 Logto Cloud 帳號登入以授權並完成連接。

### VS Code \{#vs-code}

1. 開啟指令面板（`Command + Shift + P`），選擇 **MCP: Add Server...**。
2. 選擇 **HTTP** 作為伺服器類型。
3. 輸入 URL：`https://mcp.logto.io`。你可以選擇安裝到工作區以便更好地隔離與管理。
4. 當 VS Code 要求驗證時，請允許。你將被導向 Logto Cloud 登入頁，請使用 Logto Cloud 帳號登入以完成連接。

你也可以將伺服器加入 `.vscode/mcp.json` 或你的使用者 `mcp.json`：

```json
{
  "servers": {
    "logto": {
      "type": "http",
      "url": "https://mcp.logto.io"
    }
  }
}
```

### Windsurf \{#windsurf}

Windsurf 尚未記載 CIMD 支援，因此請搭配 [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) 並使用靜態 client ID。

1. 開啟指令面板（`Command + Shift + P`），選擇 **Windsurf: MCP Marketplace**。
2. 在 **Installed MCPs** 區塊，點擊右側設定圖示以開啟 MCP 設定檔。
3. 加入以下[設定](https://docs.windsurf.com/windsurf/cascade/mcp#mcp_config-json)：

   ```json
   {
     "mcpServers": {
       "Logto": {
         "command": "npx",
         "args": [
           "mcp-remote",
           "https://mcp.logto.io",
           "--allow-http",
           "--static-oauth-client-info",
           "{ \"client_id\": \"mcp-client\", \"scope\": \"mcp:all\" }",
           "--resource",
           "https://mcp.logto.io/"
         ]
       }
     }
   }
   ```

Logto Cloud 登入頁會自動出現。請使用 Logto Cloud 帳號登入以完成連接。

### 其他 MCP 客戶端 \{#other-mcp-clients}

Logto MCP Server 可搭配任何支援 OAuth 授權 (Authorization) 的 MCP 客戶端：

- **若你的客戶端支援 CIMD**：只需輸入 MCP 伺服器 URL `https://mcp.logto.io`，其餘資訊客戶端會自動從伺服器取得。
- **否則**：請使用以下設定。
  - **MCP 伺服器 URL：** `https://mcp.logto.io`
  - **OAuth client ID：** `mcp-client`（無需 client secret）
  - **Redirect URI：** loopback 位址，如 `http://localhost:<port>/callback`
  - **Resource：** `https://mcp.logto.io/`（如客戶端需要）
  - **Scope：** `mcp:all`（如客戶端需要）

Logto MCP Server 不支援 Dynamic Client Registration (DCR)。如果你是 AI 應用程式開發者，請[發佈 client ID metadata document](/integrate-logto/third-party-applications/dynamic-apps#publish-a-client-id-metadata-document) 以便應用程式無需在 Logto 進行任何設定即可連接。如無法發佈，請[聯絡我們](https://logto.io/contact)並提供你的應用程式資訊。

## 建立你自己的遠端 MCP 伺服器 \{#build-your-own-remote-mcp-server}

Logto MCP Server 以 Logto 與 [MCP Auth](https://mcp-auth.dev) 打造。如果你想建立具備驗證 (Authentication) 的遠端 MCP 伺服器，請參考以下資源：

- [Remote MCP server in action：AI 時代 SaaS 產品的新入口](https://blog.logto.io/remote-mcp-server-in-action)
- [加入我們的 Discord](https://discord.gg/fUQmaFyAam)：分享遠端 MCP 伺服器建置經驗與最佳實踐
- [MCP Auth](https://mcp-auth.dev)：一站式為你的 MCP 伺服器加入生產等級驗證 (Authentication) 能力，無需花費數週閱讀規範或手動串接。
