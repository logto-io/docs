# 管理使用者工作階段

使用者工作階段管理協助使用者與管理員檢視目前的登入狀態，並在需要時撤銷工作階段。

在 Logto 中，你可以透過三種常見方式管理工作階段：

- **Account API**：用於產品帳號設定頁的終端使用者自助服務。
- **Management API**：供管理員或客服工具管理任何使用者的工作階段。
- **管理主控台 (Admin Console)**：在 Logto Console 內直接進行操作，無需自建工具。

## 選擇合適的 API \{#choose-the-right-api}

| 情境                                        | 推薦 API       |
| ------------------------------------------- | -------------- |
| 讓已登入使用者管理自己的啟用工作階段        | Account API    |
| 讓管理員或客服團隊管理特定使用者的工作階段  | Management API |
| 讓營運人員直接在 Logto Console 管理工作階段 | Admin Console  |

## 檢視啟用中的工作階段 \{#view-active-sessions}

### Account API（自助服務）\{#account-api-self-service}

使用 Account API 的 session 端點列出目前使用者的啟用工作階段。

- 參考章節：[管理使用者工作階段](/end-user-flows/account-settings/by-account-api#manage-user-sessions)
- 端點：[`GET /api/my-account/sessions`](https://openapi.logto.io/operation/operation-getsessions)

在將此功能開放給終端使用者前，請確保已於 Account center 設定中啟用工作階段管理，且你的應用程式已請求所需的 Account API 權限範圍 (scope)。

### Management API（管理工具）\{#management-api-admin-tools}

當你的管理系統需要列出目標使用者的工作階段時，請使用 Management API。

- 參考章節：[使用者工作階段管理](/end-user-flows/account-settings/by-management-api#user-session-management)
- 端點：[`GET /api/users/{userId}/sessions`](https://openapi.logto.io/operation/operation-listusersessions)
- 可選詳細資訊端點：[`GET /api/users/{userId}/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-getusersession)

## 撤銷工作階段 \{#revoke-sessions}

### Account API（終端使用者撤銷自己的工作階段）\{#account-api-end-user-revokes-own-sessions}

終端使用者可從自己的工作階段清單中撤銷特定工作階段。

- 參考章節：[管理使用者工作階段](/end-user-flows/account-settings/by-account-api#manage-user-sessions)
- 端點：[`DELETE /api/my-account/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-deletesessionbyid)

針對敏感操作，Account API 的工作階段管理需使用者近期驗證後才能存取。詳見 [進階驗證 (Step-up authentication)](/end-user-flows/step-up-authentication#account-api-and-account-center)。

### Management API（管理員撤銷使用者工作階段）\{#management-api-admin-revokes-user-sessions}

管理員可依使用者 ID 與工作階段 ID 撤銷目標使用者的工作階段。

- 參考章節：[使用者工作階段管理](/end-user-flows/account-settings/by-management-api#user-session-management)
- 端點：[`DELETE /api/users/{userId}/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-deleteusersession)

## 管理主控台 (Admin Console) \{#admin-console}

若你的團隊直接於 Logto Console 管理使用者，可在使用者詳細頁檢視啟用工作階段並撤銷特定工作階段。

- 參考章節：[管理使用者啟用工作階段](/user-management/manage-users#manage-user-active-sessions)
