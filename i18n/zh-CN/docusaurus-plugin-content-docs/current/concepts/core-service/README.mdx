# 核心服务

## 简介 \{#introduction}

_核心服务_ 是用于关键 Logto 职责的单体服务。源代码位于 [`@logto/core`](https://github.com/logto-io/logto/tree/master/packages/core)。

:::note
_核心服务_ 和 _SDK core_ 是两个不同的概念。区别请参见 [SDK 约定](/developers/sdk-conventions)。
:::

为便于理解，我们将核心服务分为四个主要模块：

  <thead>
    <tr>
      <td>名称</td>
      <td>描述</td>
      <td>挂载路径</td>
    </tr>
  </thead>
  <tbody>
    <tr>

      <td>
        一个 <a href="https://openid.net/specs/openid-connect-core-1_0.html">OpenID Provider</a>。
      </td>
      <td>
        <code>/oidc</code>
      </td>
    </tr>
    <tr>
      <td>Logto API</td>
      <td>Management API、Experience API 和 Account API。</td>
      <td>
        <code>/api</code>
      </td>
    </tr>

      <td>

后端 API（包括 OIDC）构建在 `core` 包内，而前端代理依赖于 Logto monorepo 中相应的兄弟包。

## OIDC Provider \{#oidc-provider}

Logto 底层采用了优秀且通过认证的 [OpenID Connect](https://openid.net/connect/) 实现 [node-oidc-provider](https://github.com/panva/node-oidc-provider)。该 provider 挂载在 `/oidc`，你可以在 [packages/core/src/oidc](https://github.com/logto-io/logto/tree/master/packages/core/src/oidc) 查看相关配置和文件。

OIDC 的 [Userinfo Endpoint](https://openid.net/specs/openid-connect-core-1_0.html#UserInfo) 可用，并挂载在 `/oidc/me`。

:::info
如果你想直接调用 OIDC API，请记得设置请求头 `Content-Type: application/x-www-form-urlencoded`。
:::

## Logto API \{#logto-api}

### Management API \{#management-api}

_Management API_ 是一组用于管理和更新 Logto 数据的 API。只有拥有 `admin` 角色的用户才能访问。

前往 [API 参考](https://openapi.logto.io) 查看详情。

如需以编程方式访问 API，请参见 [与 Management API 交互](/integrate-logto/interact-with-management-api)。

### Experience API \{#experience-api}

Experience API 是一组专门支持自定义登录界面交互的端点。

这些 API 使开发者能够实现核心认证 (Authentication) 功能，包括登录、注册、重置密码、社交账号绑定和多因素认证 (MFA)。要实现这些功能，你的自定义 UI 需要与 Experience API 交互。

想要更好地理解用户流程和实现细节：

- 查看 [开发你的自定义 UI](/customization/bring-your-ui/#develop-your-custom-ui) 指南，学习如何使用 Experience API 构建自定义体验 UI
- 参考 [Experience API 参考文档](https://openapi.logto.io/group/endpoint-experience) 获取详细 API 文档
- 阅读 [Experience API 设计 RFC](https://github.com/logto-io/rfcs/blob/master/draft/0004-experience-api.md) 了解深入的技术规范和示例

### Account API \{#account-api}

Account API 是一套全面的 API，允许终端用户直接访问 API，无需经过 Management API，主要亮点如下：

- 直接访问：Account API 让终端用户可以直接访问和管理自己的账户资料，无需通过 Management API 中转。
- 用户资料与身份管理：用户可以管理自己的资料和安全设置，包括邮箱、手机号、密码、社交连接和 MFA 因素，并可获取关联社交和企业 SSO 连接的 Secret Vault 令牌。
- 全局访问控制：管理员拥有对访问设置的完全全局控制，可自定义每个字段。
- 无缝授权 (Authorization)：授权 (Authorization) 变得前所未有的简单！只需使用 `client.getAccessToken()` 获取 OP (Logto) 的不透明令牌 (Opaque token)，并将其作为 `Bearer <access_token>` 附加到 Authorization 头中。

通过 Logto Account API，你可以构建一个与 Logto 完全集成的自定义账户管理系统，如个人资料页。

查看 [通过 Account API 管理账户设置](/end-user-flows/account-settings/by-account-api) 学习如何利用 Account API 构建你自己的账户设置页面。

参考 [Account API 参考文档](https://openapi.logto.io/group/endpoint-my-account) 获取详细 API 文档。

## 前端代理 \{#frontend-proxies}

_前端代理_ 是一种中间件函数，根据环境为前端项目提供服务：

- 开发环境下，将 HTTP 请求代理到前端开发服务器。
- 生产环境下，直接提供静态前端文件。
