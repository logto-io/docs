# 租户成员管理

## 邀请协作者 \{#invite-collaborators}

前往 <CloudLink to="/tenant-settings/members">控制台 > 租户设置 > 成员</CloudLink>。你会看到当前的成员，并可以邀请更多成员。输入邮箱地址并分配角色（支持批量操作），然后发送邀请。

Logto 允许你以三种不同的角色邀请团队成员加入你的 Logto Cloud 租户：

- **管理员 (Admin)：** 对租户拥有完全访问权限，包括成员和账单管理。
- **协作者 (Collaborator)：** 可以查看和更改租户的资源，如应用程序、用户、连接器和登录体验，但不能管理成员或账单。
- **查看者 (Viewer)：** 可以查看租户的资源和成员，但不能更改它们。一些凭证对查看者隐藏；详见 [查看者无法看到的内容](#what-viewers-cannot-see)。

### 角色权限 \{#role-permissions}

| 操作                                                       | 管理员 (Admin) | 协作者 (Collaborator) | 查看者 (Viewer) |
| ---------------------------------------------------------- | -------------- | --------------------- | --------------- |
| 查看租户的资源和成员                                       | ✅             | ✅                    | ✅              |
| 创建、更改和删除租户的资源                                 | ✅             | ✅                    | ❌              |
| 邀请和移除成员、更改其角色、查看邀请                       | ✅             | ❌                    | ❌              |
| 重命名或删除租户                                           | ✅             | ❌                    | ❌              |
| 将开发租户转换为生产租户                                   | ✅             | ❌                    | ❌              |
| 在 **租户设置 > 域名** 中添加或移除租户的自定义域名        | ✅             | ❌                    | ❌              |
| 要求成员启用多因素认证 (MFA)                               | ✅             | ❌                    | ❌              |
| 查看 **套餐与账单** 和 **账单历史** 标签页，升级或管理账单 | ✅             | ❌                    | ❌              |
| [离开租户](/logto-cloud/tenant-settings#leave-tenant)      | ✅             | ✅                    | ✅              |

在控制台中，查看者会看到 **仅可查看** 标签和横幅。创建、保存、删除或测试的按钮会被隐藏，字段为只读。

### 查看者无法看到的内容 \{#what-viewers-cannot-see}

查看者无法读取授予你 Logto 租户或其用户访问权限的凭证：

- 应用程序密钥
- 用户的个人访问令牌
- 一次性令牌
- 用户密码哈希

在控制台中，应用程序密钥和个人访问令牌会显示为 **对查看者隐藏**。

:::warning
查看者仍然可以读取你租户设置中的其他密钥，例如连接器和企业单点登录 (SSO) 连接器配置中的密钥、验证码 (CAPTCHA) 密钥、Webhook 签名密钥、自定义 JWT 脚本和 Actions 的环境变量。只有在你信任他们可以访问这些内容时，才邀请其为查看者。
:::

### 成员数量限制 \{#members-limit}

| 租户类型     | 成员数量限制                        |
| ------------ | ----------------------------------- |
| 开发租户     | 最多 3 名成员（如需更多请联系我们） |
| 免费生产租户 | 1 名成员（仅限管理员）              |
| 专业生产租户 | 包含 1 名成员，超出后每增加 1 名 $8 |

查看者和其他成员一样计入成员数量和单成员价格。

### 管理邀请 \{#manage-invitation}

邀请标签页会显示历史邀请及其状态

| 状态   | 说明                       | 可用操作 |
| ------ | -------------------------- | -------- |
| 待接受 | 邀请已发送，但尚未被接受。 | 重新发送 |
| 已接受 | 用户已成为租户成员。       | 删除     |
| 已过期 | 邀请超过 7 天有效期。      | 删除     |
| 已撤销 | 管理员取消了邀请。         | 删除     |

你无法邀请已经有待接受邀请或已是成员的人。

### 管理租户成员（仅限管理员） \{#manage-tenant-members-admin-only}

作为管理员，你可以通过多种方式管理你的团队：

- **邀请或移除成员：** 根据需要添加新成员或移除访问权限。
- **更改成员角色：** 根据所需访问级别分配“管理员 (admin)”、“协作者 (collaborator)”或“查看者 (viewer)”角色。
- **转移租户所有权：** 如有需要，你可以将租户所有权转移给其他成员。你可以先将管理员角色赋予其他成员，然后选择作为普通成员保留或完全离开租户。
- **添加多个管理员：** 与其他团队成员共享管理权限，实现协作管理。
