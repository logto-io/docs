# 租户成员管理

## 邀请协作者 \{#invite-collaborators}

前往 <CloudLink to="/tenant-settings/members">控制台 > 租户设置 > 成员</CloudLink>。你会看到当前成员，并可以邀请更多成员。输入邮箱地址并分配角色（支持批量操作），然后发送邀请。

Logto 允许你以两种不同的角色邀请团队成员加入你的 Logto Cloud 租户：

- **管理员 (Admin)：** 拥有所有租户资源的完全访问和管理权限。
- **协作者 (Collaborator)：** 可以管理与身份相关的资源，但有以下限制：
  - 无法访问账单信息
  - 无法邀请或管理其他成员
  - 无法更改租户名称
  - 无法删除租户

### 成员数量限制 \{#members-limit}

| 租户类型     | 成员数量限制                            |
| ------------ | --------------------------------------- |
| 开发租户     | 最多 3 名成员（如需更多请联系我们）     |
| 免费生产租户 | 1 名成员（仅限管理员）                  |
| 专业生产租户 | 包含 1 名成员，超出后每增加 1 名成员 $8 |

### 管理邀请 \{#manage-invitation}

邀请标签页会显示过往邀请及其状态

| 状态   | 说明                       | 可用操作 |
| ------ | -------------------------- | -------- |
| 待接受 | 邀请已发送，但尚未被接受。 | 重新发送 |
| 已接受 | 用户已成为租户成员。       | 删除     |
| 已过期 | 邀请超过 7 天有效期。      | 删除     |
| 已撤销 | 管理员取消了邀请。         | 删除     |

你无法邀请已经有待接受邀请或已是成员的人。

### 管理租户成员（仅限管理员）\{manage-tenant-members-admin-only} \{#manage-tenant-members-admin-only}

作为管理员，你可以通过多种方式管理你的团队：

- **邀请或移除成员：** 根据需要添加新团队成员或移除访问权限。
- **更改成员角色：** 根据所需访问级别分配“管理员 (admin)”或“协作者 (collaborator)”角色。
- **转移租户所有权：** 如有需要，你可以将租户所有权转移给其他成员。你可以先将管理员角色赋予其他成员，然后选择作为普通成员留在租户中或完全离开租户。
- **添加多个管理员：** 与其他团队成员共享管理职责，实现协作管理。
