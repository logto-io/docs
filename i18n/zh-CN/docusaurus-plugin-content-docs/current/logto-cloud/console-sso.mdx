# 控制台单点登录 (Console SSO)

控制台单点登录 (Console SSO) 允许你的团队使用公司身份提供商 (IdP)（如 Microsoft Entra ID、Okta 或 Google Workspace）登录 <Url href="https://cloud.logto.io">Logto Cloud 控制台</Url>。你验证过邮箱域名的成员在登录 Logto Cloud 时会被重定向到你的 IdP。

控制台单点登录 (Console SSO) 仅覆盖登录 Logto Cloud 本身。要让**你自己的用户**通过他们公司的 IdP 登录**你的应用程序**，请在你的租户中使用 [企业单点登录 (SSO)](/connectors/enterprise-connectors)。

## 控制台单点登录 (Console SSO) 的工作原理 \{#how-console-sso-works}

- **它属于你的账户，而不是租户。** 控制台单点登录 (Console SSO) 连接器归创建它的 Logto Cloud 账户所有，只有该账户可以管理它。租户套餐、降级和租户删除不会影响它。
- **它不会授予租户访问权限。** 使用 SSO 登录只证明了某人的身份。他们仍然需要邀请或成员资格才能打开租户。参见 [租户成员管理](/logto-cloud/tenant-member-management)。
- **它按账户计费。** 连接器按连接器数量通过你自己的订阅单独计费，与任何租户套餐分开。参见 [价格与计费](#pricing-and-billing)。

## 设置控制台单点登录 (Console SSO) \{#set-up-console-sso}

### 创建连接器 \{#create-a-connector}

1. 在 Logto Cloud 控制台，打开右上角的用户菜单并选择 **单点登录 (Single sign-on)**。<Url href="https://cloud.logto.io/console-sso">控制台单点登录 (Console SSO)</Url> 页面将在新标签页打开。
2. 点击 **添加连接器 (Add connector)** 并选择你的身份提供商。
3. 对于你的第一个连接器，选择一个计费账户并在 Stripe Checkout 完成付款。后续连接器会自动加入同一订阅，无需再次结账。
4. 连接器会在其配置页面打开。

### 配置连接 \{#configure-the-connection}

在 **连接 (Connection)** 标签页，输入来自你 IdP 的配置信息。字段与租户中的 [企业单点登录 (SSO) 连接器](/connectors/enterprise-connectors) 相同：

- **OIDC**：在你的 IdP 注册页面显示的 **重定向 URI (Redirect URI)**，然后填写发行者 (Issuer)、client ID 和 client secret。
- **SAML**：将页面显示的服务提供方元数据提供给你的 IdP，然后填写你 IdP 的元数据。

在 **SSO 体验 (SSO Experience)** 标签页，你可以更改登录页面上显示的名称。

### 验证你的邮箱域名 \{#verify-your-email-domains}

控制台单点登录 (Console SSO) 仅适用于你证明拥有的邮箱域名。

1. 在 **SSO 体验 (SSO Experience)** 标签页，输入一个域名，如 `example.com`，并点击 **添加域名 (Add domain)**。
2. 在你的 DNS 服务商处添加如下 TXT 记录：

   | Type | Name                           | Value          |
   | ---- | ------------------------------ | -------------- |
   | TXT  | `_logto-cloud-sso.example.com` | 页面显示的令牌 |

3. 保持页面上的域名处于打开状态。Logto 每 10 秒检查一次记录。一旦找到记录，该域名会绑定到连接器并标记为 **已绑定 (Bound)**。此后你可以移除 TXT 记录。

一个域名只能绑定到一个控制台单点登录 (Console SSO) 连接器。移除已绑定域名会停止该域名邮箱地址的 SSO。重新添加需要再次验证。

:::note
计费不会等待此步骤。连接器自创建之时起开始计费，无论其连接设置或域名是否配置完成。
:::

### 使用 SSO 登录 \{#sign-in-with-sso}

在 Logto Cloud 登录页面，成员输入他们的工作邮箱。如果其域名已绑定到连接器，他们会被重定向到你的 IdP 进行登录。

## 价格与计费 \{#pricing-and-billing}

每个连接器费用为 **每月 128 美元**，另加适用税费。你的账户有一个控制台单点登录 (Console SSO) 订阅，其数量为连接器数量。

| 你的操作                         | 结果                                                               |
| -------------------------------- | ------------------------------------------------------------------ |
| 添加第一个连接器                 | 你在 Stripe Checkout 支付首月费用。付款日期成为你的月度账单日。    |
| 添加另一个连接器                 | 立即添加。剩余当月的按比例费用会计入你的下一个账单。               |
| 删除一个连接器（还有其他连接器） | 未用时间的按比例抵扣会计入你的下一个账单，但不会退还到你的银行卡。 |
| 删除最后一个连接器               | 订阅立即取消。如果当月已付费，未用时间会退还到你的支付方式。       |
| 取消后再次添加连接器             | 通过 Stripe Checkout 开启新订阅，并有新的账单日。                  |

编辑连接器的设置或域名不会影响你的费用。

### 账单示例 \{#example-invoice}

以下数据假设每月 30 天且不含税。实际按比例费用精确到秒计算。

| 日期     | 操作                           | 连接器数量 | 影响                                             |
| -------- | ------------------------------ | ---------- | ------------------------------------------------ |
| 11月1日  | 添加第一个连接器               | 1          | 结账时支付：**$128.00**。账单日为每月1日。       |
| 11月16日 | 添加第二个连接器（剩余15天）   | 2          | +$128 × 15/30 = +$64.00 计入下一个账单           |
| 11月25日 | 删除一个连接器（剩余6天）      | 1          | −$128 × 6/30 = −$25.60 计入下一个账单            |
| 12月1日  | 月度账单                       | 1          | 12月费用 $128.00 + $64.00 − $25.60 = **$166.40** |
| 12月16日 | 删除最后一个连接器（剩余15天） | 0          | 订阅取消；**$64.00** 退还                        |

### 订阅与账单历史 \{#subscription-and-billing-history}

在控制台顶部栏打开 **订阅 (Subscription)**。无论选择哪个租户，都能看到你账户的所有订阅。

- **订阅 (Subscription)** 显示你当前的订阅、价格、下次扣费和账单日。使用 **管理支付 (Manage payment)** 可更新支付方式或支付未结账单。
- **账单历史 (Billing history)** 显示你的所有账单，包括已取消订阅的账单。选择账单可查看并下载发票或收据。

### 欠费处理 \{#overdue-payments}

如果支付失败，Stripe 会重试，订阅会被标记为 **逾期 (Past due)**。你的连接器仍可使用，但请通过 **管理支付 (Manage payment)** 更新支付方式。

如果**连续三个月账单**均未支付且所有重试失败，Logto 会暂停订阅并**删除所有该订阅下的连接器**。其他人的连接器和你的租户不会受影响。你的账单仍保留在账单历史中。

之后支付逾期账单不会恢复已删除的连接器。如需再次使用控制台单点登录 (Console SSO)，请[联系我们](https://logto.io/contact)结清暂停的订阅，然后添加连接器开启新订阅。

## 删除连接器或账户 \{#delete-connectors-or-your-account}

要删除连接器，请在控制台单点登录 (Console SSO) 页面打开并在其菜单中删除。删除最后一个连接器会如上所述取消订阅。如果订阅逾期，请先支付未结账单。

在你删除 Logto Cloud 账户前：

1. 删除你所有的控制台单点登录 (Console SSO) 连接器。
2. 确认你的订阅已取消。
3. 支付所有未结账单。

## 故障排查 \{#troubleshooting}

<details>

<summary>

### 我已付款，但连接器没有出现 \{#i-paid-but-my-connector-didnt-appear}

</summary>

Logto 在收到 Stripe 确认后立即创建连接器，通常只需几秒。请刷新控制台单点登录 (Console SSO) 页面。如果几分钟后仍未出现，请[联系我们](https://logto.io/contact)，不要重复付款。如果连接器无法创建，Logto 会自动取消订阅并退款。

</details>

<details>

<summary>

### 添加连接器时提示我解决当前订阅问题 \{#adding-a-connector-asks-me-to-resolve-my-current-subscription}

</summary>

你现有的控制台单点登录 (Console SSO) 订阅无法为新连接器提供资金，通常是因为逾期后被暂停。请[联系我们](https://logto.io/contact)结清后再添加连接器。

</details>

<details>

<summary>

### 创建连接器过程中失败 \{#creating-a-connector-failed-partway}

</summary>

请在同一页面重试：Logto 会继续创建同一个连接器，而不是新建一个。如需放弃未完成的连接器，请选择 **重新开始 (Start over)**。创建失败不会取消你的订阅或扣费。

</details>

<details>

<summary>

### 我的域名一直未验证通过 \{#my-domain-stays-unverified}

</summary>

请检查 TXT 记录名称是否为 `_logto-cloud-sso.` 加你的域名，且值与页面令牌一致。DNS 变更可能需要时间生效。如果页面提示该域名已绑定到其他连接器，请先从其他连接器移除。

</details>
