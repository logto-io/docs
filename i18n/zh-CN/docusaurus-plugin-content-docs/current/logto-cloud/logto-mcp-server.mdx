# Logto MCP Server

Logto MCP Server 是一个远程 [MCP (Model Context Protocol)](https://modelcontextprotocol.io/) 服务器。将该 URL 添加到你的 AI 应用中，使用你的 Logto Cloud 账户登录，然后开始与 Logto 对话。

:::tip
Logto MCP Server 基于 Logto 和 [MCP Auth](https://mcp-auth.dev) 构建。如果你想搭建自己的远程 MCP 服务器，请参阅 [构建你自己的远程 MCP 服务器](#build-your-own-remote-mcp-server)。
:::

## 你可以做什么 \{#what-you-can-do}

- **为你的项目添加认证 (Authentication)**：AI 会检测你的框架，创建一个 Logto 应用，并生成可用的集成代码。支持 38+ 种框架，包括 React、Next.js、Vue、Nuxt、SvelteKit、Express、Go、Python、iOS、Android、Flutter 等。
- **咨询 Logto 相关问题**：AI 会检索 Logto 文档，并为你提供带有来源的答案。

更多功能即将上线，包括登录体验配置、基于角色的访问控制 (RBAC) 和权限管理最佳实践指导、多租户组织的 B2B 应用搭建等。

## 你的 AI 应用如何连接 \{#how-your-ai-application-connects}

Logto MCP Server 支持两种方式让 AI 应用在你登录时识别自身。你无需在 Logto Cloud 中创建任何内容。

- **仅服务器 URL（推荐）**：大多数 AI 应用现在支持 [client ID metadata documents (CIMD)](/integrate-logto/third-party-applications/dynamic-apps)。应用使用其拥有的 URL 作为 client ID，Logto 会从该 URL 读取应用名称和重定向 URI。你只需输入服务器 URL `https://mcp.logto.io`。
- **静态 client ID**：对于尚未支持 CIMD 的应用，输入公共 OAuth client ID `mcp-client`。该 client 支持 loopback 重定向 URI（`http://localhost` 或 `http://127.0.0.1`，端口任意）。

如果你的应用同时支持两种方式，优先使用仅服务器 URL。已使用 `mcp-client` 的现有连接会继续有效，无需重新连接。

当你仅用服务器 URL 连接时，Logto Cloud 登录页会显示带有应用名称和 client ID URL 主机名的用户授权页面（Consent screen），如 `claude.ai` 或 `vscode.dev`。在授权前请确认主机名与你正在使用的应用一致。

## 在你的 AI 应用中设置 \{#set-up-in-your-ai-application}

### Claude Code \{#claude-code}

```bash
claude mcp add --transport http logto https://mcp.logto.io
```

然后，在 Claude Code 中运行 `/mcp`，选择 `logto`，并按照浏览器登录流程使用你的 Logto Cloud 账户进行认证 (Authentication)。你也可以在终端运行 `claude mcp login logto`。

### Claude（网页和桌面端） \{#claude-web-and-desktop}

1. 打开 **Customize** > **Connectors** 并点击 **Add custom connector**。
2. 输入名称 `Logto MCP Server` 和远程 MCP 服务器 URL：`https://mcp.logto.io`。**Advanced settings** 下的 OAuth 设置保持为空，点击 **Add**。
3. 在 **Connectors** 列表中找到 **Logto MCP Server** 并点击 **Connect**。
4. 你将被重定向到 Logto Cloud 登录页。使用你的 Logto Cloud 账户登录并授权连接。

连接器会保存到你的 Claude 账户，因此在 Claude 网页端和 Claude Desktop 都可用。

### Codex \{#codex}

```bash
codex mcp add logto --url https://mcp.logto.io
codex mcp login logto
```

浏览器窗口会自动打开。使用你的 Logto Cloud 账户登录以完成连接。ChatGPT 桌面应用、Codex CLI 和 Codex IDE 扩展会共享此配置。

### Cursor \{#cursor}

Cursor 目前尚不支持 CIMD，因此使用静态 client ID。

1. 打开 **Customize** > **MCPs**，或打开 `~/.cursor/mcp.json`（全局）或 `.cursor/mcp.json`（项目）。
2. 添加如下配置：

   ```json
   {
     "mcpServers": {
       "Logto": {
         "url": "https://mcp.logto.io",
         "auth": {
           "CLIENT_ID": "mcp-client",
           "scopes": ["mcp:all"]
         }
       }
     }
   }
   ```

3. 在服务器旁点击 **Connect**。Logto Cloud 登录页会弹出。使用你的 Logto Cloud 账户登录以完成连接。

请在 Cursor 桌面端登录。Cursor 网页端和 Cursor Agents 使用的 web 回调暂不支持。

### OpenCode \{#opencode}

1. 在你的 `opencode.json` 文件中添加如下配置：

   ```json
   {
     "$schema": "https://opencode.ai/config.json",
     "mcp": {
       "Logto": {
         "enabled": true,
         "type": "remote",
         "url": "https://mcp.logto.io"
       }
     }
   }
   ```

2. 运行以下命令进行认证 (Authentication)：
   ```bash
   opencode mcp auth Logto
   ```
   注意 `Logto` 要与配置文件中的 MCP 服务器名称一致。

浏览器窗口会自动打开。使用你的 Logto Cloud 账户登录以授权并连接。

### VS Code \{#vs-code}

1. 打开命令面板（`Command + Shift + P`），选择 **MCP: Add Server...**。
2. 选择 **HTTP** 作为服务器类型。
3. 输入 URL：`https://mcp.logto.io`。你可以选择安装到工作区以便更好地隔离和管理。
4. 当 VS Code 请求认证 (Authentication) 时，允许即可。你将被重定向到 Logto Cloud 登录页。使用你的 Logto Cloud 账户登录以完成连接。

或者，将服务器添加到 `.vscode/mcp.json` 或你的用户 `mcp.json`：

```json
{
  "servers": {
    "logto": {
      "type": "http",
      "url": "https://mcp.logto.io"
    }
  }
}
```

### Windsurf \{#windsurf}

Windsurf 未注明 CIMD 支持，因此请使用 [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) 并配合静态 client ID。

1. 打开命令面板（`Command + Shift + P`），选择 **Windsurf: MCP Marketplace**。
2. 在 **Installed MCPs** 区域，点击右侧设置图标以打开 MCP 配置文件。
3. 添加如下[配置](https://docs.windsurf.com/windsurf/cascade/mcp#mcp_config-json)：

   ```json
   {
     "mcpServers": {
       "Logto": {
         "command": "npx",
         "args": [
           "mcp-remote",
           "https://mcp.logto.io",
           "--allow-http",
           "--static-oauth-client-info",
           "{ \"client_id\": \"mcp-client\", \"scope\": \"mcp:all\" }",
           "--resource",
           "https://mcp.logto.io/"
         ]
       }
     }
   }
   ```

Logto Cloud 登录页会自动弹出。使用你的 Logto Cloud 账户登录以完成连接。

### 其他 MCP 客户端 \{#other-mcp-clients}

Logto MCP Server 可与任何支持 OAuth 授权 (Authorization) 的 MCP 客户端配合使用：

- **如果你的客户端支持 CIMD**：只需输入 MCP 服务器 URL `https://mcp.logto.io`。客户端会自动从服务器获取其他信息。
- **否则**：请使用以下配置。
  - **MCP 服务器 URL：** `https://mcp.logto.io`
  - **OAuth client ID：** `mcp-client`（无需 client secret）
  - **重定向 URI：** loopback 地址，如 `http://localhost:<port>/callback`
  - **Resource：** `https://mcp.logto.io/`（如客户端需要）
  - **Scope：** `mcp:all`（如客户端需要）

Logto MCP Server 不支持动态客户端注册 (DCR)。如果你是 AI 应用开发者，请为你的应用 [发布 client ID metadata document](/integrate-logto/third-party-applications/dynamic-apps#publish-a-client-id-metadata-document)，这样无需在 Logto 进行任何设置即可连接。如果无法实现，请[联系我们](https://logto.io/contact)并提供你的应用信息。
