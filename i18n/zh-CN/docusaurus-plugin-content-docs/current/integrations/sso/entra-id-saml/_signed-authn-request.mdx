Microsoft Entra ID 可以要求对 SAML 认证请求 (Authentication request) 进行签名。要在 Logto 中使用此功能，请按照以下顺序操作，以避免任何登录中断：

1. 在 Logto 连接器的 `Connection` 选项卡下，点击 **生成新密钥**（**Generate new key**）位于 **请求签名证书**（**Request signing certificate**）下，并下载当前激活密钥的证书。
2. 在 Entra ID 应用的单点登录 (SSO) 设置中，将证书上传到 **验证证书**（**Verification certificates**）下。参见 [强制执行已签名的 SAML 认证请求 (Authentication request)](https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/howto-enforce-signed-saml-authentication)。
3. 返回 Logto，在连接器上启用 **签名认证请求 (Authentication request)**（**Sign authentication request**），并保存。
4. 在 Entra ID 中，勾选 **要求验证证书**（**Require verification certificates**），然后测试登录流程。

Entra ID 只验证使用 RSA-SHA256（Logto 的默认算法）签名的请求，并且只对由服务提供方 (SP) 发起的登录请求强制执行该要求。完整的设置和证书轮换流程，请参见 [对 SAML 认证请求 (Authentication request) 进行签名](https://docs.logto.io/integrations/saml-sso#optional-sign-the-saml-authentication-request)。
