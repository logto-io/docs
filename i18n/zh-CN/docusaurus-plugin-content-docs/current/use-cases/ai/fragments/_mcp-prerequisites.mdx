## 前置条件 \{#prerequisites}

- 一个 [Logto Cloud](https://cloud.logto.io)（或自托管）租户
- Node.js >= 20 环境

### 理解架构 \{#understanding-the-architecture}

- **MCP 服务器**：向 MCP 客户端暴露工具和资源的服务器。遵循[最新 MCP 规范](https://modelcontextprotocol.io/specification/latest/basic/authorization)，它作为 OAuth 2.0 资源服务器，验证由 Logto 签发的访问令牌 (Access token)。
- **MCP 客户端**：用于发起认证 (Authentication) 流程并测试集成的客户端。{<b>{props.isThirdParty ? '在本指南中，第三方 AI agent 将作为客户端使用。' : "在本指南中，我们将使用 VS Code（内置 MCP 支持）作为客户端。"} </b>}
- **Logto**：作为 OpenID Connect 提供方（授权 (Authorization) 服务器），管理用户身份，并为你的 MCP 服务器签发受受众 (Audience) 绑定的 JWT 访问令牌 (Access token)。
