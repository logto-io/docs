:::info[示例代码]
本指南的完整可运行示例代码可在 [mcp-auth/js](https://github.com/mcp-auth/js/tree/master/packages/sample-servers) 仓库中找到：

- [`whoami-express`](https://github.com/mcp-auth/js/tree/master/packages/sample-servers/src/whoami-express)：本指南中的 "whoami" 服务器，基于 Node.js 和 Express。
- [`whoami`](https://github.com/mcp-auth/js/tree/master/packages/sample-servers/src/whoami)：同样的服务器，基于 fetch-native（Web 标准的 `Request` / `Response`，使用 [Hono](https://hono.dev)），可部署到 Cloudflare Workers。

:::
