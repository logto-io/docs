:::note
Logto Android SDK 支持的最低 Android API 级别为 24。
:::

Logto Android SDK 有两个主要版本：

- **v3**：在 [Chrome Custom Tabs](https://developer.android.com/develop/ui/views/layout/webapps/overview-of-android-custom-tabs)（系统浏览器）中打开登录体验，这样可以实现密钥登录（passkey sign-in）并共享浏览器会话。请注意，v3 移除了对 <MainSiteUrl href="/integrations/wechat-native">微信（原生）</MainSiteUrl> 和 <MainSiteUrl href="/integrations/alipay-native">支付宝（原生）</MainSiteUrl> 连接器的支持；你可以改用 <MainSiteUrl href="/integrations/wechat-web">微信（Web）</MainSiteUrl> 和 <MainSiteUrl href="/integrations/alipay-web">支付宝（Web）</MainSiteUrl>，它们通过浏览器工作。如果你依赖原生连接器，请继续使用 v2。
- **v2**：在嵌入式 WebView 中打开登录体验，这是原生社交连接器所需的，但不支持 <MainSiteUrl href="/end-user-flows/sign-up-and-sign-in/passkey-sign-in">密钥登录（passkey sign-in）</MainSiteUrl>（WebView 不支持 WebAuthn，即密钥的底层标准）。

本指南涵盖了这两个版本。请在下方标签中选择你的版本，选择将在本指南中保持同步。

在安装 Logto Android SDK 之前，请确保在 Gradle 项目构建文件的仓库配置中添加了 `mavenCentral()`：

```kotlin title="settings.gradle.kts"
dependencyResolutionManagement {
  repositories {
    mavenCentral()
  }
}
```

由于 SDK 需要访问互联网，你需要在 `AndroidManifest.xml` 文件中添加以下权限：

```xml title="AndroidManifest.xml"
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
  xmlns:tools="http://schemas.android.com/tools">

  <!-- 添加网络权限 -->
  <uses-permission android:name="android.permission.INTERNET" />

  <!-- 其他配置... -->
</manifest>
```
