通过创建一个带有 `LogtoConfig` 对象的 `LogtoClient` 实例来初始化客户端。

```swift title="ContentView.swift"
import Logto
import LogtoClient

let config = try! LogtoConfig(
  endpoint: "<your-logto-endpoint>", // 例如 http://localhost:3001
  appId: "<your-app-id>"
)
let client = LogtoClient(useConfig: config)
```

:::info

默认情况下，我们会将 ID 令牌 (ID token) 和刷新令牌 (Refresh token) 等凭证存储在 Keychain 中。因此，用户在返回时无需再次登录。

如果你想关闭此行为，可以将 `usingPersistStorage` 设置为 `false`：

```swift
let config = try! LogtoConfig(
  // ...
  usingPersistStorage: false
)
```

:::
