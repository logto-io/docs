# 管理用户会话

用户会话管理帮助用户和管理员查看活跃的登录状态，并在需要时撤销会话。

在 Logto 中，你可以通过三种常见路径管理会话：

- **Account API**：用于产品账户设置页面的终端用户自助服务。
- **Management API**：用于管理员或支持工具管理任意用户的会话。
- **Admin Console**：用于 Logto 控制台中的运营工作流，无需自定义工具。

## 选择合适的 API \{#choose-the-right-api}

| 场景                                  | 推荐 API       |
| ------------------------------------- | -------------- |
| 让已登录用户管理自己的活跃会话        | Account API    |
| 让管理员或支持团队管理某个用户的会话  | Management API |
| 让运营人员直接在 Logto 控制台管理会话 | Admin Console  |

## 查看活跃会话 \{#view-active-sessions}

### Account API（自助服务） \{#account-api-self-service}

使用 Account API 的会话端点列出当前用户的活跃会话。

- 参考章节：[管理用户会话](/end-user-flows/account-settings/by-account-api#manage-user-sessions)
- 端点：[`GET /api/my-account/sessions`](https://openapi.logto.io/operation/operation-getsessions)

在向终端用户开放此功能前，请确保已在 Account center 设置中启用会话管理，并且你的应用已请求所需的 Account API 权限 (Scope)。

### Management API（管理员工具） \{#management-api-admin-tools}

当你的管理系统需要为目标用户列出会话时，使用 Management API。

- 参考章节：[用户会话管理](/end-user-flows/account-settings/by-management-api#user-session-management)
- 端点：[`GET /api/users/{userId}/sessions`](https://openapi.logto.io/operation/operation-listusersessions)
- 可选详情端点：[`GET /api/users/{userId}/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-getusersession)

## 撤销会话 \{#revoke-sessions}

### Account API（终端用户撤销自己的会话） \{#account-api-end-user-revokes-own-sessions}

终端用户可以从自己的会话列表中撤销指定会话。

- 参考章节：[管理用户会话](/end-user-flows/account-settings/by-account-api#manage-user-sessions)
- 端点：[`DELETE /api/my-account/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-deletesessionbyid)

对于敏感操作，Account API 会话管理在访问前需要用户近期认证 (Authentication)。参见 [增强认证 (Step-up authentication)](/end-user-flows/step-up-authentication#account-api-and-account-center)。

### Management API（管理员撤销用户会话） \{#management-api-admin-revokes-user-sessions}

管理员可以通过用户 ID 和会话 ID 撤销目标用户的会话。

- 参考章节：[用户会话管理](/end-user-flows/account-settings/by-management-api#user-session-management)
- 端点：[`DELETE /api/users/{userId}/sessions/{sessionId}`](https://openapi.logto.io/operation/operation-deleteusersession)

## Admin Console \{#admin-console}

如果你的团队直接在 Logto 控制台管理用户，可以在用户详情页查看活跃会话并撤销指定会话。

- 参考章节：[管理用户活跃会话](/user-management/manage-users#manage-user-active-sessions)
