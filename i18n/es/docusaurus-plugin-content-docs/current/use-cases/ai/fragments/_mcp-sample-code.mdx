:::info[Código de ejemplo]
El código de ejemplo completo y ejecutable para esta guía se puede encontrar en el repositorio [mcp-auth/js](https://github.com/mcp-auth/js/tree/master/packages/sample-servers):

- [`whoami-express`](https://github.com/mcp-auth/js/tree/master/packages/sample-servers/src/whoami-express): el servidor "whoami" de esta guía, en Node.js con Express.
- [`whoami`](https://github.com/mcp-auth/js/tree/master/packages/sample-servers/src/whoami): el mismo servidor construido con fetch-native (`Request` / `Response` estándar web con [Hono](https://hono.dev)), desplegable en Cloudflare Workers.
