# Gestión de miembros del tenant

## Invitar colaboradores \{#invite-collaborators}

Ve a <CloudLink to="/tenant-settings/members">Consola > Configuración del tenant > Miembros</CloudLink>. Verás tus miembros actuales y podrás invitar a más. Ingresa las direcciones de correo electrónico y asigna roles (puedes hacerlo en lote) y luego envía.

Logto te permite invitar miembros del equipo a tu tenant con dos roles diferentes en Logto Cloud:

- **Admin:** Acceso completo y gestión de todos los recursos del tenant.
- **Colaborador:** Puede gestionar recursos relacionados con la identidad, pero con limitaciones:
  - Sin acceso a la información de facturación
  - No puede invitar ni gestionar a otros miembros
  - No puede cambiar el nombre del tenant
  - No puede eliminar el tenant

### Límite de miembros \{#members-limit}

| Tipo de tenant                | Límite de miembros                                 |
| ----------------------------- | -------------------------------------------------- |
| Tenant de desarrollo          | Hasta 3 miembros (contáctanos para más)            |
| Tenant de producción gratuito | 1 miembro (solo admin)                             |
| Tenant de producción Pro      | 1 miembro incluido, luego $8 por miembro adicional |

### Gestionar invitaciones \{#manage-invitation}

La pestaña de invitaciones muestra las invitaciones anteriores con su estado

| Estado    | Explicación                               | Acción disponible |
| --------- | ----------------------------------------- | ----------------- |
| Pendiente | Invitación enviada, pero aún no aceptada. | Reenviar          |
| Aceptada  | El usuario ahora es miembro del tenant.   | Eliminar          |
| Expirada  | La invitación superó el límite de 7 días. | Eliminar          |
| Revocada  | El admin canceló la invitación.           | Eliminar          |

No puedes invitar a personas que ya tengan invitaciones pendientes o que ya sean miembros.

### Gestionar miembros del tenant (solo Admin) \{#manage-tenant-members-admin-only}

Como admin, tienes varias formas de gestionar tu equipo:

- **Invitar o eliminar miembros:** Agrega nuevos miembros del equipo o elimina el acceso según sea necesario.
- **Cambiar roles de los miembros:** Asigna roles de 'admin' o 'colaborador' según el nivel de acceso requerido.
- **Transferir la propiedad del tenant:** Si es necesario, puedes transferir la propiedad del tenant a otro miembro. Primero puedes dar el rol de admin a otro miembro y luego elegir quedarte como miembro regular o salir del tenant por completo.
- **Agregar múltiples admins:** Comparte responsabilidades administrativas con otros miembros del equipo para una gestión colaborativa.
