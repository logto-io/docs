# Servicio central

## Introducción \{#introduction}

_El Servicio central_ es un servicio monolítico para tareas críticas de Logto. El código fuente está en [`@logto/core`](https://github.com/logto-io/logto/tree/master/packages/core).

:::note
_El Servicio central_ y _SDK core_ son dos conceptos separados. Consulta [Convención de SDK](/developers/sdk-conventions) para conocer las diferencias.
:::

Para simplificar, dividimos el Servicio central en cuatro módulos principales:

Las APIs de backend, incluido OIDC, se construyen dentro del paquete `core`, mientras que los proxies de frontend dependen de los paquetes hermanos correspondientes en el monorepo de Logto.

## Proveedor OIDC \{#oidc-provider}

Logto utiliza la increíble implementación certificada de [OpenID Connect](https://openid.net/connect/) [node-oidc-provider](https://github.com/panva/node-oidc-provider) en su núcleo. El proveedor está montado en `/oidc`, y puedes consultar las configuraciones y archivos relativos en [packages/core/src/oidc](https://github.com/logto-io/logto/tree/master/packages/core/src/oidc).

El [Userinfo Endpoint](https://openid.net/specs/openid-connect-core-1_0.html#UserInfo) de OIDC está disponible y montado en `/oidc/me`.

:::info
Si deseas llamar directamente a las APIs de OIDC, recuerda establecer el encabezado `Content-Type: application/x-www-form-urlencoded`.
:::

## Logto API \{#logto-api}

### Management API \{#management-api}

_Management API_ es un conjunto de APIs que gestionan y actualizan los datos de Logto. Solo los usuarios con el rol `admin` tienen acceso a ellas.

Dirígete a [Referencias de API](https://openapi.logto.io) para ver los detalles.

Para acceder a la API de forma programática, consulta [Interactuar con Management API](/integrate-logto/interact-with-management-api).

### Experience API \{#experience-api}

Experience API es un conjunto de endpoints dedicados que soportan interacciones personalizadas de la interfaz de inicio de sesión.

Estas APIs permiten a los desarrolladores implementar funcionalidades centrales de autenticación, incluyendo inicio de sesión, registro, restablecimiento de contraseña, vinculación de cuentas sociales y autenticación multifactor (MFA). Para implementar estas funciones, tu interfaz personalizada debe interactuar con Experience API.

Para comprender mejor los flujos de usuario y los detalles de implementación:

- Consulta la guía [Desarrolla tu interfaz personalizada](/customization/bring-your-ui/#develop-your-custom-ui) para aprender cómo usar Experience API para construir tu propia interfaz de experiencia personalizada
- Consulta [Referencias de Experience API](https://openapi.logto.io/group/endpoint-experience) para la documentación detallada de la API
- Lee el [RFC de diseño de Experience API](https://github.com/logto-io/rfcs/blob/master/draft/0004-experience-api.md) para especificaciones técnicas y ejemplos en profundidad

### Account API \{#account-api}

Account API es un conjunto completo de APIs que brinda a los usuarios finales acceso directo a la API sin necesidad de pasar por Management API, aquí los puntos destacados:

- Acceso directo: Account API permite a los usuarios finales acceder y gestionar directamente su propio perfil de cuenta sin requerir el relay de Management API.
- Gestión de perfil de usuario e identidades: Los usuarios pueden gestionar sus perfiles y configuraciones de seguridad, incluyendo correo electrónico, teléfono, contraseña, conexiones sociales y factores MFA, así como recuperar tokens de Secret Vault para conexiones sociales y SSO empresarial vinculadas.
- Control de acceso global: El administrador tiene control total y global sobre la configuración de acceso, pudiendo personalizar cada campo.
- Autorización sin fricciones: ¡Autorizar es más fácil que nunca! Simplemente usa `client.getAccessToken()` para obtener un token de acceso opaco para OP (Logto), y adjúntalo al encabezado Authorization como `Bearer <access_token>`.

Con Logto Account API, puedes construir un sistema personalizado de gestión de cuentas como una página de perfil totalmente integrada con Logto.

Consulta [Configuración de cuenta por Account API](/end-user-flows/account-settings/by-account-api) para aprender cómo aprovechar Account API y construir tu propia página de configuración de cuenta.

Consulta [Referencias de Account API](https://openapi.logto.io/group/endpoint-my-account) para la documentación detallada de la API.

## Proxies de frontend \{#frontend-proxies}

Un _proxy de frontend_ es una función middleware que sirve un proyecto frontend de acuerdo al entorno:

- Si es desarrollo, redirige las solicitudes HTTP al servidor de desarrollo frontend.
- Si es producción, sirve directamente los archivos estáticos del frontend.
