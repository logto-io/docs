# バックアップコード

## 概念 \{#concepts}

バックアップコード（リカバリーコードとも呼ばれます）は、多要素認証 (MFA) のための使い捨てコードであり、ユーザーの主要な認証要素（例：認証アプリやハードウェアトークン）が利用できない場合のバックアップとして機能します。

これらを紛失するとアカウントの復旧が困難になる場合があります。そのため、バックアップコードを有効にする前に追加の主要要素を設定し、優先順位を高くすることを推奨します。

Logto は、ユーザーが追加の要素を設定すると自動的に 10 個のバックアップコードを生成します。各コードは一度だけ使用できます。ユーザーは [組み込みのアカウントセンター UI](/end-user-flows/account-settings/by-account-center-ui)（`/account/backup-codes/regenerate`）、[Account API](/end-user-flows/account-settings/by-account-api#manage-backup-codes) を使ったカスタムセルフサービスインターフェース、または [Management API](/end-user-flows/account-settings/by-management-api#user-mfa-settings-management) を利用した管理ツールから、既存のコードをすべて使い切る前に新しいコードセットを再生成できます。

## MFA のためのバックアップコード設定 \{#configure-backup-codes-for-mfa}

1. <CloudLink to="/mfa">コンソール > 多要素認証 (MFA)</CloudLink> に移動します
2. 「バックアップコード」要素を有効にします。バックアップコードは唯一の MFA 要素としては使用できません。他の主要な MFA 要素（パスキー、認証アプリ、SMS、メール）と組み合わせて使用する必要があります。
3. 希望する MFA ポリシー（任意、適応型、必須）を設定します
4. 設定変更を保存します

## バックアップコード管理の設定 \{#configure-backup-codes-management}

ユーザーは [組み込みのアカウントセンター UI](/end-user-flows/account-settings/by-account-center-ui)（`/account/backup-codes/manage` および `/account/backup-codes/regenerate`）を使ってバックアップコードを表示・再生成できます。また、Account API を利用してカスタムアカウント管理インターフェースを構築し、ユーザーがバックアップコードの表示、再生成、削除を行えるようにすることも可能です。これにより、アプリケーションのアカウント設定画面から直接リカバリーオプションを管理できます。

詳細な実装手順や API エンドポイントについては、[Account API によるアカウント設定](/end-user-flows/account-settings/by-account-api#manage-backup-codes) を参照してください。

## バックアップコード設定フロー \{#backup-codes-setup-flows}

バックアップコードは二次的な MFA 要素であるため、主要な MFA 要素が正常に設定された後にのみセットアップできます。自動生成された 10 個のバックアップコードがユーザーに表示され、ダウンロードや安全なコピーが可能です。ユーザーは MFA 設定プロセスを完了するために、バックアップコードを手動で確認する必要があります。

## バックアップコード認証フロー \{#backup-codes-verification-flow}

バックアップコードは、主要な MFA 要素が利用できない場合の緊急認証手段として機能します。各コードは一度だけ使用でき、認証に成功すると無効になります。

**認証の優先順位：**

- **まず主要要素**：他の MFA 要素が設定されている場合、主要要素（パスキー、TOTP、SMS、メール）が最初に求められます。
- **バックアップコードへの切り替え**：主要要素が利用できない場合、「別の方法で認証する」をクリックしてバックアップコードに切り替えることができます。
- **フォールバックシナリオ**：すべての主要要素が削除された場合、バックアップコードが唯一の認証手段となります。サインイン時にバックアップコードで MFA 認証に成功すると、Logto は自動的に新しい主要要素の設定を促します。
