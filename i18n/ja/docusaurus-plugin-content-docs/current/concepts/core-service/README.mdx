# コアサービス

## 概要 \{#introduction}

_コアサービス_ は、Logto の重要な役割を担うモノリシックサービスです。ソースコードは [`@logto/core`](https://github.com/logto-io/logto/tree/master/packages/core) にあります。

:::note
_コアサービス_ と _SDK core_ は別の概念です。違いについては [SDK の規約](/developers/sdk-conventions) を参照してください。
:::

## OIDC プロバイダー \{#oidc-provider}

Logto は、認証済みの素晴らしい [OpenID Connect](https://openid.net/connect/) 実装である [node-oidc-provider](https://github.com/panva/node-oidc-provider) を内部で利用しています。プロバイダーは `/oidc` にマウントされており、関連する設定やファイルは [packages/core/src/oidc](https://github.com/logto-io/logto/tree/master/packages/core/src/oidc) で確認できます。

OIDC の [Userinfo エンドポイント](https://openid.net/specs/openid-connect-core-1_0.html#UserInfo) も利用可能で、`/oidc/me` にマウントされています。

:::info
OIDC API を直接呼び出す場合は、ヘッダー `Content-Type: application/x-www-form-urlencoded` を設定してください。
:::

## Logto API \{#logto-api}

### Management API \{#management-api}

_Management API_ は、Logto データの管理や更新を行うための API 群です。`admin` ロールを持つユーザーのみがアクセスできます。

詳細は [API リファレンス](https://openapi.logto.io) をご覧ください。

API をプログラムから利用するには、[Management API との連携](/integrate-logto/interact-with-management-api) を参照してください。

### Experience API \{#experience-api}

Experience API は、カスタムサインインインターフェースのインタラクションをサポートする専用エンドポイント群です。

これらの API により、開発者はサインイン、サインアップ、パスワードリセット、ソーシャルアカウント連携、多要素認証 (MFA) などのコア認証機能を実装できます。これらの機能を実装するには、カスタム UI から Experience API との連携が必要です。

ユーザーフローや実装詳細をより深く理解するには：

- [カスタム UI の開発](/customization/bring-your-ui/#develop-your-custom-ui) ガイドで、Experience API を使ったカスタム体験 UI の構築方法を学べます
- [Experience API リファレンス](https://openapi.logto.io/group/endpoint-experience) で詳細な API ドキュメントを参照できます
- [Experience API 設計 RFC](https://github.com/logto-io/rfcs/blob/master/draft/0004-experience-api.md) で技術仕様や例を確認できます

### Account API \{#account-api}

Account API は、エンドユーザーが Management API を経由せずに直接 API アクセスできる包括的な API 群です。主な特徴は以下の通りです：

- ダイレクトアクセス：Account API により、エンドユーザーは自分のアカウントプロファイルに直接アクセス・管理できます。Management API の中継は不要です。
- ユーザープロファイルとアイデンティティ管理：ユーザーはメール、電話番号、パスワード、ソーシャル連携、MFA 要素などのプロファイルやセキュリティ設定を管理でき、連携済みソーシャルやエンタープライズ SSO 接続の Secret Vault トークンも取得できます。
- グローバルアクセス制御：管理者はアクセス設定をグローバルに完全管理でき、各フィールドをカスタマイズ可能です。
- シームレスな認可 (Authorization)：認可 (Authorization) がこれまで以上に簡単に！`client.getAccessToken()` を使って OP (Logto) 用の不透明トークン (Opaque token) を取得し、`Authorization` ヘッダーに `Bearer <access_token>` として付与するだけです。

Logto Account API を使えば、Logto と完全連携したプロフィールページのようなカスタムアカウント管理システムを構築できます。

[Account API によるアカウント設定](/end-user-flows/account-settings/by-account-api) を参照し、Account API を活用したアカウント設定ページの構築方法を学んでください。

[Account API リファレンス](https://openapi.logto.io/group/endpoint-my-account) で詳細な API ドキュメントを確認できます。

## フロントエンドプロキシ \{#frontend-proxies}

_フロントエンドプロキシ_ とは、フロントエンドプロジェクトを環境に応じて提供するミドルウェア関数です：

- 開発環境の場合、HTTP リクエストをフロントエンド開発サーバーへプロキシします。
- 本番環境の場合、静的フロントエンドファイルを直接配信します。
