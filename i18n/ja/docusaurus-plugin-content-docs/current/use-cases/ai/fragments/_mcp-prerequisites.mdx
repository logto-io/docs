## 前提条件 \{#prerequisites}

- [Logto Cloud](https://cloud.logto.io) （またはセルフホスト型）テナント
- Node.js >= 20 の環境

### アーキテクチャの理解 \{#understanding-the-architecture}

- **MCP サーバー**：MCP クライアントにツールやリソースを提供するサーバーです。[最新の MCP 仕様](https://modelcontextprotocol.io/specification/latest/basic/authorization) に従い、Logto が発行するアクセス トークン (Access token) を検証する OAuth 2.0 リソースサーバーとして動作します。
- **MCP クライアント**：認証 (Authentication) フローを開始し、統合をテストするためのクライアントです。{<b>{props.isThirdParty ? 'このガイドではサードパーティの AI エージェントをクライアントとして使用します。' : "このガイドでは VS Code（MCP サポート内蔵）をクライアントとして使用します。"} </b>}
- **Logto**：OpenID Connect プロバイダー（認可 (Authorization) サーバー）として機能し、ユーザーアイデンティティを管理し、MCP サーバー向けにオーディエンスバウンドの JWT アクセス トークン (Access token) を発行します。
