`LogtoClient` インスタンスを `LogtoConfig` オブジェクトで作成してクライアントを初期化します。

```swift title="ContentView.swift"
import Logto
import LogtoClient

let config = try! LogtoConfig(
  endpoint: "<your-logto-endpoint>", // 例: http://localhost:3001
  appId: "<your-app-id>"
)
let client = LogtoClient(useConfig: config)
```

:::info

デフォルトでは、ID トークン (ID token) やリフレッシュ トークン (Refresh token) などの認証情報は Keychain に保存されます。これにより、ユーザーが再度戻ってきた際に再サインインする必要がありません。

この動作を無効にするには、`usingPersistStorage` を `false` に設定してください：

```swift
let config = try! LogtoConfig(
  // ...
  usingPersistStorage: false
)
```

:::
