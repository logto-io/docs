# テナントメンバー管理

## コラボレーターの招待 \{#invite-collaborators}

<CloudLink to="/tenant-settings/members">コンソール > テナント設定 > メンバー</CloudLink> に移動します。現在のメンバーが表示され、さらに招待することができます。メールアドレスを入力し、ロールを割り当てて（まとめて操作可能）、送信します。

Logto では、Logto Cloud のテナントにチームメンバーを 3 種類のロールで招待できます：

- **管理者 (Admin)：** テナントのすべて（メンバーや請求も含む）にフルアクセスできます。
- **コラボレーター (Collaborator)：** テナントのリソース（アプリケーション、ユーザー、コネクター、サインイン体験など）を閲覧・変更できますが、メンバーや請求の管理はできません。
- **閲覧者 (Viewer)：** テナントのリソースやメンバーを閲覧できますが、変更はできません。一部の認証情報は閲覧者から隠されています。詳細は [閲覧者が見られないもの](#what-viewers-cannot-see) を参照してください。

### ロールごとの権限 \{#role-permissions}

| アクション                                                                | 管理者 (Admin) | コラボレーター (Collaborator) | 閲覧者 (Viewer) |
| ------------------------------------------------------------------------- | -------------- | ----------------------------- | --------------- |
| テナントのリソースとメンバーの閲覧                                        | ✅             | ✅                            | ✅              |
| テナントのリソースの作成・変更・削除                                      | ✅             | ✅                            | ❌              |
| メンバーの招待・削除、ロール変更、招待状況の閲覧                          | ✅             | ❌                            | ❌              |
| テナント名の変更や削除                                                    | ✅             | ❌                            | ❌              |
| 開発テナントから本番テナントへの変換                                      | ✅             | ❌                            | ❌              |
| **テナント設定 > ドメイン** でのカスタムドメインの追加・削除              | ✅             | ❌                            | ❌              |
| メンバーへの多要素認証 (MFA) 必須化                                       | ✅             | ❌                            | ❌              |
| **プランと請求** および **請求履歴** タブの閲覧、アップグレードや請求管理 | ✅             | ❌                            | ❌              |
| [テナントから退出](/logto-cloud/tenant-settings#leave-tenant)             | ✅             | ✅                            | ✅              |

コンソール上では、閲覧者には **閲覧のみ** のタグとバナーが表示されます。作成・保存・削除・テストのボタンは非表示となり、フィールドは読み取り専用です。

### 閲覧者が見られないもの \{#what-viewers-cannot-see}

閲覧者は、Logto テナントやそのユーザーへのアクセス権を与える認証情報を閲覧できません：

- アプリケーションシークレット
- ユーザーの個人用アクセストークン
- ワンタイムトークン
- ユーザーパスワードハッシュ

コンソール上では、アプリケーションシークレットや個人用アクセストークンは **閲覧者には非表示** と表示されます。

:::warning
閲覧者でも、コネクターやエンタープライズ SSO コネクターの設定、CAPTCHA シークレットキー、Webhook 署名キー、カスタム JWT スクリプトや Actions の環境変数など、テナント設定内の他のシークレットは閲覧できます。これらを閲覧しても問題ないと信頼できる場合のみ、閲覧者として招待してください。
:::

### メンバー数の上限 \{#members-limit}

| テナント種別     | メンバー上限                                      |
| ---------------- | ------------------------------------------------- |
| 開発テナント     | 最大 3 名（追加希望の場合はお問い合わせください） |
| 無料本番テナント | 1 名（管理者のみ）                                |
| Pro 本番テナント | 1 名まで無料、追加 1 名ごとに $8                  |

閲覧者も他のメンバーと同様に上限や追加料金の対象となります。

### 招待の管理 \{#manage-invitation}

招待タブでは、過去の招待とそのステータスが表示されます。

| ステータス   | 説明                                         | 操作可能内容 |
| ------------ | -------------------------------------------- | ------------ |
| 保留中       | 招待が送信されたが、まだ受諾されていません。 | 再送         |
| 受諾済み     | ユーザーがテナントメンバーになりました。     | 削除         |
| 期限切れ     | 招待が 7 日間の有効期限を超えました。        | 削除         |
| 取り消し済み | 管理者が招待をキャンセルしました。           | 削除         |

すでに保留中の招待がある人や、既存メンバーには招待できません。

### テナントメンバーの管理（管理者のみ） \{#manage-tenant-members-admin-only}

管理者は、チームを次の方法で管理できます：

- **メンバーの招待・削除：** 新しいチームメンバーの追加や、不要になったメンバーのアクセス削除ができます。
- **メンバーのロール変更：** 必要なアクセスレベルに応じて「管理者」「コラボレーター」「閲覧者」のロールを割り当てられます。
- **テナント所有権の譲渡：** 必要に応じて、テナントの所有権を他のメンバーに譲渡できます。まず他のメンバーに管理者ロールを付与し、その後自分は通常メンバーとして残るか、テナントから退出することができます。
- **複数の管理者追加：** 他のチームメンバーと管理責任を分担し、共同管理が可能です。
