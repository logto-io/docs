# テナントメンバー管理

## コラボレーターの招待 \{#invite-collaborators}

<CloudLink to="/tenant-settings/members">コンソール > テナント設定 > メンバー</CloudLink> に移動します。現在のメンバーが表示され、さらに招待することができます。メールアドレスを入力し、ロールを割り当てて（まとめて操作可能）、送信します。

Logto では、Logto Cloud のテナントにチームメンバーを 2 種類のロールで招待できます：

- **管理者 (Admin)：** すべてのテナントリソースへのフルアクセスと管理が可能です。
- **コラボレーター (Collaborator)：** アイデンティティ関連リソースの管理が可能ですが、制限があります：
  - 請求情報へのアクセス不可
  - 他のメンバーの招待や管理不可
  - テナント名の変更不可
  - テナントの削除不可

### メンバー数の上限 \{#members-limit}

| テナント種別               | メンバー上限                                        |
| -------------------------- | --------------------------------------------------- |
| 開発テナント               | 最大 3 名（追加が必要な場合はお問い合わせください） |
| 無料プロダクションテナント | 1 名（管理者のみ）                                  |
| プロプロダクションテナント | 1 名含む、追加メンバーごとに $8                     |

### 招待の管理 \{#manage-invitation}

招待タブでは、過去の招待とそのステータスが表示されます

| ステータス   | 説明                                         | 利用可能な操作 |
| ------------ | -------------------------------------------- | -------------- |
| 保留中       | 招待が送信されたが、まだ承認されていません。 | 再送信         |
| 承認済み     | ユーザーがテナントメンバーになりました。     | 削除           |
| 期限切れ     | 招待が 7 日間の期限を超えました。            | 削除           |
| 取り消し済み | 管理者が招待をキャンセルしました。           | 削除           |

すでに保留中の招待がある人や、すでにメンバーである人は招待できません。

### テナントメンバーの管理（管理者のみ） \{#manage-tenant-members-admin-only}

管理者として、チームを管理するためのいくつかの方法があります：

- **メンバーの招待や削除：** 新しいチームメンバーの追加や、必要に応じてアクセス権の削除ができます。
- **メンバーのロール変更：** 必要なアクセスレベルに応じて「管理者 (admin)」または「コラボレーター (collaborator)」のロールを割り当てられます。
- **テナント所有権の移譲：** 必要に応じて、テナントの所有権を他のメンバーに移譲できます。まず他のメンバーに管理者ロールを付与し、その後、通常メンバーとして残るか、テナントから完全に退出するかを選択できます。
- **複数の管理者を追加：** 他のチームメンバーと管理責任を分担し、協力して管理できます。
