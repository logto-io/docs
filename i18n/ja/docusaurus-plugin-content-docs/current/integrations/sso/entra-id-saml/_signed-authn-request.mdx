Microsoft Entra ID では、署名付き SAML 認証リクエスト (Authentication request) を要求できます。Logto でこれを利用する場合、サインインの中断を避けるために次の順序で操作してください：

1. Logto コネクターの `Connection` タブで、**Request signing certificate** の下にある **Generate new key** をクリックし、アクティブキーの証明書をダウンロードします。
2. Entra ID アプリケーションのシングルサインオン設定で、証明書を **Verification certificates** の下にアップロードします。詳細は [署名付き SAML 認証リクエスト (Authentication request) の強制](https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/howto-enforce-signed-saml-authentication) を参照してください。
3. Logto に戻り、コネクターで **Sign authentication request** を有効にして保存します。
4. Entra ID で **Require verification certificates** をチェックし、サインインフローをテストします。

Entra ID は RSA-SHA256（Logto のデフォルトアルゴリズム）で署名されたリクエスト (Authentication request) のみを検証し、SP 発行のサインインリクエスト (Authentication request) に対してこの要件を強制します。セットアップ全体や証明書ローテーションの流れについては、[SAML 認証リクエスト (Authentication request) に署名する](https://docs.logto.io/integrations/saml-sso#optional-sign-the-saml-authentication-request) を参照してください。
