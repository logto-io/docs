# Logto MCP Server

Logto MCP Server는 원격 [MCP (Model Context Protocol)](https://modelcontextprotocol.io/) 서버입니다. AI 애플리케이션에 URL을 추가하고, Logto Cloud 계정으로 로그인한 뒤, Logto와 대화를 시작하세요.

:::tip
Logto MCP Server는 Logto와 [MCP Auth](https://mcp-auth.dev)로 구축되었습니다. 직접 원격 MCP 서버를 구축하고 싶다면 [직접 원격 MCP 서버 구축하기](#build-your-own-remote-mcp-server)를 참고하세요.
:::

## 할 수 있는 일 \{#what-you-can-do}

- **프로젝트에 인증 (Authentication) 추가하기**: AI가 프레임워크를 감지하고, Logto 애플리케이션을 생성하며, 동작하는 통합 코드를 생성합니다. React, Next.js, Vue, Nuxt, SvelteKit, Express, Go, Python, iOS, Android, Flutter 등 38개 이상의 프레임워크를 지원합니다.
- **Logto에 대해 질문하기**: AI가 Logto 문서를 검색하여 출처와 함께 답변을 제공합니다.

곧 로그인 경험 설정, 역할 기반 접근 제어 (RBAC) 및 권한 관리, 조직을 활용한 B2B 앱 구축을 위한 다중 테넌시 설정 등 더 많은 기능이 추가될 예정입니다.

## AI 애플리케이션 연결 방식 \{#how-your-ai-application-connects}

Logto MCP Server는 AI 애플리케이션이 로그인 시 자신을 식별할 수 있는 두 가지 방식을 지원합니다. 두 방식 모두 Logto Cloud에서 별도의 설정이 필요하지 않습니다.

- **서버 URL만 사용 (권장)**: 대부분의 AI 애플리케이션은 이제 [클라이언트 ID 메타데이터 문서 (CIMD)](/integrate-logto/third-party-applications/dynamic-apps)를 지원합니다. 애플리케이션은 자신이 소유한 URL을 클라이언트 ID로 사용하고, Logto는 해당 URL에서 애플리케이션 이름과 리디렉션 URI를 읽어옵니다. 서버 URL `https://mcp.logto.io`만 입력하면 됩니다.
- **고정 클라이언트 ID**: 아직 CIMD를 지원하지 않는 애플리케이션의 경우, 공개 OAuth 클라이언트 ID `mcp-client`를 입력하세요. 이 클라이언트는 루프백 리디렉션 URI (`http://localhost` 또는 `http://127.0.0.1`의 임의 포트)를 허용합니다.

두 옵션이 모두 가능한 경우, 서버 URL만 사용하는 방식을 선택하세요. 기존에 `mcp-client`를 사용해 연결된 경우에도 계속 정상 동작하므로 재연결할 필요가 없습니다.

서버 URL만으로 연결하면, Logto Cloud 로그인 페이지에 애플리케이션 이름과 클라이언트 ID URL의 호스트(예: `claude.ai` 또는 `vscode.dev`)가 표시된 동의 화면이 나타납니다. 인가 (Authorization) 전에 호스트가 사용 중인 애플리케이션과 일치하는지 확인하세요.

## AI 애플리케이션에서 설정하기 \{#set-up-in-your-ai-application}

### Amp \{#amp}

1. [Amp](https://ampcode.com)에서 **Personal Settings** > **Integrations & MCP**로 이동하여 **Add MCP Server**를 클릭하세요.
2. 이름에 `Logto MCP Server`를 입력하고, 서버 URL로 `https://mcp.logto.io`를 입력하세요. Amp가 인증 방식을 자동으로 감지합니다.
3. **Connect**를 클릭하고 Amp의 안내에 따라 로그인하세요.
4. Logto Cloud 계정으로 로그인하고 연결을 인가 (Authorization)하세요.

:::tip
Amp가 **Detecting Authentication** 단계에서 오래 머무를 경우, **Change**를 클릭하고 **OAuth**를 선택하여 자동 인증 감지를 건너뛰세요. **Use Your Own OAuth App**의 **OAuth Client ID**와 **OAuth Client Secret**은 비워두고, **Connect**를 클릭한 뒤 로그인 안내를 따르세요. Amp는 CIMD를 지원하므로 OAuth 앱 등록이나 `mcp-client` 입력이 필요하지 않습니다.
:::

### Claude Code \{#claude-code}

```bash
claude mcp add --transport http logto https://mcp.logto.io
```

이후 `/mcp`를 Claude Code에서 실행하고, `logto`를 선택한 뒤 브라우저 로그인 흐름을 따라 Logto Cloud 계정으로 인증 (Authentication)하세요. 또는 쉘에서 `claude mcp login logto`를 실행할 수도 있습니다.

### Claude (웹 및 데스크톱) \{#claude-web-and-desktop}

1. **Customize** > **Connectors**로 이동하여 **Add custom connector**를 클릭하세요.
2. 이름에 `Logto MCP Server`를 입력하고, 원격 MCP 서버 URL로 `https://mcp.logto.io`를 입력하세요. **Advanced settings**의 OAuth 설정은 비워두고 **Add**를 클릭하세요.
3. **Connectors** 목록에서 **Logto MCP Server**를 찾아 **Connect**를 클릭하세요.
4. Logto Cloud 로그인 페이지로 리디렉션됩니다. Logto Cloud 계정으로 로그인하고 연결을 인가 (Authorization)하세요.

커넥터는 Claude 계정에 저장되므로 웹과 Claude Desktop 모두에서 사용할 수 있습니다.

### ChatGPT 및 Codex \{#chatgpt-and-codex}

1. 왼쪽 사이드바에서 **Plugins**를 열고, 오른쪽 상단의 **Add** > **Add custom MCP server**를 클릭하세요.
2. 이름에 `Logto MCP Server`를 입력하세요. **Connection**에서 **Server URL**을 선택하고 `https://mcp.logto.io`를 입력하세요.
3. 기본 **인증 (Authentication)** (**OAuth**) 및 **Advanced OAuth settings**를 그대로 두세요.
4. **I understand and want to continue**를 선택한 뒤 **Create as a plugin**을 클릭하세요.
5. **Connect Logto MCP Server** 대화상자에서 **Connect Logto MCP Server**를 클릭하세요. Logto Cloud 계정으로 로그인하고 연결을 인가 (Authorization)하세요.

:::tip
로그인 후 **Logto MCP Server**가 **Installed** 아래에 나타나지 않으면 잠시 기다렸다가 **Plugins** 페이지 오른쪽 상단의 새로고침 버튼을 클릭하세요.
:::

Codex CLI로도 서버를 추가할 수 있습니다:

```bash
codex mcp add logto --url https://mcp.logto.io
codex mcp login logto
```

브라우저 창이 열리면 Logto Cloud 계정으로 로그인하여 연결하세요. ChatGPT 데스크톱 앱, Codex CLI, Codex IDE 확장 프로그램이 이 구성을 공유합니다.

### Cursor \{#cursor}

Cursor는 아직 CIMD를 지원하지 않으므로 고정 클라이언트 ID를 사용합니다.

1. **Customize** > **MCPs**를 열거나, `~/.cursor/mcp.json`(글로벌) 또는 `.cursor/mcp.json`(프로젝트)을 엽니다.
2. 다음과 같이 구성하세요:

   ```json
   {
     "mcpServers": {
       "Logto": {
         "url": "https://mcp.logto.io",
         "auth": {
           "CLIENT_ID": "mcp-client",
           "scopes": ["mcp:all"]
         }
       }
     }
   }
   ```

3. 서버 옆의 **Connect**를 클릭하세요. Logto Cloud 로그인 페이지가 나타납니다. Logto Cloud 계정으로 로그인하여 연결하세요.

Cursor 데스크톱 앱에서 로그인하세요. 웹 및 Cursor Agents에서 사용하는 웹 콜백은 지원되지 않습니다.

### OpenCode \{#opencode}

1. `opencode.json` 파일에 다음 구성을 추가하세요:

   ```json
   {
     "$schema": "https://opencode.ai/config.json",
     "mcp": {
       "Logto": {
         "enabled": true,
         "type": "remote",
         "url": "https://mcp.logto.io"
       }
     }
   }
   ```

2. 다음 명령어로 인증 (Authentication)하세요:
   ```bash
   opencode mcp auth Logto
   ```
   여기서 `Logto`는 구성 파일의 MCP 서버 이름과 일치해야 합니다.

브라우저 창이 열리면 Logto Cloud 계정으로 로그인하여 인가 (Authorization) 및 연결하세요.

### VS Code \{#vs-code}

1. 명령 팔레트(`Command + Shift + P`)를 열고 **MCP: Add Server...**를 선택하세요.
2. 서버 유형으로 **HTTP**를 선택하세요.
3. URL에 `https://mcp.logto.io`를 입력하세요. 워크스페이스에 설치하여 더 나은 격리 및 관리를 할 수 있습니다.
4. VS Code에서 인증 (Authentication)을 요청하면 허용하세요. Logto Cloud 로그인 페이지로 리디렉션됩니다. Logto Cloud 계정으로 로그인하여 연결하세요.

또는 `.vscode/mcp.json` 또는 사용자 `mcp.json`에 서버를 추가할 수 있습니다:

```json
{
  "servers": {
    "logto": {
      "type": "http",
      "url": "https://mcp.logto.io"
    }
  }
}
```

### Windsurf \{#windsurf}

Windsurf는 CIMD 지원이 문서화되어 있지 않으므로, 고정 클라이언트 ID와 함께 [`mcp-remote`](https://www.npmjs.com/package/mcp-remote)를 사용하세요.

1. 명령 팔레트(`Command + Shift + P`)를 열고 **Windsurf: MCP Marketplace**를 선택하세요.
2. **Installed MCPs** 섹션에서 오른쪽의 설정 아이콘을 클릭하여 MCP 구성 파일을 엽니다.
3. 다음 [구성](https://docs.windsurf.com/windsurf/cascade/mcp#mcp_config-json)을 추가하세요:

   ```json
   {
     "mcpServers": {
       "Logto": {
         "command": "npx",
         "args": [
           "mcp-remote",
           "https://mcp.logto.io",
           "--allow-http",
           "--static-oauth-client-info",
           "{ \"client_id\": \"mcp-client\", \"scope\": \"mcp:all\" }",
           "--resource",
           "https://mcp.logto.io/"
         ]
       }
     }
   }
   ```

Logto Cloud 로그인 페이지가 자동으로 나타납니다. Logto Cloud 계정으로 로그인하여 연결하세요.

### 기타 MCP 클라이언트 \{#other-mcp-clients}

Logto MCP Server는 OAuth 인가 (Authorization)를 지원하는 모든 MCP 클라이언트와 호환됩니다:

- **클라이언트가 CIMD를 지원하는 경우**: MCP 서버 URL `https://mcp.logto.io`만 입력하세요. 클라이언트가 나머지 정보를 서버에서 자동으로 가져옵니다.
- **그 외의 경우**: 다음 구성을 사용하세요.
  - **MCP 서버 URL:** `https://mcp.logto.io`
  - **OAuth 클라이언트 ID:** `mcp-client` (클라이언트 시크릿 없음)
  - **리디렉션 URI:** `http://localhost:<port>/callback`과 같은 루프백 주소
  - **리소스:** `https://mcp.logto.io/` (클라이언트가 필요로 할 경우)
  - **스코프:** `mcp:all` (클라이언트가 필요로 할 경우)

Logto MCP Server는 Dynamic Client Registration (DCR)을 지원하지 않습니다. AI 애플리케이션 개발자라면, 애플리케이션을 위해 [클라이언트 ID 메타데이터 문서 게시](/integrate-logto/third-party-applications/dynamic-apps#publish-a-client-id-metadata-document)를 진행하면 Logto에서 별도 설정 없이 연결할 수 있습니다. 불가능하다면, [문의하기](https://logto.io/contact)로 애플리케이션 정보를 보내주세요.

## 직접 원격 MCP 서버 구축하기 \{#build-your-own-remote-mcp-server}

Logto MCP Server는 Logto와 [MCP Auth](https://mcp-auth.dev)로 구축되었습니다. 인증 (Authentication)이 적용된 원격 MCP 서버를 직접 구축하고 싶다면 다음 리소스를 참고하세요:

- [Remote MCP server in action: a new entry point for SaaS products in the AI era](https://blog.logto.io/remote-mcp-server-in-action)
- [Discord에 참여하기](https://discord.gg/fUQmaFyAam): 원격 MCP 서버 구축 경험과 모범 사례를 공유하세요
- [MCP Auth](https://mcp-auth.dev): MCP 서버에 프로덕션 수준의 인증 (Authentication)을 추가하는 데 필요한 모든 것. 사양을 읽거나 직접 연결하는 데 몇 주를 소비할 필요가 없습니다.
