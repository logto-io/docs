# 콘솔 SSO

콘솔 SSO를 사용하면 팀이 회사의 아이덴티티 제공자 (IdP) (예: Microsoft Entra ID, Okta, Google Workspace)로 <Url href="https://cloud.logto.io">Logto Cloud 콘솔</Url>에 로그인할 수 있습니다. 이메일 도메인을 인증한 멤버는 Logto Cloud에 로그인할 때 IdP로 이동합니다.

콘솔 SSO는 Logto Cloud 자체에 로그인하는 경우에만 적용됩니다. **자신의 사용자**가 **자신의 애플리케이션**에 회사의 IdP로 로그인하도록 하려면, 테넌트에서 [엔터프라이즈 SSO](/connectors/enterprise-connectors)를 사용하세요.

## 콘솔 SSO 작동 방식 \{#how-console-sso-works}

- **계정에 속하며, 테넌트와는 별개입니다.** 콘솔 SSO 커넥터는 생성한 Logto Cloud 계정에 귀속되며, 해당 계정만 관리할 수 있습니다. 테넌트 요금제, 다운그레이드, 테넌트 삭제는 영향을 주지 않습니다.
- **테넌트 접근 권한을 부여하지 않습니다.** SSO로 로그인하면 신원이 증명됩니다. 테넌트를 열려면 초대 또는 멤버십이 필요합니다. [테넌트 멤버 관리](/logto-cloud/tenant-member-management)를 참고하세요.
- **계정에 청구됩니다.** 커넥터는 각 커넥터별로 자신의 구독을 통해 청구되며, 테넌트 요금제와는 별개입니다. [요금 및 청구](#pricing-and-billing)를 참고하세요.

## 콘솔 SSO 설정하기 \{#set-up-console-sso}

### 커넥터 생성하기 \{#create-a-connector}

1. Logto Cloud 콘솔에서 우측 상단의 사용자 메뉴를 열고 **싱글 사인온**을 선택하세요. <Url href="https://cloud.logto.io/console-sso">콘솔 SSO</Url> 페이지가 새 탭에서 열립니다.
2. **커넥터 추가**를 클릭하고 아이덴티티 제공자를 선택하세요.
3. 첫 번째 커넥터의 경우, 결제 계정을 선택하고 Stripe Checkout에서 결제를 완료하세요. 이후 커넥터는 추가 결제 없이 동일한 구독에 추가됩니다.
4. 커넥터가 설정 페이지에서 열립니다.

### 연결 구성하기 \{#configure-the-connection}

**연결** 탭에서 IdP의 설정 정보를 입력하세요. 필드는 테넌트의 [엔터프라이즈 SSO 커넥터](/connectors/enterprise-connectors)와 동일합니다:

- **OIDC**: 페이지에 표시된 **Redirect URI**를 IdP에 등록한 후, 발급자, 클라이언트 ID, 클라이언트 시크릿을 입력하세요.
- **SAML**: IdP에 페이지에 표시된 서비스 제공자 메타데이터를 제공한 후, IdP의 메타데이터를 입력하세요.

**SSO 경험** 탭에서는 로그인 페이지에 표시될 이름을 변경할 수 있습니다.

### 이메일 도메인 인증하기 \{#verify-your-email-domains}

콘솔 SSO는 소유를 증명한 이메일 도메인에만 적용됩니다.

1. **SSO 경험** 탭에서 `example.com`과 같은 도메인을 입력하고 **도메인 추가**를 클릭하세요.
2. 아래와 같이 DNS 제공자에 TXT 레코드를 추가하세요:

   | Type | Name                           | Value                |
   | ---- | ------------------------------ | -------------------- |
   | TXT  | `_logto-cloud-sso.example.com` | 페이지에 표시된 토큰 |

3. 도메인을 페이지에 열어둔 상태로 두세요. Logto가 10초마다 레코드를 확인합니다. 레코드가 확인되면 도메인이 커넥터에 바인딩되고 **바인딩됨**으로 표시됩니다. 이후 TXT 레코드는 삭제해도 됩니다.

하나의 도메인은 오직 하나의 콘솔 SSO 커넥터에만 바인딩될 수 있습니다. 바인딩된 도메인을 제거하면 해당 도메인의 이메일 주소에 대한 SSO가 중단됩니다. 다시 추가하려면 새 인증이 필요합니다.

:::note
이 단계는 청구와 무관합니다. 커넥터는 생성된 순간부터 연결 설정이나 도메인 완료 여부와 상관없이 청구가 시작됩니다.
:::

### SSO로 로그인하기 \{#sign-in-with-sso}

Logto Cloud 로그인 페이지에서 멤버가 업무용 이메일을 입력하면, 해당 도메인이 커넥터에 바인딩되어 있다면 IdP로 이동하여 로그인하게 됩니다.

## 요금 및 청구 \{#pricing-and-billing}

각 커넥터는 **월 128달러(USD)** (세금 별도)입니다. 계정당 하나의 콘솔 SSO 구독이 있으며, 구독 수량은 커넥터 개수입니다.

| 상황                              | 결과                                                                                 |
| --------------------------------- | ------------------------------------------------------------------------------------ |
| 첫 커넥터 추가                    | Stripe Checkout에서 첫 달 결제. 결제일이 매월 청구일이 됩니다.                       |
| 커넥터 추가                       | 즉시 추가됩니다. 남은 일수만큼의 비례 청구가 다음 청구서에 추가됩니다.               |
| 커넥터 삭제(다른 커넥터 남아있음) | 남은 기간만큼의 비례 크레딧이 다음 청구서에 적용됩니다. 카드로 환불되지는 않습니다.  |
| 마지막 커넥터 삭제                | 구독이 즉시 취소됩니다. 해당 월이 결제된 경우, 남은 기간은 결제 수단으로 환불됩니다. |
| 취소 후 커넥터 추가               | Stripe Checkout을 통해 새 구독이 시작되며, 새 청구일이 설정됩니다.                   |

커넥터의 설정이나 도메인을 수정해도 요금에는 영향을 주지 않습니다.

### 청구서 예시 \{#example-invoice}

아래 수치는 30일 기준, 세금 제외입니다. 실제 비례 계산은 초 단위로 이루어집니다.

| 날짜      | 작업                           | 커넥터 수 | 효과                                             |
| --------- | ------------------------------ | --------- | ------------------------------------------------ |
| 11월 1일  | 첫 커넥터 추가                 | 1         | 결제 시점에 **$128.00** 결제. 청구일은 매월 1일. |
| 11월 16일 | 두 번째 커넥터 추가(15일 남음) | 2         | +$128 × 15/30 = +$64.00이 다음 청구서에 추가     |
| 11월 25일 | 커넥터 하나 삭제(6일 남음)     | 1         | −$128 × 6/30 = −$25.60이 다음 청구서에 차감      |
| 12월 1일  | 월간 청구서                    | 1         | 12월분 $128.00 + $64.00 − $25.60 = **$166.40**   |
| 12월 16일 | 마지막 커넥터 삭제(15일 남음)  | 0         | 구독 취소; **$64.00** 환불                       |

### 구독 및 청구 내역 \{#subscription-and-billing-history}

콘솔 상단바에서 **구독**을 엽니다. 선택된 테넌트와 관계없이 계정의 구독 내역이 표시됩니다.

- **구독**에는 현재 구독의 가격, 다음 결제 및 청구일이 표시됩니다. **결제 관리**를 통해 결제 수단을 변경하거나 미납 청구서를 결제할 수 있습니다.
- **청구 내역**에는 취소된 구독을 포함한 모든 청구서가 표시됩니다. 청구서를 선택하면 상세 내역을 확인하고, 청구서 또는 영수증을 다운로드할 수 있습니다.

### 미납 결제 \{#overdue-payments}

결제에 실패하면 Stripe가 재시도하며, 구독은 **연체됨**으로 표시됩니다. 커넥터는 계속 동작하지만, **결제 관리**에서 결제 수단을 업데이트해 주세요.

**3개월 연속** 모든 재시도에도 결제가 이루어지지 않으면, Logto가 구독을 일시 중지하고 **해당 구독의 모든 커넥터를 삭제**합니다. 다른 사용자의 커넥터와 테넌트에는 영향이 없습니다. 청구 내역에는 청구서가 남아 있습니다.

이후 미납 청구서를 결제해도 삭제된 커넥터는 복구되지 않습니다. 콘솔 SSO를 다시 사용하려면, [문의하기](https://logto.io/contact)로 일시 중지된 구독을 정산한 후, 커넥터를 추가해 새 구독을 시작하세요.

## 커넥터 또는 계정 삭제하기 \{#delete-connectors-or-your-account}

커넥터를 삭제하려면 콘솔 SSO 페이지에서 해당 커넥터를 열고 메뉴에서 삭제하세요. 마지막 커넥터를 삭제하면 위에서 설명한 대로 구독이 취소됩니다. 구독이 연체된 경우, 미납 청구서를 먼저 결제해야 합니다.

Logto Cloud 계정을 삭제하기 전에:

1. 모든 콘솔 SSO 커넥터를 삭제하세요.
2. 구독이 모두 취소되었는지 확인하세요.
3. 미납 청구서가 없는지 확인하세요.

## 문제 해결 \{#troubleshooting}

<details>

<summary>

### 결제했는데 커넥터가 나타나지 않습니다 \{#i-paid-but-my-connector-didnt-appear}

</summary>

Logto가 Stripe로부터 결제 확인을 받는 즉시 커넥터가 생성됩니다(보통 몇 초 소요). 콘솔 SSO 페이지를 새로고침하세요. 몇 분이 지나도 커넥터가 나타나지 않으면 [문의하기](https://logto.io/contact)로 연락하시고, 재결제하지 마세요. 커넥터 생성이 불가한 경우 Logto가 구독을 취소하고 결제를 자동 환불합니다.

</details>

<details>

<summary>

### 커넥터 추가 시 기존 구독 해결 요청이 나옵니다 \{#adding-a-connector-asks-me-to-resolve-my-current-subscription}

</summary>

기존 콘솔 SSO 구독이 새 커넥터를 지원할 수 없는 경우(주로 미납으로 일시 중지된 경우)입니다. 커넥터를 추가하기 전에 [문의하기](https://logto.io/contact)로 정산해 주세요.

</details>

<details>

<summary>

### 커넥터 생성이 중간에 실패했습니다 \{#creating-a-connector-failed-partway}

</summary>

같은 페이지에서 다시 시도하세요: Logto는 새 커넥터를 만들지 않고 기존 커넥터를 이어서 진행합니다. 미완성 커넥터를 폐기하려면 **처음부터 시작**을 선택하세요. 실패한 생성은 구독을 취소하거나 요금이 청구되지 않습니다.

</details>

<details>

<summary>

### 도메인이 계속 인증되지 않습니다 \{#my-domain-stays-unverified}

</summary>

TXT 레코드 이름이 정확히 `_logto-cloud-sso.` + 도메인인지, 값이 페이지의 토큰과 일치하는지 확인하세요. DNS 변경 사항이 전파되기까지 시간이 걸릴 수 있습니다. 페이지에 이미 다른 커넥터에 바인딩되어 있다고 나오면, 먼저 해당 커넥터에서 제거하세요.

</details>
