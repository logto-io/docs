# 테넌트 멤버 관리

## 협업자 초대하기 \{#invite-collaborators}

<CloudLink to="/tenant-settings/members">콘솔 > 테넌트 설정 > 멤버</CloudLink>로 이동하세요. 현재
멤버를 확인하고 더 많은 멤버를 초대할 수 있습니다. 이메일 주소를 입력하고 역할을 지정하세요(여러
명을 한 번에 지정할 수 있습니다). 이후 초대장을 발송하세요.

Logto에서는 Logto Cloud에서 세 가지 역할로 팀 멤버를 테넌트에 초대할 수 있습니다:

- **관리자(Admin):** 테넌트의 모든 권한을 가지며, 멤버 및 결제 관리도 포함됩니다.
- **협업자(Collaborator):** 애플리케이션, 사용자, 커넥터, 로그인 경험 등 테넌트의 리소스를 조회 및 변경할 수 있지만, 멤버나 결제는 관리할 수 없습니다.
- **뷰어(Viewer):** 테넌트의 리소스와 멤버를 조회만 할 수 있으며, 변경은 불가능합니다. 일부 자격 증명은 뷰어에게 숨겨집니다. 자세한 내용은 [뷰어가 볼 수 없는 정보](#what-viewers-cannot-see)를 참고하세요.

### 역할별 권한 \{#role-permissions}

| 작업                                                                   | 관리자 | 협업자 | 뷰어 |
| ---------------------------------------------------------------------- | ------ | ------ | ---- |
| 테넌트의 리소스 및 멤버 조회                                           | ✅     | ✅     | ✅   |
| 테넌트의 리소스 생성, 변경, 삭제                                       | ✅     | ✅     | ❌   |
| 멤버 초대 및 삭제, 역할 변경, 초대 내역 조회                           | ✅     | ❌     | ❌   |
| 테넌트 이름 변경 또는 삭제                                             | ✅     | ❌     | ❌   |
| Dev 테넌트를 프로덕션으로 전환                                         | ✅     | ❌     | ❌   |
| **테넌트 설정 > 도메인**에서 테넌트의 커스텀 도메인 추가/삭제          | ✅     | ❌     | ❌   |
| 멤버에게 MFA 요구                                                      | ✅     | ❌     | ❌   |
| **요금제 및 결제** 및 **결제 내역** 탭 조회, 업그레이드 또는 결제 관리 | ✅     | ❌     | ❌   |
| [테넌트 나가기](/logto-cloud/tenant-settings#leave-tenant)             | ✅     | ✅     | ✅   |

콘솔에서 뷰어는 **조회 전용** 태그와 배너를 볼 수 있습니다. 생성, 저장, 삭제, 테스트 버튼은 숨겨지며, 필드는 읽기 전용입니다.

### 뷰어가 볼 수 없는 정보 \{#what-viewers-cannot-see}

뷰어는 Logto 테넌트 또는 사용자에 대한 접근 권한을 부여하는 자격 증명을 볼 수 없습니다:

- 애플리케이션 시크릿
- 사용자의 개인 액세스 토큰
- 일회성 토큰
- 사용자 비밀번호 해시

콘솔에서는 애플리케이션 시크릿과 개인 액세스 토큰이 **뷰어에게 숨김**으로 표시됩니다.

:::warning
뷰어는 커넥터 및 엔터프라이즈 SSO 커넥터 설정, CAPTCHA 시크릿 키, Webhook 서명 키, 커스텀 JWT 스크립트 및 액션의 환경 변수 등 테넌트 설정 내의 다른 시크릿은 여전히 볼 수 있습니다. 이러한 정보도 신뢰할 수 있는 사람에게만 뷰어로 초대하세요.
:::

### 멤버 수 제한 \{#members-limit}

| 테넌트 유형          | 멤버 수 제한                |
| -------------------- | --------------------------- |
| Dev 테넌트           | 최대 3명 (더 필요하면 문의) |
| 무료 프로덕션 테넌트 | 1명 (관리자만 가능)         |
| Pro 프로덕션 테넌트  | 1명 포함, 추가 멤버당 $8    |

뷰어도 다른 멤버와 동일하게 멤버 수 및 1인당 요금에 포함됩니다.

### 초대 관리 \{#manage-invitation}

초대 탭에서는 과거 초대 내역과 상태를 확인할 수 있습니다.

| 상태    | 설명                                   | 가능한 작업 |
| ------- | -------------------------------------- | ----------- |
| 대기 중 | 초대가 발송되었으나 아직 수락되지 않음 | 재발송      |
| 수락됨  | 사용자가 테넌트 멤버가 됨              | 삭제        |
| 만료됨  | 초대가 7일 제한을 초과함               | 삭제        |
| 취소됨  | 관리자가 초대를 취소함                 | 삭제        |

이미 초대가 대기 중이거나 멤버인 사람은 초대할 수 없습니다.

### 테넌트 멤버 관리 (관리자 전용) \{#manage-tenant-members-admin-only}

관리자는 팀을 다음과 같이 관리할 수 있습니다:

- **멤버 초대 또는 삭제:** 새로운 팀 멤버를 추가하거나 필요에 따라 접근 권한을 제거할 수 있습니다.
- **멤버 역할 변경:** 필요에 따라 '관리자', '협업자', '뷰어' 역할을 지정할 수 있습니다.
- **테넌트 소유권 이전:** 필요하다면 테넌트 소유권을 다른 멤버에게 이전할 수 있습니다. 먼저 다른 멤버에게 관리자 역할을 부여한 뒤, 일반 멤버로 남거나 테넌트에서 완전히 나갈 수 있습니다.
- **여러 명의 관리자 추가:** 다른 팀원과 함께 관리 책임을 분담할 수 있습니다.
