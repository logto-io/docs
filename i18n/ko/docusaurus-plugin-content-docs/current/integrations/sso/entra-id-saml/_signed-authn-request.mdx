Microsoft Entra ID는 서명된 SAML 인증 요청을 요구할 수 있습니다. Logto와 함께 사용하려면, 로그인 중단을 방지하기 위해 다음 순서대로 진행하세요:

1. Logto 커넥터의 `Connection` 탭에서 **Request signing certificate** 아래의 **Generate new key**를 클릭하고, 활성 키의 인증서를 다운로드하세요.
2. Entra ID 애플리케이션의 싱글 사인온 설정에서 **Verification certificates** 아래에 인증서를 업로드하세요. 자세한 내용은 [서명된 SAML 인증 요청 적용하기](https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/howto-enforce-signed-saml-authentication)를 참고하세요.
3. 다시 Logto로 돌아와 커넥터에서 **Sign authentication request**를 활성화하고 저장하세요.
4. Entra ID에서 **Require verification certificates**를 체크한 후, 로그인 플로우를 테스트하세요.

Entra ID는 RSA-SHA256( Logto의 기본 알고리즘)으로 서명된 요청만 검증하며, SP-initiated 로그인 요청에 대해 이 요구 사항을 적용합니다. 전체 설정 및 인증서 교체 플로우는 [SAML 인증 요청 서명하기](https://docs.logto.io/integrations/saml-sso#optional-sign-the-saml-authentication-request)를 참고하세요.
