## 사용자 정보 가져오기 \{#get-user-information}

### 사용자 정보 표시 \{#display-user-information}

사용자의 정보를 표시하려면 `client.getIdTokenClaims()` 메서드를 사용할 수 있습니다. 예를 들어, SwiftUI 앱에서:

```swift title="ContentView.swift"
struct ContentView: View {
  @State var isAuthenticated: Bool
  @State var name: String?

  init() {
    isAuthenticated = client.isAuthenticated
    name = try? client.getIdTokenClaims().name
  }

  var body: some View {
    VStack {
      if isAuthenticated {
        Text("Welcome, \(name ?? "")")
      } else {
        Text("Please sign in")
      }
    }
  }
}
```

### 추가 클레임 (Claim) 요청하기 \{#request-additional-claims}

<FindUserInfoMissing method="client.getIdTokenClaims()" />

<ScopesAndClaimsIntroduction />

추가 스코프 (Scope)를 요청하려면, `LogtoConfig` 객체에 스코프를 전달할 수 있습니다. 예시:

```swift title="ContentView.swift"
let config = try! LogtoConfig(
  endpoint: "<your-logto-endpoint>", // 예: http://localhost:3001
  appId: "<your-app-id>",
  // highlight-start
  scopes: [
    UserScope.email.rawValue,
    UserScope.phone.rawValue,
  ]
  // highlight-end
)
```

그런 다음 `client.getIdTokenClaims()`의 반환값에서 추가 클레임 (Claim)에 접근할 수 있습니다:

```swift
let claims = try? client.getIdTokenClaims()
// 이제 추가 클레임인 `claims?.email`, `claims?.phoneNumber` 등에 접근할 수 있습니다.
```

### 액세스 토큰 (Access token)을 요청 헤더에 첨부하기 \{#attach-access-token-to-request-headers}

토큰을 HTTP 헤더의 `Authorization` 필드에 Bearer 형식(`Bearer YOUR_TOKEN`)으로 넣으면 됩니다.

:::note
Bearer 토큰의 통합 방식은 사용하는 프레임워크나 요청자에 따라 다를 수 있습니다. 각자의 방식에 맞게 요청의 `Authorization` 헤더를 적용하세요.
:::

```swift
let userInfo: LogtoCore.UserInfoResponse = try await LogtoRequest.get(
  useSession: session,
  endpoint: userInfoEndpoint,
  // highlight-next-line
  headers: ["Authorization": "Bearer \(accessToken)"]
)
```
